# 低空经济：万亿新赛道（任和/张维为，2026）

> 源文件：`原始素材/文章/低空经济：未来可期的万亿新赛道.md`
> 嘉宾：任和（上海通用航空协会专家委员会主任）、张维为（复旦大学中国研究院院长）
> 来源：东方卫视《这就是中国》，2026 年 3 月

## 核心数据

### 中美低空对比

| 指标 | 中国 | 美国 |
|:---|:---|:---|
| 通用航空飞机 | ~2000 架 | 24 万架 |
| 通用机场 | 470+ 个 | 公开 5000+，含私人 2 万+ |
| 持照飞行员 | 8 万+ | 50 万+ |
| 空域利用率 | — | 中国的 3.3 倍 |
| 低空飞行量 | 美国的 1.3% | — |
| 航空 GDP 贡献率 | ~1.4% | ~6% |
| 无人机保有量 | **270 万架+（世界第一）** | — |

### 关键政策进展

| 进展 | 内容 |
|:---|:---|
| 2026 定位 | 从"新兴产业"升级为"**新兴支柱产业**" |
| 新民航法 | 2026.07.01 施行，首次明确分类分级管理 |
| 试点城市 | 苏州、合肥、重庆、成都、杭州、深圳，**600 米以下下放地方** |
| 29 省方案 | 已出台低空经济三年行动方案 |
| 2035 预测 | 摩根士丹利：4 万亿 RMB，通航飞机 16 万架 |

### ★空域分层技术参数

任和明确提出："**3000米以下，以20米或200米来分层**，可以分很多层，相当于车道很多，不会拥堵。"

| 参数 | 值 |
|:---|:---|
| 低空总高度 | 3000 米 |
| 细粒度分层 | 20 米/层 |
| 粗粒度分层 | 200 米/层 |

### 产业发展时间线

| 阶段 | 时期 | 特征 |
|:---|:---|:---|
| 研发建设期 | 2026-2030 | 航空器研发制造 + 基础设施 |
| 井喷期 | 2030-2035 | 大量飞行器应用，市场成熟 |
| 普及期 | 2035 后 | 进入家庭，日常交通工具 |

### 当前挑战

- 空域审批仍复杂、周期长
- 适航审定人力不足，"一事一议"积压
- 通导监气象等基础设施待完善
- 研发者重技术轻市场、低估适航难度

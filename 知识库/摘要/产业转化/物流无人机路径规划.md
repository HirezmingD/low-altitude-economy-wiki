# 城市物流无人机运输路径规划

## 基本信息

| 项目 | 内容 |
|------|------|
| 作者 | 费毓晗、张洪海、张连东、冯棣坤、李博文、刘皞 |
| 机构 | 南京航空航天大学·民航学院 |
| 期刊 | 武汉理工大学学报(交通科学与工程版) 2023(1) |
| 方向 | ⚠️ 边缘（物流路径优化） |

## 方法
**两阶段求解**：SA确定配送顺序 → 改进A*(航程约束+转弯约束)求解飞行路径。
**双目标**：客户满意度(模糊时间窗)+ 运输成本(时间×载荷量表示能耗)

## 关键结果
- 运输成本最小方案比最短路径方案**节省3.4%能耗**
- 改进A*比传统A*求解时长**缩短4.3%**
- 权重系数调节可得差异化路径

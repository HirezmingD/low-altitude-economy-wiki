# eVTOL飞行器综述：发展史、核心技术与未来趋势

> Meng等（北航），Case Studies on Transport Policy, 2025 | SCI Q3 IF 3.3

## 一文总结

系统综述eVTOL飞行器发展历程，聚焦7大核心技术：气动构型设计、分布式电推进、长续航电池、智能自主飞行、数字化低空交通管理系统、适航与安全。讨论商业化路径和市场趋势。

## 七大核心技术

| 技术 | 关键点 |
|------|--------|
| 气动构型 | 多旋翼/复合翼/倾转旋翼/倾转涵道四种 |
| 电推进 | 高功率密度、低重量功率比、系统冗余 |
| 电池 | 固态电池、氢燃料电池为未来方向 |
| 自主飞行 | AI轨迹规划、状态预测、多传感器融合 |
| 数字化交通管理 | 数字孪生+智能管控（UTM方向） |
| 适航认证 | TC→PC→AC→OC四证体系 |

## 市场趋势

货运物流→城市公共服务→载人客运三阶段渐进路线。2025-2026年多款机型完成适航取证。

## 与子课题3关联

弱。属飞行器工程技术，不涉及空域容量量化。仅3.6节数字化低空交通管理有边际关联。

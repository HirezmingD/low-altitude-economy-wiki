# 低空经济拐点与产业落地路径（朱克力，2026）

> 源文件：`原始素材/文章/专访湾区低空经济研究院院长朱克力...md`
> 作者：朱克力（国研新经济研究院创始院长、湾区低空经济研究院院长）
> 来源：《每日经济新闻》专访，2026 年

## 背景

2026 年 7 月 1 日，新修订《[民用航空法](知识库/政策/中国/民用航空法2026.md)2026.md)》施行，首次系统纳入低空经济并设发展促进专章。UOM 平台完成全国统一 GIS 数据更新，实现"全国一张网、分钟级更新"。全国新一轮适飞空域调整同步落地。

## 核心论点

### 三大驱动

| 驱动 | 内容 |
|:---|:---|
| 政策 | 低空经济连续三年写入政府工作报告，2026 年首次明确"**新兴支柱产业**" |
| 法律 | 新《[民用航空法](知识库/政策/中国/民用航空法2026.md)2026.md)》设低空经济发展促进专章 |
| 市场 | 广东、江苏、浙江、四川等多省列为重点任务，企业需求空前迫切 |

### 三大趋势

1. **全国统一、标准贯通、同步落地** — 废止地方旧规，"一盘棋"管理
2. **适飞面积大幅扩容** — 核心城区也适度开放
3. **安全与发展平衡** — 核心敏感区严守红线，潜力区域全面松绑

### 省级适飞空域占比（2026 年调整后）

| 省份 | 占比 | 亮点 |
|:---|:---|:---|
| 广西 | 84.26% | 全国最高 |
| 四川 | 80% | 低空资源丰富 |
| 湖南 | 75.5% | 从 43% 增至 75.5%，增幅全国第一 |
| 江西 | 64.71% | — |

### 管控逻辑 → 生产要素逻辑（★核心概念）

朱克力指出：UOM 平台实现"全国一张网、分钟级更新"，标志着低空空域正从**管控逻辑向生产要素逻辑**实质性转变：

| 传统管控逻辑 | 生产要素逻辑 |
|:---|:---|
| 空域是"限制区域"，安全管控为核心 | 空域是"**可调度的生产资料**" |
| 碎片化、审批繁琐、数据不互通 | 统一 GIS、分钟级更新、跨区域无需重复报备 |
| 企业合规成本高、飞行效率低 | 企业精准规划航线、控制成本、保障时效 |

### 从"争空域"转向建生态、强配套、育场景

"低空要素化 → 场景化 → 经济化"三段式产业路径：

| 阶段 | 核心任务 |
|:---|:---|
| **要素化** | 空域边界清晰、规则统一、实时可查 → "空域的确定性" |
| **场景化** | 聚焦物流/应急/文旅/治理/植保，打造标杆示范，避免同质化 |
| **经济化** | 构建研发-制造-运营-服务全链条，推动点状试点→面状爆发 |

### 区域差异化策略（成都案例）

"郊县规模化 + 城区精品化 + 产业链高端化"三步破局路径：
- 核心城区 → 低空安防、应急救援、短途通勤（高附加值、低频次）
- 外围郊县 → 物流配送、农林植保、试飞测试（规模化场景）
- 产业链 → eVTOL 整机、核心零部件、飞控算法（技术壁垒）

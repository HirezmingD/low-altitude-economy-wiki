# 植保无人机不规则区域航线规划算法

> 徐博、陈立平、谭彧、徐旻（中国农业大学工学院），农业工程学报，2015, 31(23)
> 基金：863计划(2012AA101901) + 北京市科技计划

## 一文总结

针对植保无人机在**不规则凸多边形农田**的全覆盖航线规划问题，提出基于航向角的**坐标系旋转+子区域剖分**算法——以喷施幅宽d划分子区域，提取边界交点作为航点，遍历航向角α∈[0,π)寻优。仿真最优多余覆盖率11.5%（α=100°），田间验证2.8%。

## 问题定义

植保无人机需在凸多边形区域D1D2…Dm内进行往复全覆盖喷施。传统方法沿边界方向作业，对不规则区域产生大量多余覆盖。目标：找到最优航向角α使**总飞行距离L最小**（L=作业距离L1+转弯距离L2），同时**多余覆盖率ε最小**。

## 算法流程

```
GPS获取顶点经纬度 → 米制坐标系OXY
        ↓
按航向角α旋转 → 新坐标系O'X'Y'（X'∥作业方向）
        ↓
以幅宽d划分子区域 → n条分隔线 y'=y'max-(k-1)d
        ↓
提取各子区域横坐标极值[x'kmin, x'kmax] → 起止航点
        ↓
遍历α∈[0,π)（步长5°）→ 寻找最小多余覆盖率ε
```

## 关键公式

**多余覆盖率**：ε = (覆盖面积 - 区域面积) / 区域面积

**子区域数量**：由 (y'max - y'min)/d 的比值决定

**航点计算**：第k子区域的航点为 (x'kmin, y'max-(k-1/2)d) 和 (x'kmax, y'max-(k-1/2)d)

## 仿真与试验结果

| α | 总飞行距离(m) | 覆盖面积(m²) | 多余覆盖率 |
|:-:|:----------:|:---------:|:-------:|
| 0° | 273.38 | 1121.8 | 14.1% |
| 45° | 291.30 | 1195.5 | 21.6% |
| 90° | 273.68 | 1169.2 | 18.9% |
| 135° | 293.78 | 1197.0 | 21.8% |
| **100°** | **250.52** | **1096.5** | **11.5%** |

田间试验（QF80-1农用无人机，喷幅5m，983m²田块）：最优航向角100°时多余覆盖率2.8%。

## 与子课题3的间接关联

| 方法要素 | 可类比概念 |
|---------|----------|
| 子区域剖分（幅宽d） | 空域栅格化（栅格尺寸） |
| 航向角优化 | 航路方向对容量的影响 |
| 多余覆盖率=覆盖效率 | 空域利用率=有效容量/总容量 |
| 坐标系旋转 | 空域坐标变换（风向对齐等） |

⚠️ 边缘相关：核心方法属于全覆盖路径规划（coverage path planning），非空域容量评估。但其子区域剖分→方向优化的框架逻辑与空域栅格→航路优化的思路一脉相承。

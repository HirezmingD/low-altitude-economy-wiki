# 无人飞行器与先进空中交通的低空空域管理进展（上）（Pongsakornsathien et al., 2025）

## 背景与问题

本文发表于 **Progress in Aerospace Sciences**（Elsevier, IF ~11.8），由 RMIT 大学航空航天与智能及自主系统研究组完成，系统综述了低空空域管理（LAAM）领域全球研究进展。中文版由"低空产研记录"公众号编译（孙妍/LAIR，2025.11.06），本文为**上篇**（覆盖原文 §1-§3）。

核心论点：**传统 ATM 体系无法线性扩展至低空环境**——运行高度低、交通密度高、飞行器性能差异大、任务多样。文章识别的三大研究空白：
1. 缺少可扩展的 LAAM 冲突解决方法
2. 现有 CONOPS 未充分考虑 CNS 性能对空域功能的影响
3. 人类操作员在高度自动化 LAAM 中的角色未充分研究

## 方法与数据

系统文献综述，覆盖：
- 飞行器/任务分类体系（全球八大分类维度）
- 全球六方 CONOPS 比较（NASA/FAA UTM、SESAR U-Space、JAXA SKALE、K-drone、UOMS、CAAS-NTU）
- 空域结构设计四范式 + 容量估计数学方法
- CNS 性能量化指标建模
- 2015-2022 年社会接受度跨国调查

## 核心发现

### 1. 全球 CONOPS 技术架构比较

| 体系 | 核心架构 | 演进路线 | 容量管理 |
|:---|:---|:---|:---|
| NASA/FAA UTM | FIMS + USS | TCL1→4, UML1→6 | DCB + 垂直机场容量管理 |
| SESAR U-Space | USSP + 生态系统管理者 | U1→U4 (2019→2035+) | **DCB 五阶段**（DACUS 项目） |
| 日本 JAXA | SKALE 模拟器 | 2030 配送场景 | 实证：1km²内 146次/h |
| 中国 UOMS | CAAC-EASA 合作 | — | UTM-ATM 交互 |

### 2. 空域容量估计模型

- **分层空域容量公式**：容量 = f(L, CR_max, k, f(α))，其中 L=层数、CR_max=最大全局冲突率
- **基于密度方法**：图论/随机几何图，考虑密度+间隔+冲突检测能力
- **自由飞行方法**：安全区圆盘 + 三维网格 + Bron-Kerbosch 团计算
- **关键空白**：网格大小估计过程"没有明确界定"——子课题3可直接贡献

### 3. CNS 性能→容量定量链

| CNS 维度 | 关键参数 | 容量影响路径 |
|:---|:---|:---|
| 通信 | 延迟 <10ms, 可靠性 99.999% | 延迟↑→冲突解决时间↑→安全间隔↑→容量↓ |
| 导航 | GNSS UERE + PDOP; 城市峡谷 σ≥25m | 位置不确定性↑→间隔体积↑→容量↓ |
| 监视 | 雷达误差 + ADS-B GNSS误差 + 延迟 | 跟踪不确定性↑→SACA 总时间↑→容量↓ |

### 4. 空域结构设计四范式

完全混合 / 分层（堆叠层+天空车道）/ 分区（按风险暴露）/ 管道（固定走廊）。截至2025年**尚无统一标准**。

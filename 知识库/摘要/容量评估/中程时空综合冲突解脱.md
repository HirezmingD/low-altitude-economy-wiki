# 开放式低空空域中程时空综合冲突检测与解脱

> 杨文元、唐俊、何仁杰、陈英国（国防科技大学），IEEE TCST, 2020
> 基金：NSFC 71601181 + 湖南省自然科学基金

## 一文总结

提出**SGPS空间网格划分**冲突检测 + **TSBT(时间调度)+VCBT(垂直高度变化)** 时空双协同解脱框架。核心性能：计算时间与航迹数**线性关系**（r=0.9973），广州实例验证4对冲突全解脱，50-500架次随机基准测试证实适合大规模在线管控。**直接目标：消除级联偏差→提升空域容量**。

## 方法架构

```
4D航迹 → 离散化航点(TY_i = idt, ts, te, PList)
    ↓
SGPS网格划分（边界向量BFV→均匀网格→TWG时间窗网格）
    ↓ 哈希表+布尔占用表加速
冲突检测：同网格+时间窗重叠 → CF_i六元组
    ↓
冲突分组（PL/PR航点界定）
    ↓
TSBT优先（加速/减速+安全缓冲δ）
    ↓ 失败则
VCBT备选（RACV判向+垂直偏移Vm）
    ↓
无冲突轨迹 NTYList
```

## SGPS冲突检测

| 组件 | 功能 |
|------|------|
| 边界特征向量BFV | 定义空域范围(Lat/Lon/Alt极值) |
| 均匀网格划分 | 替代圆柱安全包络→轴对齐立方体简化检测 |
| TWG时间窗网格 | 每格记录[进入时间, 离开时间] |
| 哈希表 | 每航迹→TWG链表，加速查找 |
| 布尔占用表BT | 预筛选：哪些航迹经过哪些网格 |

**冲突判定**：两航迹同网格标签lpg + 时间窗重叠

## TSBT时间调度

- 减速模式：延迟到达→等待冲突航迹离开
- 加速模式：提前通过→在冲突航迹到达前清空
- 插入航点RP_insert，安全缓冲δ

## VCBT垂直变化

- RACV = 候选航迹爬升率 - 匹配航迹爬升率
- RACV>0 → 候选在上方(Vm偏移)
- RACV≤0 → 候选在下方

## 性能验证

| 指标 | 结果 |
|------|------|
| 计算复杂度 | y=-91+1.72x, r=0.9973 (线性) |
| 小规模(n≤150) | 运行时间波动~25-42% |
| 大规模(n=500) | 波动仅5.4% |
| I_cdr | 300架次以上超越基准算法 |

## 与子课题3关联

冲突解脱效率→直接影响有效容量。SGPS网格化可对接承载力评价的栅格化空间单元。TSBT+VCBT提供"时间-空间"双维容量优化手段。

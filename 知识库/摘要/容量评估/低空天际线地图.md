# 低空天际线地图——高密度飞行安全新基础设施

> 唐炉亮等（武汉大学测绘遥感信息工程国家重点实验室），科学通报，2026

## 一文总结

提出**低空天际线地图**（low-altitude sky-lane map）概念：一种三维动态时空密集的低空公共基础设施，以风险拓扑表达为核心，系统表示地面风险、可飞区域、天际线组成、飞行规则、拓扑关系和动态变化。本质是将低空飞行对地面土地利用和人类活动的潜在影响投影并空间化——解决"在哪儿飞、怎么飞"的百万级城市低空安全挑战。

## 核心定义

> 低空天际线地图 = 从复杂异质高动态地表环境中，生成有序、安全、可导航的低空天际线的专题地图框架——三维、动态、时空密集、拓扑连通、人机可读。

## 功能维度

| 维度 | 内容 |
|------|------|
| 地面风险 | 人口密度/建筑/敏感区→风险投影 |
| 可飞区域 | 动态禁飞区/适飞区/缓冲区分级 |
| 天际线组成 | 航路/节点/交叉口/起降点 |
| 飞行规则 | 单向/限速/限高/优先级 |
| 拓扑关系 | 天际线网络连通性 |
| 动态变化 | 实时更新（天气/临时禁飞/突发事件） |

## 与天路图的区别

| | 天路图（廖小罕） | 天际线地图（唐炉亮） |
|------|:------:|:------:|
| 重点 | 航路规划方法 | 地图制图与基础设施 |
| 尺度 | 城市级航路网 | 百万架次城市运营 |
| 核心 | 构建航线 | 风险拓扑表达+人机可读 |

## 与子课题3关联

天际线地图的空间化风险表达直接对接承载力评价的空间基底，可飞区域定义=可用容量的空间边界。

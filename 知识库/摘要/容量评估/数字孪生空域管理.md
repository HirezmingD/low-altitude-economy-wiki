# 数字孪生集成空域管理与AAM应用

> Kamesh Namuduri (University of North Texas), IEEE Access, 2023 | IF=6.6

## 一文总结

提出面向AAM的**数字孪生空域管理模型**，含8个子系统：集成空域管理、数字飞行规则、交通管理、空中走廊、自主空域运行、UAS间通信、飞行器模型、基础设施。核心论点是数字孪生可填补"实时空域仿真→动态交通管理→预测安全分析→AI优化"的全链路缺口。

## 核心概念

### 数字飞行规则（Digital Flight Rules）
NASA/FAA联合定义：以**数字信息**为参照的飞行运行模式，通过协同自分离+自动化信息交换保障安全——作为VFR和IFR之外的第三种飞行规则，支持无人化自主空域运行。

### 空中走廊（Air Corridors）
三层设计：上层/下层=单向滑行道，中层=交叉口（环岛）供转向。匹配NASA在Dallas-Fort Worth的实际空域走廊（95%时段与民航隔离）。

### UTM与AAM整合
- UTM：sUAS <400ft，USS服务
- AAM：大型UAS 400-3000ft，PSU服务
- 数字孪生桥接两端，实现统一空域快照

## 数字孪生价值

| 功能 | 说明 |
|------|------|
| 实时仿真 | 空域快照+多场景推演 |
| 动态交通管理 | PSU接收实时数据→优化路径/高度/速度 |
| 预测安全 | ML识别拥塞/恶劣天气/接近冲突 |
| AI优化 | 风场/拥塞/性能→动态调整路径 |
| 测试验证 | 安全环境下验证新算法和协议 |

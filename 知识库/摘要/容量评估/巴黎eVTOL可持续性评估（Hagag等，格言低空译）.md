# 巴黎eVTOL可持续性评估：时间节省与CO₂排放的权衡

> 德国航空航天中心（DLR）× 瑞士Axalp Technologies 联合研究，以巴黎为案例，首次系统性量化eVTOL在城市和区域航线中的时间效益与碳排放。格言低空/大为 译。

## 核心判断

**eVTOL是"时间增效工具"而非"低碳替代品"**。其环境表现高度取决于飞行任务类型和电力能源结构：
- **最佳场景**：替代传统直升机（减排47-77%）和跨区域燃油车出行（减排44-47%）
- **最差场景**：替代城市短途电动汽车（排放高388%）和轨道交通（高97-160%）

## 研究设计

| 参数 | 设定 |
|:---|:---|
| 案例城市 | 巴黎（法兰西岛大区，1230万人口，占法国18.3%） |
| 飞行高度 | **1000m** |
| 乘员 | 2名（含飞行员） |
| 电池能量密度 | **250 Wh/kg**（当前技术150-350） |
| 环境条件 | 10°C，0 m/s顶风（理想条件——实际冬季需额外防冰/除霜冗余） |
| 碳排放基准 | 欧洲平均电网 **226 g CO₂/kWh**（法国本地仅 **57**，德国 **508**） |

## 两型eVTOL对比

| 参数 | 多旋翼（UAM代表） | 升力+巡航（RAM代表） |
|:---|:---|:---|
| 巡航速度 | 100 km/h | 180 km/h |
| 电池质量 | 180 kg | 200 kg |
| 悬停效率 η_H | 0.70 | 0.70 |
| 巡航效率 η_c | 0.50 | 0.50 |
| 升阻比 L/D | **4**（无机翼，低效巡航） | **9**（固定翼，高效巡航） |
| 适用场景 | 城市短途 <50km | 区域长途 <300km |

## 量化结果

### 时间节省

| 场景 | vs 汽车 | vs 公共交通/火车 |
|:---|:---|:---|
| UAM（8条航线，1.9-29km） | **-23 min** | -22 min |
| RAM（8条航线，69-240km） | **-76 min** | -69 min（巴黎-加来 >100min） |

> ⚠️ 纯飞行时间，未扣除安检/登机/垂直起降场接驳时间。

### CO₂排放全景对比

| 对比基准 | UAM 多旋翼（城市） | RAM 升力+巡航（区域） | 判断 |
|:---|:---|:---|:---|
| vs 纯电动汽车 | **+388%** | +67% | ❌ 不如EV |
| vs 汽油车 | +123% | **-47%** | RAM优于燃油车 |
| vs 柴油车 | +129% | **-44%** | RAM优于燃油车 |
| vs 混合动力车 | +209% | **-10%** | RAM略优 |
| vs 传统直升机 | **-47%** | **-77%** | ✅ 大幅减排 |
| vs 公共交通/电动火车 | +160%（2.6倍） | +97%（1.97倍） | ❌ 远不如轨道 |

### 典型案例：巴黎→戴高乐机场（28.94km）

| 交通方式 | 人均CO₂排放 |
|:---|:---|
| 纯电动汽车 | **1.15 kg** ← 最优 |
| 混合动力车 | 2.14 kg |
| 柴油车 | 3.45 kg |
| 汽油车 | 3.62 kg |
| **多旋翼eVTOL** | **4.19 kg** ← 最高 |

## 讨论与局限

1. **全流程时间**：纯飞行时间节省会被安检/接驳/登机时间侵蚀，实际门到门节省可能大幅缩水
2. **全生命周期（LCA）缺失**：仅计算运行阶段能耗，未含制造/电池回收/基建碳足迹
3. **冬季能耗冗余**：基于10°C理想条件，冬季防冰/除霜/备降电量将显著推高能耗
4. **电网结构决定绿色程度**：法国本地57 g/kWh（核电为主）将大幅改善eVTOL排放表现——**电力来源是eVTOL可持续性的核心变量**
5. **土地占用与噪声**：垂直起降场占地、低空噪声污染尚未纳入评估

## 子课题3 启示

| 维度 | 巴黎发现 | 对容量评估的启示 |
|:---|:---|:---|
| **能耗-航程非线性** | 悬停阶段能耗极高→短途效率极差；巡航阶段机翼升力→长途效率逆转 | 容量模型需区分**短途/长途走廊**——短途走廊的能耗折减因子显著高于长途 |
| **碳排放→可持续性约束** | 电网碳排放强度直接影响eVTOL间接排放→公众接受度→政策许可 | 新增折减维度：**f_sustainability = f(grid_carbon, route_length, aircraft_type)** |
| **机型-任务匹配** | 多旋翼适合<50km但高排放，升力+巡航适合50-300km且低碳 | 不同空域走廊应指定最优机型类型——机型-走廊错配将导致容量浪费 |
| **电网敏感性** | 法国57 vs 欧洲226 vs 德国508 g/kWh——排放差异可达9倍 | 容量模型的可持续性约束参数需**按区域电网定制** |
| **替代直升机场景** | eVTOL替代直升机：47-77%减排——这是最确定的绿色用例 | 优先在现有直升机走廊部署eVTOL——减排效益最大、容量增量最可控 |

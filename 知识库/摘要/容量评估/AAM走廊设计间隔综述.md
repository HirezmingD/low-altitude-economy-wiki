# AAM走廊设计与间隔定义系统综述

> IEEE Access, 2025 | PRISMA 2020方法论 | 2039篇→62篇入选

## 一文总结

按PRISMA 2020标准执行的AAM走廊设计与安全间隔定义系统综述。覆盖16国62篇论文，识别三大研究维度：①走廊设计的影响因素（技术/环境/社会），②间隔距离定义，③定量方法论。核心发现：仅1/4论文研究间隔定义，缺乏整合框架；现有间隔沿用民航标准过于保守→制约高密度AAM运行。

## 三大研究问题

| RQ | 问题 |
|----|------|
| RQ1 | 城市环境下哪些技术/环境/社会因素影响AAM走廊设计？ |
| RQ2 | 哪些因素影响eVTOL间隔距离定义？ |
| RQ3 | 定量方法论如何定义安全间隔？ |

## 方法论

- 数据库：IEEE Xplore + Web of Science
- 初始检索：2039篇 → 去重1949 → 标题摘要筛选175 → 全文筛选62篇
- 时间范围：2010-2024

## 关键发现

| 发现 | 含义 |
|------|------|
| 美国30篇(48%)领先，韩国11篇 | 地理分布不均衡 |
| 2023年论文高峰，中国2023年后活跃 | 研究热度持续上升 |
| 走廊设计+运行占3/4 | 间隔定义仅1/4→研究不足 |
| 现有间隔沿用民航标准 | 过于保守→制约高密度 |
| 缺乏整合框架 | 零散研究，未统一 |

## 研究空白

1. 整合框架缺失：vertiport-走廊-运行-间隔未统一
2. 间隔定义不足：多沿用传统民航标准
3. 动态容量对齐：飞行需求与可用容量的动态匹配策略不足

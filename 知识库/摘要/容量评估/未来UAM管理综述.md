# 未来城市空中交通管理研究综述

> 张洪海、邹依原、张启钱、刘皞（南京航空航天大学），航空学报，2021，42(7)

## 一文总结

从UAM发展历程、运行概念设计、管理体系框架到空域规划/流量控制/交通服务/基础设施四维核心内容，系统综述了城市空中交通管理全貌。**容量评估**被定位为"空域规划"战略层的核心环节，Bulusu阈值法（冲突率相变→容量定义）和TU Delft空域结构-容量关系为子课题3承载力评估提供了技术锚点。

## 核心框架

### UAM四阶段发展

| 阶段 | 特征 | 空域融合 | 运行模式 |
|------|------|---------|---------|
| 兴起 | UAS/VTOL独立 | 120m/150m分层 | VLOS，试运营 |
| 初级 | 低密度BVLOS | 隔离空域，航路干线 | 低流量点对点 |
| 高级 | UAS/VTOL混合 | 管制空域融合 | 中等密度，AAV自主 |
| 成熟 | 全自主AAV | 高低空无缝衔接 | 高密度高流量动态网络 |

### 四维管理体系

```
空域规划（战略） ──→ 流量控制（战术/实时） ──→ 交通服务（微观）
        │                    │                      │
   空域划设              运行调度                航迹规划
   航路网络              终端排序                防撞避险
   容量评估 ←──────────── 容流平衡 ──────────→ 应急管理
        │
   基础设施（支撑）：Vertiport + CNS
```

## 容量评估核心（⭐⭐⭐ 直击子课题3）

### Bulusu阈值法（UC Berkeley，2017-2019）
- **定义**：容量 = 使空域评估指标发生**相变**的最小交通密度
- **指标演进**：
  - v1：多机冲突率（≥4机同时冲突概率）
  - v2：+危险接近率（安全）+成本增加量（效益）→ **安全可能是容量决定性因素**
  - v3：引入**吞吐量指标**→吞吐量比安全/效益更适合度量容量
- **关键实验**：合作类 vs 非合作类无人机 → 合作类提容+降低冲突解脱计算复杂度

### 空域结构-容量关系（TU Delft Metropolis）
- **四种空域**：自由（Full Mix）、分层（Layers）、扇形（Zones）、管道（Tubes）
- **结论**：**分层空域最优**（安全+效率+噪声综合）
- **Geovectoring**（向量围栏）：限制相对飞行速度 → 降低复杂性 → 提升容量
- **Geocaging**（禁止飞出围栏）vs Geofencing：前者鲁棒性更强、容量更大

### 其他方法
- **NASA**：Sky-lane/Sky-tube/Sky-corridor + 空中红绿灯 + Elevators螺旋电梯
- **KAIST**：地形图（三维可用空间）+ 骨架图（连通性）→ 拓扑容量分析框架
- **南洋理工**：AirMatrix/Over-buildings/Over-roads三种航路网络+吞吐量比较

## 流量控制（实时范式）

区别于传统ATM以先期流量管理为主，UAM应**以实时流量控制为主**：
- 类比地面交通信号控制 → 航路网络节点自适应调控
- 方法：分层深度强化学习（ISU自动间隔排序）、流体排队模型（Purdue拥堵控制）、多物网络流（GT空中出租车调度）
- NASA AutoResolver：持续轨迹管理 → 短计划周期=空中延误，长计划周期=地面延误

## 中国三级管理体系

1. **国家信息管理系统**（民航局/空管局）：全国空域信息/飞行计划汇总
2. **区域信息集成系统**（地区空管局）：跨城市协调/移交
3. **城市UAM系统**（空管分局+交通局+公安局）：终端服务管理

# 空域拥堵、流量关系与4D基本图

> Mahmassani等（Northwestern University），Transportation Research Part C, 2023
> DOI: 10.1016/j.trc.2023.104467 | IF=8.4

## 一文总结

将地面交通流理论的**基本图（fundamental diagram）**首次系统引入AAM空域——建立密度→冲突→速度下降→流量先增后减的完整宏观交通流模型。推导出速度-密度曲线（非线性格林希尔兹）和流量-密度基本图，识别**临界密度=空域容量**。仿真验证了间距要求和最大速度对容量的影响。

## 三大核心概念链

```
密度(k) → 冲突(C) → 实际速度(v)↓ → 有效速度(e)↓ → 流量(Q)↓
  │           │              │
  └─幂律关系──┘    ┌─速度损失/b──┘
                   │
              Q = k·e → 基本图→ 临界密度=容量
```

## 核心公式

### 气体定律冲突预测
```
C = (√2/2) · v · D_sep · k² · T · Vol
```
冲突数∝密度²（幂律，非线性的关键）

### 速度-密度关系
```
v(k) = v_max / (1 + √2 · b · D_sep · k · T)
```
曲线关系——低密度速度稳定，高密度加速下降

### 有效流量-密度基本图
```
Q_e(k) = k·e_max - √2·a·D_sep·v·k²·T
```
抛物线→临界密度处Q最大→过载后流量崩溃

## 基本图揭示

| 区域 | 描述 | 特征 |
|------|------|------|
| 自由流 | 低k，冲突少 | Q∝k |
| 过渡区 | 中k，冲突增加 | Q增长放缓 |
| **临界密度** | **Q_max** | **= 空域容量** |
| 拥堵区 | 超临界，流量崩溃 | Q下降 |

## 关键参数影响

| 参数 | 对容量的影响 |
|------|:----------:|
| 间距要求↓ | 容量↑↑（减少冲突→保持高速） |
| 最大速度↑ | 容量↑但临界密度↓（高速=高冲突率） |
| 速度损失/b↑ | 容量↓（每次冲突代价更大） |

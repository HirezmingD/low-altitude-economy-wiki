# 摘要：低空航路运行安全能力评估规范（T/GITIF 028-2025，征求意见稿）

## 背景
国内首个覆盖空域、地理、通信、导航、监视、电磁、气象、反制全维度的低空航路综合评估团体标准，广东省低空经济产业发展有限公司提出，2025年立项，目前为征求意见稿。

## 核心发现
- 构建了**8类基础静态 + 1类动态气象**共76项二级指标的完整评估体系
- 采用"基础分值 + 动态气象修正"的两级加权打分模型
- 四级安全分级：A(≥80)正常飞行 / B(70-79)限制飞行 / C(60-69)谨慎飞行 / D(<60)不建议
- 明确四类评估场景：规划预评、开通前全评、月度核查、年度复评
- 定义标准化飞行测试法（标准速度40-60km/h、环境条件要求）
- 评价结果可直接用于航路容量测算和动态流量调节

## 与知识库的关联
- 与课题**子课题3（容量评估）** 直接相关
- 空域环境/地理环境指标可作为容量评估模型的输入参数
- 综合评估方法可借鉴用于容量建模（静态基准+动态修正）
- 与[低空航路安全评估指标体系](/知识库/概念/容量评估/低空航路安全评估指标体系.md)和[低空航路安全综合评估方法](/知识库/技术/容量建模/低空航路安全综合评估方法.md)构成互补体系

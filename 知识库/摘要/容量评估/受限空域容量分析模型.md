# 受限城市空域容量：影响因素、分析建模与仿真

> Ellerbroek, Knoop (TU Delft), Transportation Research Part C, 2023
> DOI: 10.1016/j.trc.2023.104173 | IF=8.4 | 使用BlueSky仿真器

## 一文总结

首次建立**受限城市空域容量的分析模型**——借鉴地面交通MFD（宏观基本图），针对正交网格航路网络，推导交叉口吞吐量上界（S∥=Sh, S+=Sh√2），建模排队延迟与交通流崩溃条件。使用TU Delft自家**BlueSky ATM仿真器**验证。巴黎2035年预测：6万+无人机同时运行。

## 从冲突到排队——核心逻辑

```
受限空域（沿道路/水道单向飞行）
    ↓ 速度冲突解脱（无法水平绕行）
交叉口瓶颈 → 同源流间隔S∥/异源流间隔S+
    ↓ 流量超饱和
上游排队 → 延迟累积 → MFD崩溃
```

## 交叉口容量模型

| 参数 | 含义 | 公式 |
|------|------|------|
| S∠ | 任意角度的冲突自由距离 | Sh / cos(|Δψ|/2) |
| S∥ | 同上游支流的间隔 | Sh |
| S+ | 不同上游支流（正交）间隔 | Sh·√2 |

**假设1**：交叉口上游来源交替越少→吞吐量越大

## 分析模型输出

- 流量-密度关系（MFD适应版）
- 自由流区→临界密度点→容量
- 关注自由流+临界点（拥堵区假设可通过流入调控避免）

## 关键影响因素

| 因素 | 容量影响 |
|------|:------:|
| 水平间隔Sh | Sh↓→容量↑ |
| 正交 vs 平行流 | 正交需要更大间隔(S+>S∥) |
| 转弯交通 | 降低容量（后方需扩大S+间隔） |
| 来源交替频率 | 交替越少容量越高 |
| 航路单向化 | 对向冲突不可解→必须单向 |

## BlueSky仿真验证

使用BlueSky ATM仿真器（TU Delft开发的开源空管仿真平台），在正交网格网络上验证分析模型精度。

# CNN-ConvLSTM空域复杂度预测

> ⭐ 核心方向 — 子课题3「空域资源承载力评价」

## 来源

张云景, 王昊, 杨明辉 (2026). 基于CNN-ConvLSTM的城市低空空域复杂度建模与预测. 系统仿真学报.

## 核心命题

城市低空两类飞行器并发——SPV（物流无人机，120-300m，~15m/s）与HPV（载客eVTOL，300-1000m，~28m/s）——在高度边界存在跨层交互冲突风险。本文提出SHC（分层异构复杂度）预测框架，60s历史→180s预测，R²=0.870。

## 方法架构

### 三大量化指标

| 分量 | 核心逻辑 |
|------|---------|
| 层内密度 D | 网格飞行器数/历史最大值 |
| 冲突意图 I | Σ sin²(θ/2) / C(N,2)，速度夹角越大越危险 |
| 航向熵 H | -Σ p_k log p_k / log 8，航向越散越复杂 |
| **跨层交互 C_cross** | α√(D_spv·D_hpv)·(Δv/v_max)^β，两层密度×速度差 |

### CNN-ConvLSTM模型

```
12帧×50×50×8(60s历史)
    ↓ CNN空间编码 (8→64ch, 50→25)
    ↓ ConvLSTM时序建模 (单层, hidden=64)
    ↓ 未来预测器 (H12→36帧投影)
    ↓ CNN解码 (25→50, 64→3ch)
36帧×50×50×3 (C_spv, C_hpv, C_cross, 180s)
```

### 核心性能

| 指标 | 全格 | 非零格 |
|------|------|--------|
| MAE | 0.0045 | 0.0196 |
| R² | **0.870** | **0.838** |
| 推理延迟 | 26.1ms | — |

### 消融实验发现

1. **ConvLSTM最关键**：去掉后R²从0.809→0.570
2. **分层输出优于单通道**：三通道→单通道 R²降0.187
3. **航向通道不可替代**：去掉后R²→0.421
4. **残差学习失效**：高动态场景直接预测优于残差（R²为负）

### 鲁棒性
- 20%随机缺失 R²≥0.778
- 15×15矩形遮蔽 R²=0.783
- **假阴性率仅2.48%**（高风险漏报极低）

## 局限性

- BlueSky仿真数据，未验证真实ADS-B泛化能力
- C_cross预测精度偏低(R²=0.645)
- 验证集兼做测试集，泛化性能可能被高估

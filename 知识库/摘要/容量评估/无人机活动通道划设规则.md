# 城市区域低空空域无人机活动通道划设规则与方法

> 白龙、路紫、杜欣儒、郜方（河北师范大学），地球科学进展，2016, 31(11)
> 基金：NSFC 41671121"数据通信支持的空域资源配置模型与机制"

## 一文总结

提出城市区域低空空域无人机活动通道划设的三类规则（高度—密度、覆盖区、隔离区）及方法演进路径（3D城市模型→最优函数地图Cost-to-go），为低空航路规划提供早期规则框架。与子课题3在"航路约束容量"维度相关。

## 三类通道划设规则

| 规则 | 定义 | 与容量关系 |
|------|------|:--:|
| **高度—密度** | 不同高度层最大无人机密度限制（152m以下/152-1000m/1000m以上） | ⭐ 密度上限=容量约束 |
| **覆盖区** | "可用可降"层状空域，批准使用的特殊区域 | 可降落区容量 |
| **隔离区** | FAA全局禁飞区 + 地方城市特定禁飞区 | 限制区削减可用容量 |

## 方法演进

```
3D城市模型（障碍栅格图）
    ↓ 0栅格=可飞, 1栅格=规避
最优函数地图（Cost-to-go）
    ↓ 最小空间成本为目标
最优活动通道选择
```

## 无人机活动四类需求
1. 交通流实时监测——随车队移动
2. 新闻采集——突发性、临时区域
3. 环境监测——固定路线、时空固定
4. 急件快投——最复杂，需住宅区缓冲区

## 与子课题3关联

高度—密度规则中"不同高度层最大密度"直接对应容量上限；3D障碍栅格法是空域网格化的早期雏形。比廖小罕航路早一年，可视为通道划设规则的前驱。

# 物流无人机进场航线设计与容量评估

> 赵嶷飞、袁一凡（中国民航大学空管学院），飞行力学，2024(4)

## 一文总结

提出小型多旋翼城市物流无人机**进场航线参数化设计模型+容量评估方法**。选用同心圆环"等待圈+等待点"方式，混合整数规划最大化等待点数量，以平均等待时间Tw≤180s为阈值判定容量。**深圳星河商圈实例：容量=93架次/15分钟**（4等待圈，34个等待点）。

## 四种进场方式

| 方式 | 容量 | 能耗 | 适用场景 |
|------|:---:|:---:|------|
| 水平进场垂直下降 | 极低 | 低 | 小流量 |
| 沿斜线进近 | 低 | 最低 | 中流量 |
| **等待圈+等待点** | **高** | **中（悬停待机）** | **大流量** ✓ |
| 环型结构运行 | 高 | 高（绕圈飞行） | 大流量 |

本文选第3种。

## 参数化设计模型

**决策变量**：等待圈半径ri、高度hi、等待点数量ni、进近角度α
**约束**：横向间隔dx≥20m、纵向间隔dy≥20m、最大可用范围MSD
**目标**：max Σni（最大化总等待点数量）

```
MSD = Dcontrol - Dbuffer
     = 控制障碍物距离 - 缓冲余度
```

缓冲余度 = max(风场20m, 噪声6.35m, 隐私水平20m/垂直10m, 位置误差5m) = 20m

## 容量评估模型 ⭐

**容量定义**：单位时间内可容纳进场降落的最大无人机数量

**方法**：
1. 泊松流生成进场序列
2. 仿真飞行（顺序向内移动规则）
3. 计算系统平均等待时间Tw
4. Tw ≤ 180s → 判定容量

## 深圳星河商圈实例

| 参数 | 取值 |
|------|------|
| MSD | 44.88m |
| 等待圈数 | 4 |
| 总等待点 | 34 |
| 进近角度α | 60° |
| 容量 | **93架次/15分钟** |

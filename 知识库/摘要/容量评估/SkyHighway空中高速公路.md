# Sky Highway：低空异构VTOL空中高速公路

> Quan Quan（全权/北航）, Jack Haddad (Technion), Transportation Research Part C, 2026
> DOI: 10.1016/j.trc.2026.105531 | IF=8.4

## 一文总结

提出**Sky Highway**——融合分层+管状拓扑的低空结构化空域：多层空域(异构飞行器分层隔离)，每层为类道路网的管状拓扑(双向多车道航路+三类交叉口+3D环岛)。配套混合集中-分布式控制协议(safety area+avoidance area双层安全模型)，支持拥堵交通流宏观评估。

## 空域结构设计

```
┌─────────────────────────────────┐
│ Layer M: PAV/UAM (高速载人)      │  ← 各层独立网络
│ Layer 2: 中型货运无人机          │
│ Layer 1: 小型多旋翼 (<120m)      │
└─────────────────────────────────┘
每层内：
  航路(Airways) ↔ 交叉口(Intersections)
  多车道(按速度分级) ↔ 双向通行
```

## 四类网络元素

| 元素 | 设计 | 功能 |
|------|------|------|
| **航路** | 双向多车道管状 | 主干通行 |
| **连接交叉口** | 弧形转弯段 | 方向转换 |
| **枢纽交叉口** | 3D环岛(roundabout) | 多方向汇流 |
| **边界交叉口** | FIFO规则 | 接入vertiport |

## 五条基本设计要求

1. 每架航空器从边界交叉口到另一边界交叉口各有指定路线
2. 高度和方位不同时改变（纵向+横向分离控制）
3. 安全距离≥2r_s（安全区不重叠）
4. 不飞出航路/交叉口边界
5. 不同速度和优先级

## 安全模型：双层防护

```
安全区 (r_s)：禁止入侵
回避区 (r_a > r_s)：触发避让控制

冲突定义：i进入j的回避区 且 i的安全区无法保持
```

## 混合集中-分布式控制

- **集中式**：全局路由分配、流量管理
- **分布式**：机载避让（回避区触发）、速度调节
- 兼具安全(集中式全局优化)+可扩展(分布式局部响应)

## 宏观交通流评估

基于空域基本图(MFD)测量：密度/速度/流量/冲突率→评估不同设计方案的性能

## 与子课题3关联

- 结构化空域→冲突可预测→容量可计算
- 分层隔离→异构航空器干扰最小→有效容量最大化
- MFD测量→直接支撑承载力定量评估

# 迪拜空中出租车：Joby × RTA（巴克豪斯低空经济研究院，2026）

> 源文件：`原始素材/文章/Joby Aviation 与迪拜 RTA 独家合作项目深度研究报告 —— 中东首个规模化城市空中出租车产业落地案例分析.md`
> 作者：巴克豪斯低空经济研究院
> 来源：巴克豪斯低空经济（微信公众号），2026-06-29
> 事件基准：2025年11月 Joby Aviation × 迪拜RTA 6年独家战略合作

## 核心定位

全球首个**长周期独家、全域规模化、纯商业化**城市空中出租车项目。2025年11月Joby Aviation与迪拜RTA达成6年独家排他合作——政府出让市场权益+配套公共资源，企业投入技术+设备+运营体系——构建"企业技术运营+政府资源配套"的标准化政企合作范式，为全球跨国低空产业合作提供可复制范本。

## 四大板块

### 一、核心事件：阿联酋首次跨城载人eVTOL试飞（2025.11）

| 要素 | 详情 |
|:---|:---|
| **试飞路线** | 玛格姆试飞场→阿勒马克图姆国际机场 |
| **飞行时长** | ★ **17 分钟**（地面通勤40-70分钟→效率**3×+**） |
| **执行标准** | 完全按商业化运营标准——地面核验→垂直起飞→低空巡航→定点降落→落地复核 |
| **安全核验** | 五大维度（硬件/飞控/空域/乘客/环保）→全周期→**一票否决制** |
| **试飞结果** | 全部指标达标→零安全隐患/零设备故障/零环保超标→RTA出具官方试飞成果认定 |

### 二、网络规划：三大垂直起降场 + 点对点直飞

| 场站 | 定位 | 服务人群 |
|:---|:---|:---|
| **迪拜购物中心** | ★ 城市核心枢纽——多机位+维保+充电+高端候机 | 国际商务商旅（核心客流+营收） |
| **皇家亚特兰蒂斯酒店** | 文旅特色枢纽——轻量化/体验型出行 | 全球高端度假游客 |
| **迪拜大学** | 民生通勤节点——简化配套+平价通勤 | 外籍师生+本地居民 |

> 航线体系：①三大场站↔机场（长途通勤·核心盈利）+ ②场站两两互通（市内短途·补充客流）。三站均配地面轻轨/出租车/公交接驳——"空地一体化"闭环。

### 三、6年独家协议：政企权责+收益共享

| 条款 | 内容 |
|:---|:---|
| **排他范围** | 仅限载人eVTOL空中出租车——货运/观光/直升机不设限 |
| **政府权责** | 土地审批+空域划分+安全监管+地面接驳配套+城市品牌宣传 |
| **企业权责** | 飞行器交付+场站建设+运维调度+票务运营+客户服务 |
| **收益分配** | 票务收益按比例划分→企业运营迭代+城市低空基建升级 |
| **绿色约束** | 全电动零排放+持续噪音管控达标 |
| **退出/续约** | 重大安全事故/环保不达标→RTA单方终止；6年期满综合评估协商续约 |

### 四、Joby机型：长航程+零排放+高温适配

| 参数 | 数据 |
|:---|:---|
| 最高时速 | **322 km/h**——行业领先 |
| 最大航程 | **161 km**——机场→市区单程直达/无需中途充电 |
| 动力 | 全电动零排放+分布式多冗余——人口密集区高安全性 |
| 气候适配 | 已适配中东高温干燥——无需大规模硬件改造 |

## 三大战略意义

| 维度 | 意义 |
|:---|:---|
| **全球产业** | 打破"重试点、轻商业"困境——首次证明全域规模化空中出租车商业可行性 |
| **区域格局** | 中东取代欧美成为全球低空商业化最优落地沃土——资本/政策/市场/战略四维支撑 |
| **合作范式** | "长周期独家授权+政企权责清晰+资源深度绑定+商业闭环完整"——全球跨国低空合作标准化范本 |

## 四维风险

| 风险 | 具体内容 |
|:---|:---|
| **工期** | 场站基建+设备调试+空域审批→可能影响2026年底节点 |
| **空域** | 常态化大规模飞行→流量管控+特殊天气+多机调度 |
| **市场** | 高端票价→客流不及预期→市场接受度培育周期 |
| **政策** | 长期监管规则调整→现有运营模式受影响 |

| 维度 | 关联点 |
|:---|:---|
| **点对点图论拓扑** | 4节点6边极简图→$G(V,E)$——可直接参数化为ST-GNN最小验证集 |

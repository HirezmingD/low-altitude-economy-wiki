# 深圳低空经济示范（智荟月刊，2026）
> 源文件：`原始素材/文章/智荟月刊丨深圳探路：三维天空解锁万亿新版图.md`
> 作者：张李源清、张孔娟
> 来源：中国经济时报，2026-01-21，第14363期（A06版·实践案例）
> ★ 智荟月刊专题第三篇——与王小霞（全国宏观）、姚俊臣（福州实证）同期同版
## 核心定位
深圳以"先行先试"特区优势，构建**空域改革+政策标准+场景落地**三轮驱动的全产业链特区模式，是国内低空经济制度化、标准化、产业化程度最高的城市级标杆。
## 三大板块
### 一、空域改革：SILAS + 融合空域示范基地
| 要素 | 详情 |
|:---|:---|
| **融合空域示范基地** | 东部通航低空融合飞行示范基地（盐田），2025.04.15 动工——**全国首个**融合空域运行示范基地 |
| **SILAS 系统** | 低空智能融合基础设施系统——实现"飞行计划申报→空域智能划拨→AI风险判别"**全流程闭环管理** |
| **空域网络** | 初步划设 **309 个**低空管制空域，覆盖物流、文旅、通勤、巡检等场景的精密空域网络 |
| **定位** | 粤港澳大湾区核心引擎、国际国内双循环低空应用枢纽 |
### 二、政策标准：20亿基金 + 30+标准
| 要素 | 详情 |
|:---|:---|
| **专家委员会** | 2023.05 成立深圳市低空经济专家委员会——汇聚空管/研发/运营/法规/政策全国顶级专家 |
| **产业基金** | 2023 年设立总规模 **20 亿元**低空经济产业基金，单项奖励最高 **2000 万元** |
| **标准委员会** | 2024 年成立**全国首个城市级低空经济标准化技术委员会**，启动 **30+ 项**地方标准立项 |
| **基建方案** | 《低空基础设施高质量建设方案（2024-2026）》——2026 年底建成 **≥1200 个**低空起降点 |
| **远期规划** | 《低空起降设施布局规划（2026-2035）》——远景支撑 **1500+** 起降点科学布局 |
### 三、场景落地：eVTOL首飞 + 枢纽示范区
| 要素 | 详情 |
|:---|:---|
| **eVTOL 首飞** | 国内首条 eVTOL 跨城跨湾航线"深圳蛇口—珠海九洲港"成功首飞（2024） |
| **前海枢纽** | 建设**国内首个**低空立体综合交通枢纽先导示范区 |
| **盐田枢纽** | 探索"即时响应+无人机配送+快速送达"高效模式——全国首个空港协同低空集散枢纽 |
| **应急救援** | 低空应急救援、低空文旅等多元场景同步拓展 |
## 量化目标（2026 年底）
| 指标 | 目标值 |
|:---|:---|
| 低空产业产值 | **突破 1300 亿元** |
| 低空起降点 | **≥1200 个** |
| 商业航线 | **≥1000 条** |
| 地方标准 | **30+ 项** |

# 新加坡UTM系统：TopSky-AstraUTM（Thales，2026）

> 源文件：`Clippings/Thales to build Singapore's drone traffic management platform.md`
> 来源：Thales Group Press Release，2026-05-26
> ★ 原始为英中双语新闻稿

## 核心定位

全球城市密集型治理的**数字化UTM标杆**——CAAS携手Thales（全球航空UTM领导者）+Deeeplabs（新加坡本地技术商），部署基于TopSky-AstraUTM的国家级无人机交通管理系统。733km²/570万人口/多机场终端区重叠的极端约束下，以**全国统一一站式平台**实现所有UA运行的安全可扩展管理。★ 全球-本地联合体模式为低空技术跨国输出提供范本。

## 五大板块

### 一、合同核心

| 要素 | 详情 |
|:---|:---|
| **签约方** | CAAS → Thales（牵头）+ Deeeplabs联合体 |
| **平台** | ★ Thales TopSky - AstraUTM |
| **时间** | 2026.05.26 |
| **交付** | 国家级UTM系统——一站式集成门户 |

### 二、平台功能

| 功能 | 内容 |
|:---|:---|
| **统一注册** | 运营商+无人机电子身份——单一入口 |
| **数字飞行计划与授权** | 在线提交→自动审核→数字授权——★缩短审批时间 |
| **实时运行监控** | 全空域UA运行态势感知+自动化协调 |
| **全生命周期** | 注册→计划→授权→监控→数据——端到端闭环 |

| 场景 | 说明 |

| **海事作业** | ★ 全球最繁忙港口之一的无人机海事应用 |
| **应急响应** | 快速到达+实时监控 |
| **城市交通** | 未来UAM集成 |

| **Deeeplabs**（本地） | 部署落地+运营服务+本地工程能力→新加坡本地技术提供商 |

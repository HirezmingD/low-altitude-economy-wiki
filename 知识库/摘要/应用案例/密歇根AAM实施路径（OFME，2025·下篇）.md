# 密歇根AAM实施路径——六大战略·12项目·指标体系（OFME 2025年度报告·下篇）

> 本文译自 Michigan OFME《2025年度AAM倡议报告》下篇。与案例①（战略图景）形成"战略→实施"完整链条。陈晓燕 文，钟子祺、陈晓燕、钱峰 译，格言 校核，2026.05.12 发布。

## 核心定位

本素材是密歇根AAM战略的**实施层**——六大战略支柱的具体项目进展、运营数据、和成效指标体系。与案例①的"为什么做"形成互补，本素材聚焦"怎么做"。

## 六大战略实施详情

### 战略1：提升基础设施与部署能力——12个项目

| # | 项目 | 关键数据 | 亮点 |
|:---|:---|:---|:---|
| 1 | **AAIR先进空中创新区** | $245万，600+次货运试飞（Aerialoop），1英里BVLOS航线 | 沿铁路走廊城市真实环境BVLOS |
| 2 | **船到岸无人机配送** | $512,168，3次概念验证，五大湖Interlake Steamships | 减少停泊船只排放+优化海上物流 |
| 3 | **BETA电动航空器充电网络** | $260万，4机场（TVC/LAN/BIV/YIP），<1h充满 | 密歇根首台电动航空器充电设备，UL认证Charge Cube |
| 4 | **2025无人系统三域挑战赛（UTC）** | 水/陆/空三域自主运输，空中58.5英里+陆地23.5英里+水面5海里 | **SiFly在UTC打破世界纪录** |
| 5 | **NADWC无人机系统走廊** | $395万，60英里（格雷林→阿尔皮纳），Thales传感器（雷达+ADS-B+UTM），4000ft | 军民两用BVLOS走廊 |
| 6 | **MDOT通信网状网** | DSRC+C-V2X测试，兰辛+底特律 | 证实支持BVLOS+C5ISR |
| 7 | **DSPL屋顶无人机测试空间** | $150万（EDA GEM资助），AAIR+交通创新区协同 | 停车实验室→AAM创新枢纽 |
| 8 | **M-air大学走廊** | $100万，40英里（安娜堡→底特律），配备UTM | 真实城市环境AAM测试 |
| 9 | **奇普瓦县运营中心** | ANRA Technologies，上半岛边境 | 跨境贸易+安全+基建监测 |
| 10 | **FLITE第八轮** | 5家公司，机场场景 | 自主野生动植物驱避/AI基建监测 |
| 11 | **无人机网络安全挑战赛** | 第二届，格雷林营 | 大学生+行业专家，第三届2026.06 |
| 12 | **（隐含）网络无人机挑战赛** | 国防+公共安全双场景 | ODAI牵头 |

### ★ SiFly世界纪录

| 指标 | 旧极限 | 新纪录 | 提升 |
|:---|:---|:---|:---|
| 航程 | 11英里 | **26英里** | ×2.3 |
| 续航 | 30分钟 | **3小时** | ×6 |
| 有效载荷 | 2磅 | **10磅** | ×5 |

> 意义：直升机级性能+无人机级成本，重新定义行业能力边界，对中国无人机主导地位构成挑战。

### 战略2：激活生产能力

| 项目 | 关键内容 |
|:---|:---|
| **"成就密歇根"原型制造资助** | $82.8万(2024,17家)→**$200万**(2025,27家)，AAM企业占比提升 |
| **ASIC自主系统行业联盟** | 2025.06成立——加速无人机从概念→演示→部署→生产 |

| **密歇根制造商中心** | 2025.06上线——零部件采购+联合开发+制造技术整合 |
| **AAM制造商网络** | 封闭测试中→2026.01全面开放 |
| **Birdstop总部迁址** | 硅谷→底特律，计划雇用数百人 |

### 战略3：推动公共部门应用于商业市场——6大项目

| 项目 | 关键数据 | 意义 |
|:---|:---|:---|
| **全州出行挑战赛** | 5州级机构（MSP/DNR/MDOT/EGLE/MDARD），2025.09-2026.04 | 公共需求→商业部署 |
| **CVS Health医疗配送** | ★ $150万——**首个州政府资助CVS无人机项目** | 特效药品配送→高优先级航线 |
| **Jack Demmer Ford零部件配送** | $74万，12英里半径，DroneUp+Blueflite+Airspace Link | 汽车零部件B2B→制造物流 |
| **Traverse Connect医疗配送** | $68.9万(R1)+$95万(R2)，Munson Healthcare+DroneUp+blueflite | 农村医疗+水域测量+应急响应 |
| **Amazon Prime Air** | 2025.07庞蒂亚克→2025.11黑泽尔帕克，7.5英里半径 | 商业包裹→高密度需求 |
| **政策倡导（CFME）** | 两个行动小组→2026年形成可操作政策建议 | AAM制度演进 |

### 战略4：发展AAM劳动力——LEO调查核心发现

| 发现 | 数据 |
|:---|:---|
| 调查企业 | 36家 |
| **招聘困难** | **43%** |
| 三大障碍 | 缺乏本地技能(40%) + 缺乏行业经验(37%) + 缺乏技术技能(27%) |
| 紧缺岗位 | 项目经理(40%) + 电气工程师(30%) + 管理团队(27%) + 机械工程师(23%) |
| 最需培训 | 实习/合作教育(63%) + 在职培训(54%) + 招聘(46%) |

### 战略5：增进公众认知

- 全国性会议演讲+海岸警卫队搜救演示+"无人机送甜甜圈"（2.3英里，18岁认证学员操作）
- 媒体报道：安娜堡时报/桥接密歇根/标普全球/纽约时报

### 战略6：争取外部资金

- 协同争取FAA/EDA/USDOT联邦资金，与密歇根国会代表团合作

## 成效指标体系（六大战略KPI框架）

| 战略 | 核心KPI |
|:---|:---|
| 基础设施 | BVLOS走廊节点数、FAA 107.31豁免数/飞行里程、活跃测试场地数、垂直起降场数、国防资产部署次数 |
| 制造激活 | 新增AAM能力供应商数、净新增企业吸引数、撬动AAM投资总额 |
| 公共应用 | 州政府支持AAM部署数、公共/私营采购承诺数、促成收入、AAM政策法规数 |
| 劳动力 | AAM培训项目数、新增无人机认证数、新增Part 108运营人数 |
| 公众认知 | 公众宣传活动数、公共安全响应次数、AAM就业岗位总数 |
| 外部资金 | AAM资金及投资总额、获资助组织数 |

## 子课题3 启示

| 维度 | 启示 |
|:---|:---|
| **运营数据标定** | 600+次城市BVLOS飞行/26英里纪录/60英里走廊→为容量模型提供真实运营数据标定锚点 |
| **指标体系参照** | 六大战略KPI框架→直接对标子课题3的"评估-预警-调控"指标体系设计 |
| **产业驱动因子** | 原型制造17→27家增长率→制造产能→部署密度→空域需求的定量推导 |
| **多用户优先级** | 军事+商业+公共安全+跨境四类用户→需建立空域竞合模型 |
| **气候约束扩展** | 密歇根五大湖冬季运行（低温+结冰+能见度）→扩展f_climate至低温维度 |
| **劳动力供给侧** | 43%招聘困难→AAM增长受人才供给侧约束→部署速度→容量需求预测的不确定性 |

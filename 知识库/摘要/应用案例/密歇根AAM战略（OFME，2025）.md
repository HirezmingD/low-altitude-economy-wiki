# 密歇根州AAM战略图景（OFME 2025年度报告）

> 美国密歇根州未来出行与电气化办公室（OFME）2025年度AAM倡议报告。依托汽车制造+国防空域+跨境地理三大优势，提出2030七大愿景和六大战略支柱。钟子祺、陈晓燕、钱峰 译，格言 校核。

## 核心定位

密歇根正将自身打造为**美国AAM测试、部署与制造中心**，其战略定位为"制造驱动+国防锚定+跨境协同"三驱模式：

| 驱动维度 | 核心资产 | 竞争优势 |
|:---|:---|:---|
| **制造驱动** | 汽车供应链→无人机部件全覆盖 | 工程师密度全美第一，255K技工，高混合低批量敏捷制造能力 |
| **国防锚定** | 17,000平方英里军事空域（密西西比河以东最大） | "北部打击"演习含反UAS测试，蓝名单UAS平台制造 |
| **跨境协同** | 美加边境4条国际通道 | 跨境AAM走廊潜力，贸易/安全/应急响应 |

## 全球竞争格局

| 区域 | 关键动态 |
|:---|:---|
| **中国（深圳）** | ★ 占全球无人机市场~**80%**，1,700+家企业，年产值 >100亿美元 |
| 韩国 | Joby 2024首飞，2027年建40座垂直起降场 |
| 日本 | eVTOL制造商+大型企业合作，适航认证嵌入空域监管 |
| 新加坡 | 渐进式监管改革——放宽注册/数字号牌/简化空域放行 |
| 法国 | 公私协同，货运+应急服务AAM生态 |
| 德国 | 交通部资助真实世界测试实验室，2025垂直起降场部件开发 |
| 阿联酋 | GCAA投资eVTOL+无人机+垂直起降场+综合监管框架 |
| 沙特 | GACA与Archer合作，沙特-阿曼-卡塔尔UTM计划 |

> **地缘张力**：美国拟议对华零部件限制正在倒逼本土供应链加速形成。报告明确将中国（深圳80%份额）定位为竞争基准。

## 美国州级竞争

| 州 | 战略重点 | 关键投入 |
|:---|:---|:---|
| 俄亥俄 | 货运物流+区域出行+应急 | 1,000万美元国家AAM卓越中心，6,100万美元研究（35项目），目标2045年15K岗位+81垂直起降场 |
| 加利福尼亚 | 立法+试验+基础设施+财政工具 | SB800/AB431法案，CAEATFA税收减免吸引Archer/Joby/AIBOT |
| 得克萨斯 | 基础设施+公私合作+立法 | FAA 1.4亿美元先进航空技术中心（CAAT），Wisk+休斯敦机场垂直起降场 |

## 密歇根核心资产

### 测试网络（5大设施）

| 设施 | 地点 | 能力 |
|:---|:---|:---|
| **MUASC** | 阿尔皮纳 | UAS联盟+飞行测试中心，研发→制造一体化 |
| **FLITE** | 大急流城机场 | 全美最早机场场景AAM试点之一 |
| **Mcity/M-air** | 密歇根大学 | 32英亩城市/郊区模拟，1,740万美元/86+项目，向AAM扩展 |
| **DSPL** | 底特律 | 屋顶垂直起降场测试（原停车实验室→AAM扩展） |
| **AAIR** | 底特律中央创新区 | 真实商业无人机应用试点，BVLOS审批支持 |

### 国防资产

- 密歇根全域作战中心（NADWC）：**148,000英亩**训练区 + 17,000平方英里特殊用途空域
- "北部打击"（Northern Strike）：美国规模最大的后备役战备演习之一
- 四个支撑基地：格雷林营、阿尔皮纳、巴特尔克里克、塞尔弗里奇
- 含反UAS系统测试评估及网络空间行动

### 供应链映射

汽车供应商基础可直接映射至无人机三大类别关键部件：
- **轻型（<250g）**：碳纤维机体、小型无刷电机、ESC、LiPo电池、GPS/IMU
- **中型（250g-25kg）**：铝合金机体、RTK GPS、避障传感器、LiDAR、高分辨率相机
- **重型（>25kg）**：工业级铝材、冗余飞控、多组电池包/燃料电池、远距离加密通信

### 政策环境

| 政策 | 核心内容 |
|:---|:---|
| 2016年《无人驾驶航空系统法》 | 州级统一规则，**禁止地方自行制定UAS政策**→监管确定性高 |
| UAS工作组（2017报告） | 建议：清晰规则+联邦-州级UTM协同+地方教育外联 |
| 《航空法典》 | 航空委员会排他性审批权；商业运营仅限公共用途航空设施 |

## "TAKE-OFF" 2030愿景

1. **全美AAM测试与部署最密集的州**——跨境/城市/工业/对抗/GPS拒止全覆盖
2. **网络化UAS基础设施**——支撑长距离BVLOS运行，数据反哺联邦政策
3. **端到端供应链**——企业无需离州即可从原型→量产
4. **设计→生产周期全球最快**——测试与制造共址协同
5. **首创性全州级AAM市场建设政策**——公共需求汇聚→带动私营采用
6. **全美最具竞争力AAM人才供给**——可堆叠式认证与资质项目
7. **高增长无人机企业集聚度全球领先**——覆盖各发展阶段的资本机制

## 四类优先应用场景

| 场景 | 具体应用 | 子课题3关联 |
|:---|:---|:---|
| **自主物流** | 汽车零部件B2B、医疗物资、包裹配送 | 货运需求密度→容量基准 |
| **国防与国家安全** | 军民两用平台、DoD认证UAS、"蓝名单" | 军事空域用户→空域竞合模型 |
| **公共安全** | 第一响应、搜救、灾害、基建监测、交通安全 | 应急优先权→容量动态预留 |
| **农业技术** | 农药施用、播种、作物分析 | 农村低密度场景→容量下限标定 |

## 子课题3 启示

| 维度 | 密歇根贡献 | 对容量评估的启示 |
|:---|:---|:---|
| **州级治理层级** | 联邦/州/市三级AAM治理——州级统一规则+禁止地方碎片化 | 治理层级→空域管理粒度→容量建模的空间分辨率 |
| **BVLOS走廊标准化** | FAA批准的标准化BVLOS走廊——物理+数字+数据系统三统一 | 为走廊容量公式提供标准化参数（通信/导航/监视的州级规范） |
| **多用户空域竞合** | 军事训练+商业测试+公共安全+跨境——四类用户在17,000平方英里内共存 | 多用户优先级模型——军事/公共安全/商业的空域时间-空间分配 |
| **制造→部署密度** | 汽车供应链转型→无人机快速放量→空域需求密度激增 | 制造产能→飞行量增长→容量需求预测的产业驱动因子 |
| **跨境容量** | 美加边境4条通道→跨境AAM走廊 | 跨境空域协调→跨国境容量模型的制度变量 |

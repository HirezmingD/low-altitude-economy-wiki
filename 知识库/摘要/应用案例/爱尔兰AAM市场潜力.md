# 爱尔兰AAM市场潜力与FMCI实验（LAIR，2024）
> 源文件：`原始素材/文章/低空运营启示录｜爱尔兰城市空中交通市场潜力预测与初步实验案例.md`
> 来源：LAIR低空产研记录（微信公众号），2024-11-21
> 事件基准：2024年11月爱尔兰商业和通用航空协会会议发布EAM/FMCI联合研究
## 核心定位
全球首个**国家层面AAM市场潜力全量化预测**——EAM咨询公司为FMCI（爱尔兰未来交通园区）完成的宏观分析报告。174条UAM航线连接103个人口中心+50条RAM航线连接16个机场→目标市场7800万乘客/年→时间节省经济效益€1.92亿。FMCI同时提供实验验证基础设施：移动式无人机港口+4km开放试验台+数据中心+Skyports垂直起降枢纽——"定量预测+实验验证"双轮驱动。
## 五大板块
### 一、市场预测：从需求侧到航线网络的完整推导
| 要素 | UAM（城市空中交通） | RAM（区域空中交通） |
|:---|:---|:---|
| **航线数** | **174**条 | **50**条 |
| **节点数** | 103个人口中心 | 16个机场 |
| **目标市场** | 8900万游客/年 | ★ 7800万乘客/年 |
| **经济影响** | €9600万（时间节省） | ★ €1.92亿 |
| **飞行器类型** | eVTOL | 电动/混合动力固定翼 |
| **核心枢纽** | 都柏林74条/利默里克29条/科克27条 | 16个机场 |
> 每周为区域旅行者节省**111,500小时**。
### 二、爱尔兰优势：紧凑岛国+气候温和
| 优势 | 详情 |
|:---|:---|
| **紧凑国土** | 7万km²→平均航线短→eVTOL单程无需充电→周转率优势 |
| **气候温和** | 极寒/极热少→电池性能稳定→全年运行窗口长 |
| **出行痛点** | ★ **87%**出行由汽车完成→替代需求迫切+脱碳潜力巨大 |
| **机场网络** | 16个机场→可直接纳入区域AAM网络 |
### 三、FMCI实验基础设施
| 设施 | 功能 |
|:---|:---|
| **移动式无人机港口** | 模块化集装箱+无线电/通信设备→可扩展可移动 |
| **开放试验台** | ★ 4km公共道路网络（香农工业区）+光纤+多传感器+CCTV+高精度定位 |
| **数据中心+控制室** | 实时监控+数据驱动可视化分析 |
| **车间+实验室** | 企业入驻+高速宽带+面部识别门禁+硬件生产 |
| **★ Skyports垂起枢纽** | FMCI × Skyports——香农机场附近垂直起降枢纽 |
### 四、实施挑战
| 挑战 | 内容 |
|:---|:---|
| **基础设施** | 垂直起降场网络从零建设+电网容量升级 |
| **监管** | 低空空域管理框架+EASA标准+载人/无人航空整合（EALU-AER项目） |
| **岛国隔离** | 跨境AAM仅连接英国——外部网络扩展受限 |
### 五、方法论价值
> ★ 国家AAM市场预测可复制方法论：人口中心分布→OD出行数据→航线推导→经济影响量化→基础设施匹配——五步法为全球中小国家AAM规划提供模板。

## 子课题3 关联
| 维度 | 关联点 |
|:---|:---|
| **需求→容量推导链** | 市场规模→航线→乘客量→飞行密度→容量需求——完整经济学驱动推导 |
| **紧凑国土→短航程高周转** | $L_{avg}$短→$C_{throughput}$高——与新疆超大国土长航程形成对照 |

| **枢纽幂律分布→异质图** | 都柏林74条vs其他→无标度网络→枢纽瓶颈=系统容量瓶颈 |

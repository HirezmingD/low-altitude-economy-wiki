# 珠海低空基础设施规划（低空产研记录，2026）
> 源文件：`原始素材/文章/确定新增低空起降设施用地（S5）：一文读懂珠海低空基础设施规划管理工作的15条措施.md`
> 作者：低空产研记录
> 来源：微信公众号"低空产研记录"，2026-04-10
> 原文事件：珠海市自然资源局《关于优化规划管理支持低空经济高质量发展的若干措施（试行）》正式发布
## 核心定位
珠海在全国率先从**土地与规划管理制度**维度破解低空基础设施"落地难"问题。17条措施以**全国首个S5低空起降设施用地**为标志性制度创新，形成"规划统筹→用地保障→审批简化→场景应用→数据赋能"五维支撑体系，是低空基础设施规划管理的制度先行者。
## 五大板块
### 一、规划统筹：低空交通网络纳入国土空间规划
| 要素 | 详情 |
|:---|:---|
| **空间基础** | 强化国土空间规划统筹引领，奠定低空交通网络空间基础 |
| **规划指引** | 为各类低空建设主体提供规划建设指引 |
| **航线设计** | 支持企业结合市场需求科学设计运营航线 |
| **目标** | 保障全市低空经济规范有序发展 |
### 二、用地保障：土地要素"组合拳"
| 要素 | 详情 |
|:---|:---|
| **指标保障** | 用地指标规模优先保障低空经济建设项目 |
| **供应创新** | 土地供应方式优化创新 |
| **地价减免** | 企业增资扩产享受地价减免 |
| **效果** | 加大土地要素支撑 + 降低开发建设成本 +★ 激发市场活力 |
### 三、规划审批：★ S5地类 + 报建豁免 + 复合建设
| 要素 | 详情 | 意义 |
|:---|:---|:---|
| **S5 地类** | 率先增设"低空起降设施用地（S5）" | ★ **全国首个**——从源头保障设施落地 |
| **报建豁免清单** | 符合条件的设施设备免于规划报建 | 大幅提升审批效率 |
| **用地混合兼容** | 鼓励低空基础设施与其他地类混合使用 | 拓宽建设渠道 |
| **既有建筑附设** | 支持利用自有用地和既有建筑设置低空设施 | 降低空间门槛 |
| **塔杆资源复合** | 通信塔/灯杆/监控杆与起降点一体化建设 | 网络化分布式部署 |
### 四、场景应用："低空+"珠海特色
| 场景 | 详情 |
|:---|:---|
| **无人机配送住宅** | 结合低空经济应用场景，建设无人机配送试点住宅项目 |
| **无居民海岛** | 支持在无居民海岛因地制宜布局低空基础设施 |
| **自然资源领域** | 积极探索自然资源领域低空场景应用 |
### 五、数据赋能：实景三维数字空间底座
| 要素 | 详情 |
|:---|:---|
| **技术基础** | 实景三维赋能低空经济创新应用场景 |
| **核心能力** | 构建高精度、可分析的数字空间底座 |
| **服务对象** | 为企业在航线规划、飞行服务等方面提供地理信息服务保障 |
| **效果** | 提升飞行活动安全性与运行效率 |

## 珠海-深圳双城对照
| 维度 | 珠海 | 深圳 |
|:---|:---|:---|
| **制度创新方向** | 土地规划制度（S5地类+复合建设） | 特区立法+产业基金+标准体系 |
| **基础设施保障** | ★ 从用地分类制度源头解决 | 从专项规划+量化目标解决 |
| **核心平台** | 实景三维数字空间底座 | SILAS低空智能融合系统 |
| **特色场景** | 海岛+无人机配送住宅 | eVTOL跨城跨湾+应急救援 |
| **城市形态** | 海滨+海岛、中等密度 | 超高密度、陆海空三栖 |
| **制度定位** | 规划管理制度先行者 | 全产业链特区标杆 |
## 与子课题3 关联
| 维度 | 关联点 |
|:---|:---|
| **地面侧容量约束** | S5用地面积→垂直起降场密度→$C_{ground}$ 硬约束——容量模型需增加土地可用性维度 |
| **审批效率→容量释放速率** | 报建豁免清单→$\frac{dC}{dt}$ 加速——制度摩擦系数可量化为容量释放时间参数 |
| **复合建设→共享容量** | 独立S5 vs 复合建设的容量特征不同→$C_{dedicated}$ + $C_{shared}$ 双层建模 |
| **实景三维→环境数字模型** | 数字空间底座直接输入子课题3的低空环境数字模型 |
| **海岛场景→拓扑退化** | 节点稀疏+备降场有限→图连通性退化的极限容量测试场景 |

# 安徽低空经济示范（2025）

> 源文件：`原始素材/文章/低空版图  安徽，低空经济绘就江淮新图景- 中国航空新闻网.md`
> 作者：王兰，通讯员 胡琛璟
> 来源：中国航空新闻网，"低空产业大脑"，2025-07-31
> ★ "低空版图"系列——与新疆篇（2026.06.18）同系列姊妹篇

## 核心定位

安徽是长三角地区**唯一**全域低空空域管理改革试点省份，以 eVTOL 制造集群为核心驱动，基础设施先行，多场景规模化落地，形成**制造驱动型**省级低空经济模式。

## 五大板块

### 一、基础设施

| 要素 | 详情 |
|:---|:---|
| 机场体系 | "运输+通用"双轨——3个通用机场运营 + A类通航飞行服务站 |
| 试点空域 | 累计划设 **54个**低空试点空域 |
| 低空航线 | 开辟 **43条**低空航线 |
| 三平台 | 省级飞行服务 + 无人机监管 + 航空应急救援——**三平台打通** |

### 二、低空文旅

| 要素 | 详情 |
|:---|:---|
| 观光航线 | 合肥—芜湖、芜湖—黄山（2024.09 开通） |
| 景观覆盖 | 天鹅湖、巢湖、长江、桃花潭、太平湖、黄山风景区 |
| 远期目标 | 2027 年通用飞机飞行达 **1.5万小时** |

### 三、eVTOL 制造集群

| 企业 | 地点 | 核心产品 |
|:---|:---|:---|
| **亿航智能** | 芜湖 | 全球首个自动驾驶 eVTOL 适航认证机型生产基地 |
| **零重力飞行器** | 合肥 | "天行"系列，计划 2025 年完成适航验证 |
| **中电科芜湖钻石** | 芜湖 | 航空材料、动力系统等关键部件 |
| 安徽应流集团 | — | 航空关键部件制造 |
| 产业集聚 | 芜湖湾沚区 | **200+**低空经济企业 |

### 四、村集体购机（★ 全国首例）

| 要素 | 详情 |
|:---|:---|
| 飞机名称 | **"永兴号"** |
| 购置价格 | **103.9万元** |
| 出资方 | 芜湖湾沚区花桥镇永兴村股份经济合作社 |
| 运营时间 | 2025年7月正式投入运营 |
| 运营效益 | 累计接待 **3万**人次中小学生航空研学；带动周边 **100人**就业，人均月增收 **2000元**；年营收 **1500万元** |

### 五、多场景应用

| 领域 | 关键数据 |
|:---|:---|
| **低空物流** | 合肥2条无人机配送航线；安庆岳西"云上邮路"——时间压缩 **75%**，成本降低 **60%** |
| **医疗配送** | 合肥 **25条**"空中送血"航线，**20分钟**内送达 20+院区；黄山 2024年累计应急转运 **46次** |
| **电力巡检** | 国网安徽 **10万+公里**线路无人机巡检，效率较人工提升 **8倍** |
| **农业植保** | 覆盖小麦/水稻/茶叶等，效率是人工的 **30倍**以上，每亩成本降低 **20元** |

## "低空版图"系列对照

## 与子课题3 关联

| 维度 | 关联点 |
|:---|:---|
| **54空域+43航线** | 省级中尺度空域网络拓扑——介于城市级（深圳）和大尺度（新疆）之间 |
| **制造→飞行量** | 3家 eVTOL 头部企业+200+产业链企业 → 产业化驱动飞行量指数增长 → 容量需求预测 |
| **效率参数** | 75%/60%/8x/30x——效率→飞行量换算的实证参数集 |
| **多场景常态化** | 物流+医疗+巡检+植保四场景常态化——多场景耦合容量建模 |

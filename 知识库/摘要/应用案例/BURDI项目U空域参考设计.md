# BURDI项目：U空域参考设计实施（低空产研记录，2025）

> 源文件：`原始素材/文章/低空案例分析丨欧洲BURDI项目告一段落，"U空域"构建低空数字蓝图.md`
> 来源：低空产研记录（微信公众号），2025-11-04
> 事件基准：BURDI项目2025年10月成果发布会，2025年底正式收尾

## 核心定位

欧洲首个**跨境U空域参考设计实施**项目——比利时-荷兰联合，€990万/18核心伙伴/3年。将EU 2021/664 U-space法规从理论框架转化为可运营、可推广的"参考设计"。核心成果：U空域ConOps获批、首个跨境互操作参考设计、BVLOS医疗物流（30min→<13min）、CISP+USSP+UTM全栈至TRL 8/9。为全欧U空域部署提供**可复制模板**。

## 五大板块

### 一、项目概览

| 要素 | 详情 |
|:---|:---|
| **全称** | Belgium-Netherlands U-space Reference Design Implementation |
| **周期** | 2022.11–2025底（3年） |
| **预算** | €990万（EU CEF资助+SESAR JU支持） |
| **伙伴** | 18核心+4附属——跨部门联盟 |
| **测试区** | 布鲁塞尔+安特卫普+列日（比利时）+ 跨境荷兰 |

### 二、三层技术架构

| 层 | 承担方 | 功能 |
|:---|:---|:---|
| **CISP** | ★ skeyes（比利时ANSP） | 基本空域+气象信息 |
| **USSP** | ★ SkeyDrone | 数字飞行授权+交通信息+冲突解脱 |
| **UTM** | ★ Unifly | 底层技术平台 |

> 已整合验证：4项EU法规强制基本服务（网络识别/地理感知/飞行授权/交通信息）+ 2项增值服务（气象/一致性监控）。技术成熟度：**TRL 8/9**（运营就绪）。

### 三、关键成果

| 成果 | 内容 | 制度影响 |
|:---|:---|:---|
| **★ ConOps获批** | U空域运行概念——空域创建+风险评估+服务详情 | 成为EU法规更新+EASA标准化直接依据 |
| **★ 首个跨境U空域参考设计** | 比利时-荷兰互操作方案 | "互操作性和单一数字天空"关键一步 |
| **BVLOS医疗物流** | 地面30min→**<13min** | ★ 从英国远程操控比利时无人机 |
| **港口BVLOS运营** | 安特卫普港巡检+安全监控 | 港口+城市+机场三重复合环境验证 |
| **经济可持续模型** | Future Needs主导成本模型+市场需求 | U空域商业模式可行性 |
| **多层次治理框架** | 公众+政府+运营商协调 | 社会接受度的制度化 |

### 四、首个U-space空域

> ★ **安特卫普-布鲁日港**成为首个正式指定的U-space空域——欧洲最大港口之一的低空数字化转型。

### 五、标准化贡献

```
BURDI参考设计 ──→ 姐妹项目（U-ELCOME/EALÚ-AER）并行验证
                         │
                         ▼
              EU法规更新 + EASA标准化流程 ──→ 全欧推广
                         │
                         ▼
              "数字、互联、可持续的欧洲空域"
```

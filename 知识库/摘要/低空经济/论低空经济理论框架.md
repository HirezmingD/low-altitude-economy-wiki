# 论低空经济：内涵构成与动力特征

## 来源

李连成, 李名良 (2025). 论低空经济. 北京交通大学学报(社会科学版). 国家发改委综合运输研究所.

## 六大体系

飞行器研发制造 → 基础设施 → 基础制度 → 空域保障 → 安全保障 → 飞行服务应用

## 三特征 → 子课题3理论基础

| 特征 | 子课题3映射 |
|------|-----------|
| **低空资源要素化** | 空域作为"空中土地"需要容量量化 |
| **空地活动一体化** | 地面约束映射空中容量 |
| **价值创造规模化** | 容量评估支撑商业化运行 |

## 四阶段演进

孕育 → 探索 → **成长（容量工具需求爆发）** → 成熟

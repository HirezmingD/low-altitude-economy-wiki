# 低空开发权与用途管制

## 来源

石春晖, 柳泽, 尤潇, 张彦拓, 崔颖 (2026). 基于低空开发权的低空空域用途管制. 城市规划学刊, 2026(01).

## 核心创新

提出「低空开发权」概念，作为空间权与空域权的衔接纽带：

```
空间权（私法）  ←→  空域权（公法/航空）
        ↘        ↙
       低空开发权（公法规划权）
            ↓
      低空空域用途管制
```

## 用途管制三元组

"空间单元 + 空间功能 + 时间窗口" — 与子课题3的时空容量框架有概念呼应

- 美国：考斯比案确立低空财产权宪法保护，VOD开发模式
- 欧盟：U-space计划，地空协同管制
- 国际：ICAO UTM全球协作框架

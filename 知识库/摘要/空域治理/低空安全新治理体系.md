# 低空安全新治理体系（董志毅，2025）

> 源文件：`原始素材/文章/低空经济观察｜大力发展通用航空和低空经济 助力中国式现代化建设-新华网.md`

## 作者权威性

董志毅是中国民航局原副局长，现任中国航空学会低空经济首席专家，是中国低空经济领域最具权威性的行业专家之一。本文代表了民航业对低空安全治理的顶层思考。

## 核心内容

### 2024 年十大发展态势

| # | 态势 | 核心要点 |
|:---|:---|:---|
| 1 | 政策推动，部委统筹 | 写入三中全会《决定》；国家发改委成立低空司 |
| 2 | 法规筑基，标准引领 | 《无人驾驶航空器飞行管理暂行条例》《CCAR-92部》等核心法规出台 |
| 3 | 改革深化，要素释放 | **G 类（300 米以下）、W 类（120 米以下）非管制空域首次划分** |
| 4 | 政策利好，装备先行 | "无人化、电动化、智能化"方向 |
| 5 | 健全体系，适航突破 | 无人机适航"分类分级，求实创新" |
| 6 | 智能网联，基础发力 | 低空智能网联体系参考架构图发布 |
| 7 | 政府主导，市场驱动 | 26 省写入政府工作报告；**无人机 215.8 万架/2544.9 万小时** |
| 8 | 央企布局，民企活跃 | 专精特新"小巨人"增多 |
| 9 | 扰航警醒，安全为本 | **天津滨海机场因无人机停航近 11 小时**（2024.09.11） |
| 10 | 研究深入，会展丰富 | 理论研究热潮迭起 |

### 构建审慎包容的低空安全新治理体系（五大支柱）

| # | 支柱 | 核心内容 |
|:---|:---|:---|
| ① | **协同管理体系** | 地方主责 + 行业指导 + 企业主体 + 社会参与 |
| ② | **空域资源释放** | G/W 类科学配置；**城市适飞空域网格化剖分管理**；时空数据管理引擎；精细分配与动态管理 |
| ③ | **数字飞行规则** | 从"人在回路内"→"人在回路外"；适应异构、高频次、大容量、高复杂度运行 |
| ④ | **安全管理与执法体系** | 监管侧 + 制造侧 + 运行侧全链条；分级分类处置 |
| ⑤ | **内生安全技术体系** | 低空智能网联体系内生安全；数字低空内生安全底座 |

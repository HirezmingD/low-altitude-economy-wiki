## 核心发现一：五维度理解框架

> 第一编提供了一个结构化认知路径，对后续知识库页面组织有参考价值。

| 维度 | 比喻 | 核心内容 |
|:---|:---|:---|
| 一、法律法规与政策框架 | "天空的游戏规则" | ICAO SARPs → 国家法规（CCAR/FAR/EASA）→ 特定空域政策（隔离/混合/临时） |
| 二、空域结构与分类 | "空中高速公路网" | ICAO A-G分类 → 各国实践 → 管制/非管制/特殊用途空域 → 静态 vs 动态空域管理 |
| 三、技术保障与系统 | "神经系统" | 监视（雷达/ADS-B/U-cloud）→ 通信（VHF/CPDLC/4G5G）→ 运行支撑（UTM/U-space） |

## 核心发现二：[《飞行基本规则》](知识库/政策/中国/飞行基本规则.md)第二章关键空间参数

> ★ 对子课题3 直接可用。此前知识库缺乏这些法定空间约束参数。

| 参数 | 法定数值 | 法律条款 | 与容量建模的关联 |
|:---|:---|:---|:---|
| 航路宽度 | **20km**（中心线各10km），最少8km | 第15条 | 航路容量走廊的空间单元宽度 |
| 空中走廊宽度 | **10km**（中心线各5km），最少8km | 第21条 | 城市密集区空域通道空间约束 |
| 等待空域最低高度 | 距地面最高障碍物 **≥600m** | 第14条 | 安全间隔垂直基准 |
| 等待高度层间隔 | ≤8400m: 300m/层; 8400-8900m: 500m; 8900-12500m: 300m; >12500m: 600m | 第14条 | 垂直容量分层计算参数 |
| 仪表飞行空域安全缓冲 | 距航路/空中走廊 **≥10km** | 第14条 | IFR/VFR 混合运行安全间隔 |
| 国境线禁飞缓冲 | 我方一侧 **10km** 内禁止临时飞行空域 | 第23条 | 边境地区容量硬约束 |
| 航路禁建靶场距离 | 航路边界 **30km** 内禁止射击靶场 | 第25条 | 地面风险源空间约束 |
| 空中禁区 | 国家重要政治/经济/军事目标上空 | 第17条 | 容量模型的绝对禁飞区 |
| 空中限制区 | 军事要地/兵器试验场/军事单位上空 | 第18条 | 容量模型的条件禁飞区 |
| 空中危险区 | 对空射击场/发射场上空 | 第19条 | 容量模型的动态危险区 |

## 核心发现三：分类方法"有关要求"（此前知识库缺失）

| 条款 | 内容 | 价值 |
|:---|:---|:---|
| **通信监视覆盖** | A/B/C/D/E类须实现**通信和监视覆盖**；G类须实现**监视覆盖** | CNS 性能的法定最低要求——容量模型的 CNS 折减基准 |
| **VFR气象条件** | 三档：①>3000m→能见度≥8km, 距云≥1500m水平/300m垂直；②900m-3000m→≥5km, ≥1500m/300m；③<900m→≥5km, 云外飞行 | 气象折减系数的法定分级参数 |
| **隔离空域** | 难以满足飞行要求时可申请划设**隔离空域**并对外公布 | 容量不足时的法定替代方案 |
| **B/C类形状** | 可根据实际情况调整为**不规则多边形** | 空域建模不能假设标准圆形 |
| **有人/无人适用** | A-E/G类要求适用有人机，无人机按《暂行条例》执行 | 法规衔接条款 |
| **超限飞行** | 经特别批准可按 VFR 在 A类飞行，或超限速在 C/D/E/G类飞行 | 容量峰值时的弹性空间 |

## 核心发现四：[《通用航空飞行管制条例》](知识库/政策/中国/通用航空飞行管制条例.md)运营时限参数

| 流程 | 时限 | 对容量评估的意义 |
|:---|:---|:---|
| 临时空域申请 | 拟使用前 **7个工作日** | 计划性容量调整的最短提前期 |
| 临时空域批复 | 拟使用前 **3个工作日** | 容量供给侧的响应延迟 |
| 临时空域有效期 | 最长 **12个月** | 长期容量规划的时间窗 |
| 飞行计划（常规） | 前1天 **15:00前**申请 → 当天 **21:00前**批复 | 次日容量预分配的截止时间 |
| 飞行计划（紧急） | 拟飞行 **1小时前**申请 → 起飞时刻 **15分钟前**批复 | 应急容量的最快响应速度 |
| 短期计划 | **15天内**无需逐日申请 | 稳定运行期的容量管理模式 |

# 空—地协同低空空域划设技术

## 来源

安诣彬, 徐小黎, 党安荣, 孙久虎, 李翔宇, 荣月静 (2026). 国土空间视角下空—地协同低空空域划设技术及用途管理框架研究. 城市规划学刊.

## 背景

传统低空空域划设"重空中、轻地面"，难以适应物流配送、应急救援、载人飞行等多元化需求。本文从空—地系统耦合视角，推动低空空域划设由"航路管制"向"立体空间治理"转型。

## 核心方法

### 1. 理论重构
将低空空域重新界定为三维国土空间资源，具备三重属性：
- **空间形态**：由地表起伏、建筑形态与人工设施共同塑造的三维立体空间
- **功能属性**：同时承载交通、公共服务、产业运行与安全防护等多重复合用途
- **治理属性**：兼具航空管制与国土空间管控双重治理主体

### 2. 空—地协同划设技术框架
- **空中边界划设**：垂向高度分层（0-300/300-600/600-1000m）+ 水平范围划设（固定空域 + 临时空域 ≤12个月）
- **地面边界划设**：刚性管理要素（政治/军事/特殊防护区）、风险敏感要素（学校/危化品库/核电站）、高层建筑障碍物 → 映射为"限制体/禁飞体"
- **技术手段**：三维网格体素化 + GIS空间叠加分析 + 实景三维 + 数字孪生

### 3. 管理制度
"用途分区 + 用途分类"双维框架，公用/商业/私人三类，高强度/中强度/低强度三级管控

### 4. 临沂实证（三层指标体系）
- **容量评估**：障碍物分布 + 冲突避让 + 飞行高度分析
- **风险评估**：军用空域 + 机场空域 + 敏感要素
- **需求评估**：地面功能 + 产业布局 + 使用需求
→ 输出：禁用区 / 限用区 / 适用区

三维时空管理：竖向分层（0-300/300-600/600-1000m）+ 平面分区（禁飞/物流/执法/应急/商业/居民/生态/交通枢纽）+ 分时管控（高峰/平峰/低峰）

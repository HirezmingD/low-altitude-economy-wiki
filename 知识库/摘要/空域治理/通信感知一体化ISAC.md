# 通信感知一体化低空无人机关键技术研究综述

## 基本信息

| 项目 | 内容 |
|------|------|
| 机构 | 青岛科技大学 + 北京邮电大学 + 联通数科 |
| 期刊 | 电讯技术 2025(6) |
| 方向 | ⚠️ 边缘（通导监基础设施层） |

## 核心内容

### 五大技术方向
1. **波形设计**：通信+感知共享频谱资源
2. **雷达成像**：ISAC合成孔径/动目标检测
3. **干扰管理**：通信-感知互干扰消除
4. **资源管理与轨迹设计**：通感联合优化
5. **AI技术应用**：深度学习增强通感融合

### 应用场景
低空无人机扩展通信覆盖+增强感知功能，面向6G的ISAC框架

## 与子课题3的关联

弱。属通导监基础设施层，为"看得见/连得上"提供技术支撑，不直接涉及容量量化。与已处理的低空监视技术综述、ADS-B综述属同一大类。

# 低空空域经营权的理论证成与制度实现

> 刘冲（北航法学院）. (2026). 财经法学 2026(03).

## 核心问题

平阴县 9.24 亿"卖天"事件引发低空空域经营权的法律性质争议：低空空域属于什么类型的经济物品？谁有权经营？经营权的法律属性是什么？

## 关键论证

### 1. 低空的四类经济物品

| 高度层 | 经济物品属性 | 理由 |
|:------|:------|:------|
| 超低空（<120m） | 私人/俱乐部物品 | 与地表产权紧密关联 |
| 低空信息基础设施 | **俱乐部物品** | 排他性强、非竞争性、自然垄断 |
| 低空航行服务 | 私人物品 | 边际成本高，可市场定价 |
| 高空航路 | 纯公共物品 | 国家战略安全 |

### 2. 经营权三权能

| 权能 | 内容 | 可操作性 |
|:------|:------|:------|
| 收费权 | 对空域使用者收费，可质押/证券化 | 高 |
| 排他性运营权 | 一城一主体，源于自然垄断 | 中 |
| 飞行活动管理权 | 经营权人作为"治理中介" | 低（争议最大） |

### 3. 治理体系演进

```
二元（军方+民航）→ 三元（+地方政府）→ 四元（+经营权人）
```

经营权人成为治理体系中的第四极，既是对空域使用的市场化运作，也是对地方政府的监管缓冲。

## 与子课题3的关联

- **俱乐部物品 → 最优用户规模**：低空基础设施作为俱乐部物品存在最优用户数，超过则拥挤（容量衰减），这与"空域承载力/饱和度"概念直接对应
- **收费权 → 容量定价**：经营权人的收费机制可转化为容量使用的经济信号，为动态容量评估提供需求侧约束
- **排他性运营 → 区域容量上限**：一城一主体的垄断结构意味着区域空域容量存在人为上限

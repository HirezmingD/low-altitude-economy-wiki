# 中央统领·地方主导：央地视角下的低空空域协同管理机制（王凯博，2026）

> 首篇以**央地关系**为分析框架的低空空域管理体制研究。核心论点：低空空域管理体制改革的关键不在机构调整，而在央地事权的重新配置——从"中央统一监管"转向"中央统领，地方主导"。

## 背景

低空经济蓬勃发展背景下，现行低空空域管理体制出现管理效率低下、规制成本过高、与产业发展不相适应等问题。表面看是机构设置和职权配置问题，实则根源于**央地关系在民用航空领域的投射**。[《无人驾驶航空器飞行管理暂行条例》](知识库/政策/中国/无人驾驶航空器飞行管理暂行条例.md)（2024）虽首次赋予地方公安机关"黑飞"先期处置权，但未能完全明确央地职权配置。

## 核心发现

### 一、现行体制的精确结构（此前知识库缺失）

| 体系 | 层级 | 职责 |
|:---|:---|:---|
| **军航（四级）** | 空军 → 军区空军 → 军师级航空单位 → 军航机场 | 全国空域管理 → 飞行管制区 → 飞行管制分区 → 机场管制区 |
| **民航（三级）** | 民航空管局 → 地区空管局 → 空管分局/站 | 区域管制 → 进近管制 → 机场管制 |

**审批痛点**：不同事项（空域使用权、起降点核准等）分属军航不同单位（航行部门、作战部门等），单个飞行任务需协调**多个管制单位**。

### 二、央地关系重构的可行性（三维论证）

| 维度 | 核心论据 | 关键来源 |
|:---|:---|:---|
| **法理** | 宪法第3条第4款——"中央统一领导下，充分发挥地方主动性、积极性" | 《宪法》 |
| **功能** | 集中式管理两大弊端：①难以应对海量无人机 ②地面执法与空中执法分离 | "黑飞"案例：河北廊坊2022、天津滨海2024.09 |
| **地方经验** | 深圳2023年率先立法；四川/重庆"区域管理" vs 无锡/深圳"高度管理"——差异化模式已验证可行 | 各地方实践 |

### 三、央地关系重构的必要性——"三化"挑战

| 趋势 | 表现 | 对管理体制的冲击 |
|:---|:---|:---|
| **信息化** | 高分辨率摄像头+热成像→数据泄露风险 | 现行规制仅锚定实体风险（坠/撞机），**未覆盖信息风险** |
| **智能化** | AI深度学习→视觉感知+路径规划+决策 | **算法替代重量**成为核心风险因素——现行以重量分类的规制框架失效 |
| **规模化** | 未来城市同时在空百万级UAV，起降次数更高 | 现行"全流程逐一审批"模式无法支撑，需**自动化容量管理** |

### 四、国际比较——三方模式与量化数据

| 指标 | 美国（联邦主导+州辅助） | 欧盟（超国家统一+成员国灵活） | 澳大利亚（联邦监管+行业自律） |
|:---|:---|:---|:---|
| **核心法规** | 小型无人机系统规则（FAR 107） | 无人机实施条例（OPEN/SPECIFIC/CERTIFIED） | 无人机操作规则 |
| **高度限制** | 400ft (≈122m) | 按类别区分 | 120m |
| **注册量** | **320万架**（2024） | — | — |
| **关键技术** | Remote ID（85%覆盖）+ DroneZone | **U-Space**（80%成员国） | Self-Approval（30天→1天） |
| **事故率变化** | ↓60%（0.15‰→0.06‰） | 西班牙↓70%（0.12‰→0.036‰） | — |
| **监管成本变化** | — | 中小企业合规€10万/年 | ↓40%（A$500万→A$300万） |
| **审批加速** | [LAANC](知识库/概念/空域治理/空域分类制度.md)秒级 | 跨国审批7天→**24小时** | 审批30天→**1天** |
| **主要问题** | 监管套利（州降标准竞争）/ 州联邦冲突 | 东欧执行困难 / 中小企业成本高 | 自律执行不严 |
| **治理模式类型** | 市场化监管型 | 协同监管型 | 平衡型 |

### 五、完善路径

**纵向：中央统领 + 地方主导**

```
中央（统领）                         地方（主导）
─────────────────                    ─────────────────
· 战略谋划、组织协调                  · 细化监管制度（结合本地空域环境）
· 许可/空域分配原则和标准制定          · 承担行政区域内低空飞行活动的具体管理
· 保障国家安全统一管控                · 因地制宜促进产业发展
```

**渐进转移策略**（关键创新）：

| 阶段 | 下放对象 | 条件 |
|:---|:---|:---|
| **先行下放** | 物流无人机 | 运行范围/状态稳定可控、产业规模效应显著、运营主体相对集中 |
| **暂不下放** | 载人eVTOL | 应用范围小、经验不成熟、风险未全面充分评估 |

**横向：一体化综合监管服务平台**

- 平台角色：**数据监控载体**（不享有"决策"权力）
- 执法主体：地方政府——从平台收集信息 → 实地核实调查 → 行使执法权
- 核心功能：整合飞行数据+外部因素 → 算法模型**描述并预测低空空域态势** → 识别异常 → 警报 → 响应
- 跨区域案件：民航各地区管理局依托平台协调地方政府

# 低空航路安全评估与容量评估的关系分析

## 概念辨析

| 维度 | 航路安全评估 | 空域容量评估 |
|:---|:---|:---|
| **核心问题** | 航路是否安全？ | 空域能容纳多少飞行器？ |
| **评估对象** | 特定航路的环境条件 | 空域单元的承载上限 |
| **输出** | 安全等级(A/B/C/D) | 容量值（架次/小时、架次/日） |
| **时间维度** | 静态基准+动态气象修正 | 静态容量基准+动态折扣 |
| **空间粒度** | 航路中心线带状区域 | 空域网格或扇区 |

## 两者的互补关系

### 安全评估 → 容量评估：输入参数
安全评估指标中的约束条件可直接作为容量模型的参数：

| 安全指标类别 | 容量评估用途 |
|:---|:---|
| 禁飞区覆盖率、高度限制 | 可用空域比例计算 |
| 障碍物密度、超障余度 | 安全缓冲裕度 → 折减系数 |
| 通信/导航/监视覆盖率 | 技术能力约束 → 容量折扣 |
| 气象参数（风速、能见度） | 气象折减系数 |
| 空域管理复杂度 | 运行效率系数 |

### 容量评估 → 安全评估：阈值验证
容量评估得出的最大流量值可反向验证安全等级的合理性——超出一定容量阈值后安全等级必然下降。

## 方法对比

| 要素 | 安全评估方法 | 可迁移到容量评估 |
|:---|:---|:---|
| 静态基础评分 | 基础分值 = Σ(指标得分 × 权重) | 静态容量基准 × 多因素耦合 |
| 动态修正 | 气象修正系数 | 天气、时间等动态折扣系数 |
| 设备失效归零 | 对应指标置0 | 技术故障容量退化模型 |
| 四级分级 | A/B/C/D | 容量等级可借鉴 |
| 评估场景 | 规划/开通/月度/年度/专项 | 容量评估的阶段划分可参照 |

## 对课题的核心价值

1. **指标体系复用**：评估规范的8大类76项指标可直接或转化后用于容量评估的多因素耦合模型
2. **方法论参照**：静态基准+动态修正的两层模型结构可直接迁移
3. **数据源共享**：评估规范定义的飞行测试法和数据采集流程可为容量数据采集提供方法论
4. **结果互验**：安全评估结果可作为容量评估的约束条件，两者互为校验

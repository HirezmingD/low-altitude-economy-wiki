# 全球 LAAM CONOPS 技术架构七方比较

## 三、容量管理机制深度对比

### 3.1 DCB（欧盟）vs 动态调配（中国）vs 战略冲突管理（美国）

| 管理维度 | NASA/FAA | U-Space DACUS | 中国方案（子课题3） |
|:---|:---|:---|:---|
| **管理粒度** | 垂直机场/走廊 | 空域块（DCB blocks） | GeoSOT 网格单元（10m/20m） |
| **时间尺度** | 战略-战术 | 五阶段（年→分钟） | 实时动态（目标：0-30min预测驱动） |
| **评估因素** | 安全+效率 | 安全+**社会影响**（噪音/隐私/视觉） | 安全+**多因素耦合**（气象/生态/电磁/地面/CNS） |
| **预警机制** | 冲突概率阈值 | 冲突风险 + 社会影响指标 | 红-黄-绿三级饱和度 |
| **调控方式** | 走廊准入控制 | DCB 措施（性能门槛/优先级/空域重构/需求平滑） | "评估-预警-调控"自动化闭环 |

### 3.2 X/Y/Z 三级（U-Space）vs 红-黄-绿三级（子课题3）

| 比较维度 | U-Space X/Y/Z | 子课题3 红-黄-绿 |
|:---|:---|:---|
| **本质** | **空域类型准入控制**（静态分类） | **实时饱和度状态**（动态监控） |
| **决定因素** | 空域风险等级 + U-Space 服务类型 | 实时交通密度 + 多因素耦合折减 |
| **变化频率** | 按需调整（非实时） | 实时/近实时（分钟级） |
| **X=低风险VLOS无冲突解决** | ↔ 可关联 | **绿**=低饱和度，正常通行 |
| **Y=BVLOS预战术冲突解决** | ↔ 可关联 | **黄**=中饱和度，警戒疏导 |
| **Z=战术冲突解决（Zu指令/Zz建议）** | ↔ 可关联 | **红**=高饱和度，强制干预 |
| **映射关系** | X/Y/Z定义了空域的**能力上限** | 红-黄-绿反映空域的**实时状态** |

> **核心洞察**：X/Y/Z 是"空域能提供什么服务"（供给侧分类），红-黄-绿是"空域现在处于什么状态"（实时状态监控）。两者的整合可实现**实时状态驱动的空域类型动态切换**——这是子课题3 在国际学术谱系中的独特创新空间。

## 五、研究缺口与子课题3 的创新定位

| 缺口 | 描述 | 子课题3 的对应贡献 |
|:---|:---|:---|
| **CNS-容量定量模型缺失** | 现有 CONOPS "未充分考虑 CNS 性能对 SACA 的影响" | CNS 性能驱动的容量折减模型 |
| **统一空间编码** | 除中国外，各国使用非统一的空间编码方案 | GeoSOT 网格作为全球可对标方案 |
| **社会接受度的容量约束** | 仅 DACUS 将社会影响纳入 DCB | 多因素耦合中纳入噪声/隐私等社会维度 |
| **短临预测驱动** | 现有 DCB 以"计划驱动"为主 | ST-GNN 实现"感知驱动"的 0-30min 预警 |
| **网格容量模型** | 网格大小估计"没有明确界定" | 基于 GeoSOT 10m/20m 的统一网格容量基准 |
| **气候-性能-容量耦合** ☆ | 除 GCC 外，所有 CONOPS 均未系统纳入气候约束对容量的定量影响 | 气候折减因子 f_climate = f_temp × f_humidity × f_dust × f_wind，GCC白皮书提供首个完整实证参数集 |

## 六、对研究意图的更新建议

基于本比较分析，子课题3 在国际学术谱系中的独特定位可以表述为：

> 以 GeoSOT 统一网格编码为空间基础，以 CNS 性能驱动+多因素耦合（含气候折减）为容量评估内核，以 ST-GNN 短临预测为感知驱动的"评估-预警-调控"实时闭环——区别于美国 DCB（战略计划驱动）、欧盟 X/Y/Z（静态空域分类）和 GCC（气候约束优先），形成**实时感知驱动型动态容量管理**的第三种范式。

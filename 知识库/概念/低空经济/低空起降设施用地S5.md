# 低空起降设施用地（S5）

> ★ 中国首个专门为低空起降设施设立的土地利用分类代码。由珠海市自然资源局在全国率先提出，将低空起降设施从"无类可归"的边缘状态纳入法定规划管理体系，从土地制度源头破解低空基础设施"落地难"问题。

## 一、核心概念

**低空起降设施用地（S5）** 是中国国土空间规划用地用海分类体系中新增的专项地类，隶属于**S类（公共设施用地）**大类，专门用于垂直起降场（Vertiport）、无人机起降点、通航机场配套起降区等低空飞行器的地面起降基础设施。

> ★ S5 的设立意味着：低空起降设施在中国城市规划体系中获得了与道路（S1）、轨道交通（S2）、公交场站（S3/S4）同等级别的法定用地地位。这是低空基础设施从"临时设施"走向"永久城市基础设施"的制度里程碑。

## 二、在中国用地分类体系中的位置

### 2.1 S类（公共设施用地）谱系

| 代码 | 地类名称 | 功能 |
|:---|:---|:---|
| S1 | 城市道路用地 | 地面道路交通 |
| S2 | 轨道交通线路用地 | 地铁/轻轨/城际 |
| S3 | 综合交通枢纽用地 | 多模式换乘枢纽 |
| S4 | 交通场站用地 | 公交场站/停车场 |
| **S5** | ★ **低空起降设施用地** | **垂直起降场/无人机起降点** |

> S5 位于 S1-S4 的序列延伸——将城市交通设施体系从**地面-地下（S1-S2）→ 换乘枢纽（S3）→ 静态交通（S4）→ 低空起降（S5）**完成了从二维到三维的交通用地谱系闭合。

### 2.2 S5 的制度功能

| 功能 | 说明 |
|:---|:---|
| **合法性赋予** | 低空起降设施获得法定用地身份——不再需要"借道"工业用地、商业用地或其他不相称地类 |
| **指标保障** | 国土空间规划可单独为S5用地配置指标——避免与其他地类竞争用地配额 |
| **审批简化** | 作为明确地类→规划报建路径清晰——不再因"无类可归"陷入审批灰色地带 |
| **地价管理** | S类公共设施用地的地价标准远低于商业/住宅——降低低空基础设施的土地成本 |

## 三、S5 地类的复合使用

珠海《措施》明确鼓励 S5 用地的复合建设模式：

### 3.1 三种复合模式

| 模式 | 操作方式 | 容量特征 |
|:---|:---|:---|
| **①用地混合兼容** | S5 + 其他地类（商业/工业/绿地）在同一地块内混合使用 | 共享但受兼容性约束——$C_{effective} \leq C_{nominal}$ |
| **②既有建筑附设** | 利用自有用地或已建建筑的屋顶/空地设置垂直起降设施 | 零新增用地——快速释放但容量上限低 |
| **③塔杆资源复合** | 通信塔、灯杆、监控杆与无人机起降点一体化建设 | 网络化部署——适合物流无人机末端节点 |

### 3.2 复合建设的容量含义

```
独立S5用地 ──→ 专用容量 $C_{dedicated}$
                 高效但土地需求大

复合建设   ──→ 共享容量 $C_{shared}$
                 节约土地但受共用资源竞争约束

塔杆复合   ──→ 分布式容量 $C_{distributed}$
                 网络效应但单点容量极低
```

## 四、制度创新意义

### 4.1 与其他城市制度的对照

| 城市 | 基础设施制度创新 | 制度工具 |
|:---|:---|:---|
| **珠海** | ★ S5 地类——用地分类制度创新 | 土地规划制度 |
| **深圳** | 低空基础设施高质量建设方案——起降点目标量化 | 专项规划+产业基金 |
| **福州** | 空域网格动态释放——空域供给侧改革 | 军地民协同+管理流程 |
| **安徽** | eVTOL制造集群——制造反哺应用 | 产业集群政策 |

### 4.2 S5 的扩散潜力

> 珠海率先设立 S5 地类是**地方先行先试**的典型案例。若其他城市跟进采纳，S5 有望从珠海地方标准上升为**全国性用地分类标准**——类似于深圳的低空经济特区立法对其他城市的示范效应。S5 的全国扩散进程将是衡量中国低空基础设施制度化程度的关键指标。

## 五、国际对照

| 国家/地区 | 垂直起降场用地制度 | 对比 |
|:---|:---|:---|
| **中国（珠海）** | ★ 新增 S5 专项地类 | 从土地分类制度源头解决 |
| **美国** | FAA 垂直起降场设计指南（EB 105）——无独立用地分类，依赖地方 zoning | 市场化但碎片化 |
| **欧盟（EASA）** | EASA 垂直起降场技术规范——无统一用地制度，成员国各自为政 | 技术规范先行、用地制度滞后 |
| **GCC（阿联酋）** | CAR AGA PART VFI——垂直起降场认证→由自由区/城市管理局分配用地 | 监管沙盒灵活性高但制度化程度低 |
| **日本** | 国交省统管铁路+航空→垂直起降场嵌入交通枢纽——无独立用地分类 | 行政协调替代用地分类创新 |

> ★ 珠海 S5 的全球参照意义：全球范围内，即使在美国 EASA 等航空监管领先地区，垂直起降场的土地制度保障仍主要通过 zoning 调整或行政协调实现——珠海 S5 将垂直起降场用地**嵌入国家法定用地分类体系**的做法，在全球低空基础设施制度化进程中具有先行意义。

## 六、对子课题3的启示

| 维度 | 启示 |
|:---|:---|
| **地面侧容量约束** | S5 用地总量→垂直起降场密度上限→空域容量的地面根源约束：$C_{airspace}$ 理论上可达但受 $C_{ground}(S5)$ 硬约束。容量评估体系需增加**土地可用性维度** |
| **制度→容量释放速率** | S5 地类的设立本身是制度基础设施——有了 S5 → 规划报建路径通畅 → $\frac{dC_{vertiport}}{dt}$ 加速→容量释放曲线更陡峭 |
| **专用vs共享容量建模** | 独立 S5 vs 复合建设 → 两类容量源，需分别建模后在网络层叠加——$C_{network} = \sum C_{dedicated,i} + \sum C_{shared,j} \times \eta_j$（$\eta$ 为共享效率系数） |
| **扩散效应→容量预测** | S5 从珠海向全国扩散的速度和广度→影响全国低空基础设施容量的增长轨迹 → 可作为容量预测的**制度变量输入** |

# 低空经济四维优先级评价框架

## 定义

樊一江等（2024）提出的低空经济应用场景优先级评价体系：从**技术成熟度、需求迫切度、经济效益性、风险可控力**四个维度，对五大低空应用场景进行半定量评级，指导分类别、分区域稳步有序推进试点示范。

## 四维评价

| 维度 | 含义 | 评价方法 |
|------|------|---------|
| 技术成熟度 | 低空飞行及相关保障技术的成熟水平 | 产业实践+适航认证进展 |
| 需求迫切度 | 场景对低空飞行需求的不可替代性 | 有无替代方案 |
| 经济效益性 | 场景可释放的市场价值规模 | 市场预测+商业模式 |
| 风险可控力 | 场景运行的安全隐患可控程度 | 载人/非载人+环境复杂度 |

## 五大场景评级

```
经济效益     ★★★★★ 载人出行
                ↕
需求迫切     ★★★★★ 公共服务
                ↕
技术成熟     ★★★★☆ 货运物流、生产作业
                ↕
风险可控     ★★★★☆ 生产作业（非载人、非城市复杂环境）
```

## 优先级矩阵

```
        高需求 ←→ 低需求
高成熟  货运物流    文旅活动
  ↕     生产作业    载人出行
低成熟  公共服务     
```

**最优先推**：货运物流 + 生产作业（技术成熟+需求迫切+风险可控）
**远期培育**：载人出行（经济潜力最大但技术/风险挑战最高）

## 对子课题3的启示

- **场景优先级=承载力评价的切入顺序**：先评估货运物流和生产作业场景的空域承载力
- **风险可控维度**：非载人场景风险低→可先用简化承载力模型；载人场景→需完整风险评估
- **技术成熟度→评价精度要求**：技术越成熟，承载力评价可越精细化

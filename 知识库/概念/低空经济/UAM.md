# 城市空中交通（UAM）

## 定义

**城市空中交通**（Urban Air Mobility, UAM）是指利用 eVTOL 等新型航空器，在城市及近郊范围内提供客运、物流等出行服务的低空交通系统。UAM 是低空经济在**城市场景**中最具代表性的应用方向。

## 核心构成

| 要素 | 说明 |
|:---|:---|
| **载具** | 以 eVTOL 为主，辅以小型无人机 |
| **基础设施** | Vertiports（垂直起降场）、充电/加氢设施 |
| **空域系统** | UTM（无人机交通管理）、低空航路网络 |
| **运营模式** | 按需出行（on-demand）、固定航线、接驳服务 |

## 主要应用场景

1. **机场-市中心快速接驳**：15-30 分钟完成地面 1 小时以上的行程
2. **商业区-住宅区空中连接**：跨江、跨山等地理阻隔区域的直达通勤
3. **城市间短途通勤**：50-200 公里的城际空中走廊
4. **紧急医疗运输**：器官、血浆、急救药品的快速送达

## 对空域容量的核心影响

UAM 是本课题子课题3（空域资源承载力评价）中**最核心的需求场景**：

| 挑战维度 | 具体问题 |
|:---|:---|
| **高密度** | 单城市可能同时运行数百架 eVTOL，远超传统通航密度 |
| **强异构** | eVTOL、无人机、直升机混合运行，速度/高度/机动性差异大 |
| **动态性** | 按需出行模式导致交通流时空分布高度不确定 |
| **城市化约束** | 建筑物遮蔽、噪音敏感区、微气象等复杂城市因素 |
| **安全性要求** | 载人交通对安全间隔、冲突探测的要求远高于货物运输 |

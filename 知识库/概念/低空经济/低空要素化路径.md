# 低空要素化路径

## 定义

**低空要素化路径**是由朱克力（2026）提出的低空经济产业发展三段式框架：**低空要素化 → 场景化 → 经济化**。该框架描述了空域资源从被识别为生产要素到形成可持续商业闭环的完整演进过程。

## 三阶段模型

```
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│   要素化      │ ──→ │   场景化      │ ──→ │   经济化      │
│ Factorization │      │ Scenarization │      │ Economization │
├──────────────┤      ├──────────────┤      ├──────────────┤
│ 空域边界清晰  │      │ 标杆示范项目  │      │ 全链条生态     │
│ 规则统一      │      │ 因地制宜      │      │ 研发-制造-运营  │
│ 实时可查      │      │ 避免同质化    │      │ 点状→面状爆发  │
│ UOM 一张网    │      │ 场景驱动迭代  │      │ 可持续商业闭环  │
└──────────────┘      └──────────────┘      └──────────────┘
```

## 各阶段详解

### 第一阶段：要素化

| 要素 | 内容 | 标志性进展 |
|:---|:---|:---|
| 空域确权 | G/W 类非管制空域划分 | [《国家空域基础分类方法》](知识库/概念/空域治理/空域分类制度.md) |
| 数据统一 | UOM 平台全国一张网 | 2026 年 GIS 数据更新 |
| 法律保障 | 新[《民用航空法》](知识库/政策/中国/民用航空法2026.md)专章 | 2026.07.01 施行 |
| 边界清晰 | 各省适飞空域占比明确 | 广西 84%/四川 80%/湖南 75.5% |

### 第二阶段：场景化

| 领域 | 典型场景 | 差异化策略 |
|:---|:---|:---|
| 低空物流 | 快递配送、医疗物资、偏远地区 | 农业大省侧重植保物流 |
| 应急救援 | 灾害响应、消防监控 | 工业城市聚焦巡检运维 |
| 文旅观光 | 空中游览、赛事航拍 | 旅游城市发力低空游览 |
| 城市治理 | 巡检、安防、测绘 | 核心城区聚焦高附加值 |

### 第三阶段：经济化

- 构建研发 → 制造 → 运营 → 服务全链条生态
- 引入链主企业、培育本土配套
- 在土地、资金、人才等方面给予政策支持
- 从点状试点走向面状爆发
- 形成可持续的商业闭环

## 地方策略转型

朱克力强调，空域边界明确后，地方政府的发力点应从"**争空域**"转向：

| 旧焦点 | 新焦点 | 核心任务 |
|:---|:---|:---|
| 争空域 | **建生态** | 构建研发-制造-运营-服务全链条 |
| 争空域 | **强配套** | 起降点/停机坪/充换电站/通信基站；USS 服务平台与 UOM 打通 |
| 争空域 | **育场景** | 因地制宜打造标杆示范，避免同质化竞争 |

## 与子课题3 的关系

| 阶段 | 子课题3 的技术支撑 |
|:---|:---|
| **要素化** | 容量评估为"空域的确定性"提供**量化工具** |

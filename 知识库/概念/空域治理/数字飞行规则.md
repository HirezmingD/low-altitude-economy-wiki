# 数字飞行规则

## 定义

**数字飞行规则**（Digital Flight Rules, DFR）是一种面向低空"异构、高频次、大容量、高复杂度"运行环境的新型空中交通管理范式，由董志毅（2025）明确提出。其核心是实现从"有人驾驶、有人管控、系统辅助"向"**无人驾驶、智能管控、有人监督**"的转变，从"人在回路内"转向"**人在回路外**"的智能管控模式。

## 范式转变

| 维度 | 传统飞行规则 | 数字飞行规则 |
|:---|:---|:---|
| **驾驶模式** | 有人驾驶 | 无人驾驶为主 |
| **管控模式** | 有人管控 | 智能管控 |
| **人类角色** | 人在回路内（直接操控） | **人在回路外**（监督决策） |
| **技术基础** | 目视飞行、仪表飞行 | 数字低空智能网联体系 |
| **适用场景** | 低密度、同质化运行 | 异构、高频次、大容量、高复杂度 |
| **决策方式** | 飞行员/管制员人工决策 | AI 辅助自动化决策 |

## 核心特征

```
传统模式：  飞行员 → 目视/仪表 → 管制员 → 指令
                （人在回路内）

数字飞行规则：飞行器 → 智能网联 → AI决策 → 执行
                          ↑
                      人在回路外（监督）
```

| 特征 | 说明 | 对子课题3 的影响 |
|:---|:---|:---|
| **无人驾驶** | 飞行器自主飞行，无需人类驾驶员持续操控 | 飞行行为可预测性增强 |
| **智能管控** | AI 系统自动进行冲突探测、路径规划、调度决策 | ST-GNN 预测 + MARL 调度 |
| **人在回路外** | 人类从"操作者"变为"监督者" | 预警系统需支持人机协同 |
| **数字低空智能网联** | 基于 5G-A+北斗的飞行器-地面-卫星互联 | 数据基础设施 |

## 需要解决的关键问题

董志毅指出数字飞行规则需要解决：

1. **异构运行兼容**：有人机与无人机在同一空域融合飞行
2. **高密度管理**：单城市可能同时运行数千架飞行器
3. **大容量处理**：远超人力的并发决策需求
4. **高复杂度协调**：多类型、多优先级、多场景的动态协调

## 与子课题3 的关系

数字飞行规则为子课题3 的三大技术模块提供了**范式层面的需求论证**：

| 子课题3 技术 | 数字飞行规则的需求 |
|:---|:---|
| 多因素耦合容量评估 | 智能管控需要精确知道"当前能容纳多少飞行器" |
| ST-GNN 态势预测 | 自动化决策需要 0-30 分钟高精度预测 |
| 饱和度监测预警 | "人在回路外"模式下，预警系统是人类的最后安全屏障 |

# 低空功能分层

## 定义

**低空功能分层**是由中国科学院院士闫楚良（北京航空航天大学教授）在 2024 年成都低空经济大会上提出的低空空域垂直功能划分方案。该方案将 3000 米以下低空空域按功能划分为三个层级，分别服务于不同的经济和社会目标。

## 三层架构

```
┌─────────────────────────────────────────┐
│  3000 米  │  一小时交通圈                  │
│           │  城际互联互通天路网              │
│           │  跨城市快速出行                  │
├─────────────────────────────────────────┤
│  1500 米  │  县乡村电商与快递物流            │
│           │  乡村振兴基础设施                │
│           │  农村快递配送体系                │
├─────────────────────────────────────────┤
│  1000 米  │  智慧作业园                    │
│           │  新型智慧城市                   │
│           │  城市治理/应急救援/快递物流       │
└─────────────────────────────────────────┘
```

## 各层详解

| 高度层 | 功能定位 | 核心应用 | 适用载具 | 容量评估要点 |
|:---|:---|:---|:---|:---|
| **3000m** | 一小时交通圈 | 城际客运、跨城通勤 | eVTOL、小型固定翼 | 城际航路容量 |
| **1500m** | 电商快递物流 | 县乡村物流配送 | 旋翼无人机、中型货运无人机 | 乡村空域利用率 |
| **1000m** | 智慧城市作业 | 城市治理、应急救援、末端配送 | 小型旋翼无人机 | 高密度城市网格容量 |

## 城乡分类施策

闫楚良特别强调**城乡差异化**策略：

| 区域 | 重点场景 | 推荐载具 |
|:---|:---|:---|
| **城市** | 智慧城市建设、城市治理、应急救援 | eVTOL、小型无人机 |
| **乡村** | 电商平台、快递物流、乡村振兴 | 旋翼无人机（起降无需机场，机动性好） |

> "旋翼无人机或将是未来我国航空产业重点发展的领域和经济快速增长点。" —— 闫楚良

## 与已有分层方案的对比

| 方案来源 | 分层粒度 | 侧重点 |
|:---|:---|:---|
| G/W 类（国家空域分类） | G 300m / W 120m | 管制属性划分 |
| 任和（2026） | 20m 或 200m 间隔 | 技术分层参数 |
| **闫楚良（2024）** | **3000/1500/1000m** | **功能用途划分** |
| 董志毅（2025）网格化 | 未指定具体数值 | 管理单元划分 |

## 与子课题3 的关系

闫楚良的功能分层为子课题3 的容量评估提供了**垂直维度的功能分区框架**：

- 不同高度层的飞行密度和载具类型差异显著 → 容量模型需按层差异化参数
- 1000m 以下城市层密度最高 → 核心评估层
- 1500-3000m 城际层速度最快 → 安全间隔需求不同

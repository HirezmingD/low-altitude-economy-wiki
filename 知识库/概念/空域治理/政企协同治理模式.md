# 政企协同治理模式

> 梳理低空经济/AAM领域三种主要的政企协同治理模式——日本"政企协议会"、GCC"主权保留+特许经营"、中国"军地民协同"——分析各自的制度逻辑、协同深度和适用条件。为子课题3的治理维度→容量约束映射提供制度基础。

## 一、三种模式对照

| 维度 | 日本·政企协议会 | GCC·PPP主权保留 | 中国·军地民协同 |
|:---|:---|:---|:---|
| **核心机制** | 国交省+经产省联合协议会 | 主权保留战略资产+竞争性特许经营 | 军方+地方政府+民航三方协调 |
| **设立时间** | 2018年 | 2020s（GCAA/GACA并行） | 2010年低空空域管理改革启动 |
| **参与主体** | 政府双部门+飞行器开发+运营+垂直起降场+铁路/轨道运营商 | 政府（GCAA/GACA）+主权基金（PIF/穆巴达拉）+国际运营商 | 军方（空军/战区）+地方政府+民航局+公安部 |
| **协同深度** | 覆盖全产业链→路线图/ConOps/年度计划三级联动 | 政府保留空域/基础设施所有权→运营权特许经营→竞争性招标 | 空域划设→军地协商；飞行审批→多级贯通；监管平台→地方主导 |
| **约束力** | 非法律但行业共识驱动（实质约束） | 法律+合同+监管沙盒 | 行政命令+条例+试点授权 |
| **决策节奏** | 年度会议+路线图修订（按需） | 分阶段许可+定期审核 | 试点→推广渐进 |

## 二、日本·政企协议会模式

### 2.1 制度架构

```
国土交通省 + 经济产业省（联合召集）
        │
        ├── 飞行器开发企业（型式认证+技术研发）
        ├── 运营企业（航线规划+商业模式）
        ├── 垂直起降场企业（基础设施建设）
        ├── 交通运营商（★JR东日本/大阪地铁——多模式衔接）
        └── 研究机构（技术验证+标准制定）
```

### 2.2 运作机制

| 机制 | 说明 |
|:---|:---|
| **年度会议** | 第12次（2026.03.27）——审议路线图修订+ConOps更新+年度工作方向 |
| **路线图修订** | 产业发展关键节点触发（如大阪世博会闭幕→社会实施阶段） |
| **ConOps同步** | 路线图时间节点→ConOps航行场景细化→技术成熟度要求对齐 |
| **新成员准入** | 协议会审议通过（本次新增3家：大阪地铁+白银技研+JR东日本） |

### 2.3 核心优势

- **产业链共识驱动**：路线图不是政府单方面规划，而是全产业链协商共识——执行阻力小
- **双部门联合**：国交省（交通/空域）+经产省（产业/制造）——避免部门分割
- **铁路跨界整合**：JR东日本加入→AAM嵌入综合交通网络而非独立发展

### 2.4 适用条件

- 产业龙头集中（丰田/ANA/JAL/NEC/日立等可代表全产业链）
- 政府产业政策传统强（通产省→经产省路径依赖）
- 市场空间有限→需政府协调避免过度竞争

### 2.5 企业实践案例（★③补充·实践层）

#### 大阪地铁——地方政府特许经营PPP

| 要素 | 详情 |
|:---|:---|
| **运营商资格** | 大阪市"飞行汽车场外起降场运营商"公开招募→大阪地铁入选——地方政府与企业特许经营 |
| **垂直起降场建设** | 大阪港垂直起降场（2025.03）+ 森之宫楼顶垂直起降场（2028年目标） |
| **企业性质** | 公营改制股份公司（2018年大阪市交通局→Osaka Metro株式会社）——混合所有制基础 |
| **商业合作** | 2026.03与Soracle株式会社签署商业运营基本协议——公私合资推进 |
| **模式特征** | ★"地方政府公开招募→公营改制企业承接→私营伙伴联合运营"三层PPP |

#### JR东日本——协议会嵌入路径

| 要素 | 详情 |
|:---|:---|
| **加入协议会** | 2026年第11次会议正式加入→从企业自主探讨到国家战略框架嵌入 |
| **资产策略** | 既有直升机停机坪改造（新宿）——利用现有基础设施而非新建 |
| **网络叠加** | 铁路网络→垂直起降场网络，"干线铁路+支线飞行"立体重叠 |
| **价值主张** | 为协议会提供"铁路资产×AAM"整合方案——补足AAM讨论中缺失的多模式衔接维度 |

#### ★ 制度基础：国交省统管铁路+航空

| 国家 | 铁路监管 | 航空监管 | 跨界协调成本 |
|:---|:---|:---|:---|
| **日本** | 国土交通省（同一部门） | 国土交通省（同一部门） | **低——部门内协调** |
| 中国 | 国家铁路局/国铁集团 | 中国民航局（CAAC） | **高——跨部门协调** |
| 美国 | FRA | FAA | **高——跨部门协调** |

> 日本国交省同时管辖铁路和航空，使铁路企业跨界AAM的监管路径天然通畅。大阪地铁和JR东日本可以从"铁路运营商"顺利转型为"综合交通运营商（含AAM）"——这是日本"铁路跨界AAM"全球独特性的制度基础，也是其他分治国家难以复制的结构性优势。

## 三、GCC·PPP主权保留模式

### 3.1 制度架构

```
政府（GCAA/GACA）
    │
    ├── 战略资产（空域/垂直起降场/通信导航）→ 政府永久保留所有权
    ├── 运营权 → 竞争性特许经营（5-15年）
    ├── 融资 → 主权基金（PIF/穆巴达拉）+ 国际资本
    └── 监管沙盒 → GCAA/GACA并行验证→快速迭代
```

### 3.2 核心特征

| 特征 | 说明 |
|:---|:---|
| **主权保留** | 空域+起降场+通信导航→政府永久所有，不可私有化 |
| **运营分离** | 运营权通过竞争性招标授予（5-15年特许经营） |
| **资本先行** | 主权基金直投（PIF $925B/穆巴达拉 $300B）→基础设施建设先于运营需求 |
| **监管并行** | GCAA（阿联酋）+GACA（沙特）独立验证→结果互认 |

### 3.3 适用条件

- 强主权资本（石油美元/主权基金）
- 空域从零规划（无历史包袱的绿色城市项目NEOM等）
- 气候极端约束（高温/沙尘→技术验证必须先于部署）

## 四、中国·军地民协同模式

### 4.1 制度架构

```
中央军航（空军→战区空军→空军基地）
    │                    │
    ├── 空域划设审批 ────┤
    │                    │
    ├── 民航局（地区管理局→监管局）
    │                    │
    └── 地方政府（省级→市级→区级）
                         │
                    低空经济专班/平台
```

### 4.2 现行模式痛点

| 痛点 | 描述 | 福州案例缓解 |
|:---|:---|:---|
| **审批层级多** | 军航4级+民航3级 | "榕智九天"平台简化 |
| **空域释放不足** | 适飞<11%（福州改革前） | →~50% |
| **信息不对称** | 军方不了解地方需求/地方不了解空域状态 | 可计算网格动态释放 |

### 4.3 演进方向（王凯博，2026）

"中央统领·地方主导"——中央负责空域基础分类+安全底线，地方负责适飞空域细化+运营管理+平台建设。一体化综合监管服务平台实现跨部门信息贯通。

## 五、对子课题3的启示

### 5.1 治理模式→容量模型参数

| 治理特征 | 容量模型映射 | 参数影响 |
|:---|:---|:---|
| 政企协议会共识驱动 | 路线图密度时序→需求预测 | 低→中→高→全面的密度参数f_time |
| PPP主权保留 | 基础设施供给确定性 | C_static的下限保障（政府承诺建设） |
| 军地民协同 | 空域释放率→有效容量 | 适飞空域比例×网格动态释放率 |
| 监管沙盒 | 试错空间→创新加速 | 技术验证→容量公式参数校准速度 |

### 5.2 治理协同度→容量折减

治理协同度越高，空域管理制度摩擦越小，有效容量越接近理论容量。可定义：

$$f_{governance} = \frac{C_{effective}}{C_{theoretical}} \in (0,1]$$

- 日本（协议会共识）→ f_governance ≈ 0.85-0.95（产业协同→执行效率高）
- GCC（主权保留+监管沙盒）→ f_governance ≈ 0.80-0.90（资本驱动→建设快但运营竞争待验证）
- 中国（军地民协同）→ f_governance ≈ 0.50-0.75（多级审批→制度摩擦→福州改革<11%→50%即为例证）

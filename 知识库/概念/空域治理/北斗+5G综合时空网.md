# 北斗+5G综合时空网

## 定义

北斗+5G综合时空网是以北斗卫星导航系统为全域时空基准、以5G蜂窝网络为广域覆盖载体的通导融合新型基础设施，以**北斗+5G一体化基站**为核心接入节点，为低空经济提供通信、导航、感知一体化时空服务。

## 四层架构

```
┌──────────────────────────────────────┐
│           应用层                      │
│  巡检/植保/物流/eVTOL/应急/测绘/文旅  │
├──────────────────────────────────────┤
│           空基层                      │
│      无人机中继 + 低轨卫星补盲        │
├──────────────────────────────────────┤
│           地基层（核心枢纽）           │
│  北斗+5G一体化基站（集成BBU/AAU+      │
│  北斗接收+MEC边缘计算+短报文）         │
├──────────────────────────────────────┤
│           天基层                      │
│   北斗GEO/IGSO/MEO 全球PNT基准        │
└──────────────────────────────────────┘
```

## 五大服务能力

| 能力 | 精度/指标 | 低空价值 |
|------|----------|---------|
| 时间同步 | 纳秒级 | 机群协同、多站联合感知 |
| 定位增强 | 厘米级 | 城市峡谷持续定位、精准投递 |
| 协同感知 | 米级追踪 | 全域反黑飞、轨迹溯源 |
| 环境监测 | 实时 | 气象/电磁风险预警 |
| 通信服务 | 大带宽+低时延+海量连接 | 4K/8K航拍、集群指令 |

## 部署策略

**插花式优选改造**：不全部改造483万5G基站，优先选择：
- 开阔无遮挡区（保障北斗信号接收）
- 楼宇峡谷关键点位（消除定位盲区）
- 城市蜂窝六边形组网（多站交叉覆盖）

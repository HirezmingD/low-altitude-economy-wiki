# 三级管控体系（预警-警戒-处置）

## 定义

**三级管控体系**是低空空域安全监管的分级响应框架，由国家信息中心 2026 年政策研究报告提出，包括**预警、警戒、处置**三个逐级升级的管控层级。旨在构建全方位、全时段的精细化安全监管能力。

## 三级结构

```
┌──────────────┐
│    处置       │  ← 突发事件响应、强制干预、应急联动
│   (红色)      │
├──────────────┤
│    警戒       │  ← 异常行为检测、风险升级、重点监控
│   (黄色)      │
├──────────────┤
│    预警       │  ← 常态监测、趋势研判、早期风险识别
│   (绿色)      │
└──────────────┘
```

| 层级 | 颜色映射 | 触发条件 | 响应动作 |
|:---|:---|:---|:---|
| **预警** | 🟢 绿色 | 常态运行，空域利用率 < 阈值 | 常规监测、流量统计、趋势分析 |
| **警戒** | 🟡 黄色 | 空域利用率接近容量上限、异常行为检测 | 加强监控、轨迹追踪、风险研判 |
| **处置** | 🔴 红色 | 安全事件发生、空域饱和/超容 | 强制干预、应急响应、空域临时管制 |

## 技术实现方案：低空立体交通红绿灯系统

程承旗（北京大学，2024）提出的**低空立体交通红绿灯系统**是三级管控的工程实现方案：

| 管控层级 | 红绿灯映射 | 网格状态 |
|:---|:---|:---|
| 🟢 预警（常态监测） | 🟢 绿灯 | 网格空旷，飞行器数量 < 容量 |
| 🟡 警戒（异常检测） | 🟡 黄灯（子课题3 补充） | 飞行器数量接近容量上限 |
| 🔴 处置（强制干预） | 🔴 红灯 | 网格内有建筑/障碍/超饱和 |

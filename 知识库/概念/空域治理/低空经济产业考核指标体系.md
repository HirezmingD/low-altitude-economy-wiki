# 低空经济产业考核指标体系

> 以密歇根OFME六维KPI框架为核心参照，系统梳理省市级低空经济产业考核的指标维度、设计原则和数据采集机制。**中国当前缺乏统一的省市级低空经济考核标准——密歇根框架为首个可参照的国际模板。**

## 一、密歇根六维KPI框架

### 1.1 框架总览

| 维度 | 核心逻辑 | 指标数 | 报告频率 |
|:---|:---|:---|:---|
| **基础设施与部署能力** | 供给侧——空域可运行性 | 6项 | 半年/年度 |
| **生产能力激活** | 供给侧——产业可制造性 | 3项 | 半年/年度 |
| **公共部门应用与商业市场** | 需求侧——市场可实现性 | 3项 | 半年/年度 |
| **劳动力发展** | 供给侧——人才可持续性 | 3项 | 年度 |
| **公众理解** | 需求侧——社会可接受性 | 3项 | 半年/年度 |
| **外部资金争取** | 供给侧——资本可获得性 | 2项 | 年度 |

### 1.2 指标设计四要素

密歇根框架每项指标均包含：

| 要素 | 说明 | 示例 |
|:---|:---|:---|
| **指标名称** | 明确的度量对象 | "基础设施节点数量" |
| **数据口径/定义** | 精确的统计方法和范围 | "包括飞行保障系统（雷达）以及接收AAM/UAS飞行信息的地面和/或通信系统" |
| **报告频率** | 数据更新周期 | 半年/年度 |
| **基线状态** | 截至报告期的实际数据 | "8个节点" |

> ★ 这一"指标-口径-频率-基线"四要素设计，确保指标可采集、可比较、可追溯——是中国省市AAM考核体系应直接借鉴的核心方法论。

## 二、指标体系的设计原则

基于密歇根框架提炼的五项通用原则：

| 原则 | 密歇根实践 | 对中国的启示 |
|:---|:---|:---|
| **供需双侧覆盖** | 基础设施+制造（供给）+ 公共应用+公众理解（需求） | 中国当前考核偏重产值/企业数（供给端），需求端（公众接受度/公共安全）指标缺失 |
| **框架先于数据** | 多项TBD——先定义"度量什么"再解决"怎么采集" | 中国可先建立框架共识，TBD指标标注数据可得性时间表 |
| **频率分层** | 半年（运营类）+ 年度（结构类） | 避免"一刀切"年度考核——运营指标需更高频次 |
| **口径可追溯** | 每项明确牵头部门和数据来源 | 中国需打破部门数据孤岛（交通/工信/公安/应急） |
| **基线+目标双轨** | 2025.12基线→2026目标隐含在优先事项中 | 中国应建立"现状基线→年度目标→长期愿景"三级考核 |

## 三、对中国的适用性分析

### 3.1 可直接借鉴的维度

| 密歇根维度 | 中国对应 | 适用性 |
|:---|:---|:---|
| 基础设施节点 | 空域网格单元/起降点/通信基站 | ★★★ 直接适用 |
| BVLOS豁免数量 | 超视距飞行审批数量 | ★★★ 直接适用 |
| 测试场数量 | 适飞空域试点/测试基地 | ★★★ 直接适用 |
| 供应商/制造商 | 低空经济产业链企业 | ★★★ 已有统计基础 |
| 公共安全响应 | 应急救援/医疗配送次数 | ★★★ 直接适用 |
| 政策法规数量 | 地方低空经济立法/标准 | ★★★ 直接适用 |

### 3.2 需要调整的维度

| 密歇根维度 | 中国差异 | 调整建议 |
|:---|:---|:---|
| 国防资产部署 | 中国军民航协同体制不同 | 改为"军地民协同演练/测试次数" |
| 联邦资金争取 | 中国以地方财政+专项债为主 | 改为"省级专项资金+社会资本撬动" |
| Part 108运营主体 | 中国无对应法规 | 改为"无人机运营合格证数量" |
| 全州采购优先（Buy Michigan） | 中国地方保护敏感 | 改为"本地企业中标率/市场份额" |

### 3.3 中国特有需新增的维度

| 新增维度 | 理由 |
|:---|:---|
| **空域资源释放率** | 中国核心约束在空域供给侧——福州<11%→~50%的量化逻辑应标准化 |
| **跨部门协同效率** | 军地民协同是中国独有制度特征——审批时效/协同演练频次 |
| **标准制定参与度** | 深圳30+地方标准→标准化进度应纳入考核 |
| **碳排放/噪声约束** | 中国"双碳"目标+城市噪声投诉——巴黎研究的可持续性维度中国化 |

## 四、子课题3关联：KPI→容量评估指标映射

### 4.1 供给端→容量上限指标

| KPI指标 | 容量评估映射 | 映射逻辑 |
|:---|:---|:---|
| 基础设施节点数量 | C_static（静态容量基准） | 节点密度→空域可服务单元数量 |
| BVLOS豁免数量 | 走廊容量（corridor capacity） | 豁免=走廊开通→可叠加容量 |
| 测试场数量 | 空域类型多样性系数 | 不同测试场景→多用户空域容量加权 |
| 垂直起降场数量 | 节点吞吐容量（throughput） | 起降场=容量瓶颈节点 |
| 供应商/制造商数量 | 产业驱动因子 f_industry | 制造产能→飞行器部署密度→容量需求 |

### 4.2 需求端→容量压力指标

| KPI指标 | 容量评估映射 | 映射逻辑 |
|:---|:---|:---|
| C-UAS追踪违规率 | f_safety（安全折减因子） | 30.5%违规→安全容量需打折扣 |
| 公共安全响应次数 | 应急容量预留比例 | 338次响应→需预留应急容量 |
| 公众外联活动 | f_social（社会接受度→容量上限） | 44场活动→社会接受度提升→容量释放 |
| 采购承诺/收入 | 经济密度→容量需求推导 | 经济密度与空域需求密度正相关 |

## 五、国际对比

| 维度 | 密歇根（美国州级） | 深圳（中国市级） | 安徽（中国省级） |
|:---|:---|:---|:---|
| **考核框架成熟度** | ★★★★ 六维18项/四要素设计 | ★★ 产值+企业数为主 | ★★ 场景数+航线数为主 |
| **空域供给侧指标** | ★★★★ 节点+豁免+测试场 | ★★★ 309空域+1200起降点 | ★★★ 54空域+43航线 |
| **产业供给侧指标** | ★★★★ 供应商+投资+引入企业 | ★★★ 1700+企业+1300亿 | ★★★ 200+企业+亿航基地 |
| **需求侧指标** | ★★★★ 公共应用+公众认知 | ★★ 1000航线（供给端思维） | ★★ 四场景（定性为主） |
| **数据采集机制** | ★★★★ 半年/年度/多部门协同 | ★ 缺乏公开系统框架 | ★ 缺乏公开系统框架 |
| **TBD透明度** | ★★★★★ 坦率标注 | — | — |

> ★ 核心差距：中国省市低空经济考核偏重"产出端"（产值/企业数/场景数），缺乏密歇根框架的"能力端"（基础设施节点/豁免/测试场/数据采集机制）和"社会端"（公众认知/安全响应/劳动力）。

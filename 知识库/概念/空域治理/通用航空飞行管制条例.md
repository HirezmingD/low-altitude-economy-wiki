# 通用航空飞行管制条例

## 定义

[《通用航空飞行管制条例》](知识库/政策/中国/通用航空飞行管制条例.md)是规范中国通用航空飞行活动、保证飞行安全的重要行政法规。其核心内容包括临时飞行空域的划设与批准、飞行计划的申请与审批、空域使用的组织与责任，以及升放气球活动的特殊规定。

> 与[《国家空域基础分类方法》](知识库/概念/空域治理/空域分类制度.md)（定义"空域是什么类型"）和[《无人驾驶航空器飞行管理暂行条例》](知识库/政策/中国/无人驾驶航空器飞行管理暂行条例.md)（定义"无人机怎么飞"）不同，本条例定义的是**通用航空的运营节奏**——"何时申请、多久批复、怎么使用"。

## 临时飞行空域管理

### 申请内容

申请划设临时飞行空域须向飞行管制部门提交：
- 水平范围和高度
- 飞入和飞出方法
- 使用时间
- 飞行活动性质
- 其他有关事项

### 批准权限（四级层级）

| 空域范围 | 批准部门 |
|:---|:---|
| 机场区域内 | 负责该机场飞行管制的部门 |
| 超出机场区域、在飞行管制分区内 | 负责该分区飞行管制的部门 |
| 超出飞行管制分区、在飞行管制区内 | 负责该管制区飞行管制的部门 |
| 在飞行管制区间 | **中国人民解放军空军** |

> 批准部门需报上一级备案，并通报有关单位。

### 时限参数

| 环节 | 时限 | 说明 |
|:---|:---|:---|
| 申请提交 | 拟使用前 **7个工作日** | 向飞行管制部门提出 |
| 审批决定 | 拟使用前 **3个工作日** | 批准或不批准，通知申请人 |
| 使用有效期 | 最长 **12个月** | 可报原批准部门同意后延期 |
| 任务完成后 | 及时报告 | 临时空域即行撤销 |

> 其他单位/个人因飞行需要，经批准部门同意，也可使用已划设的临时飞行空域。

## 飞行计划申请与审批

### 申请内容

飞行计划申请须包含：飞行单位/任务性质、机长姓名代号/空勤组人数、航空器型别和架数、通信联络方法/二次雷达应答机代码、起降机场/备降场、预计飞行时间、气象条件、航线/高度/范围、其他特殊保障需求。

### 三类审批时限

| 计划类型 | 申请时限 | 批复时限 | 适用场景 |
|:---|:---|:---|:---|
| **常规计划** | 拟飞行前1天 **15:00前** | 拟飞行前1天 **21:00前** | 一般通用航空飞行 |
| **紧急计划** | 拟飞行 **1小时前** | 拟起飞时刻 **15分钟前** | 紧急救护、抢险救灾、人工影响天气等 |
| **短期计划** | 申请空域时一并提出 | — | 临时空域内 **15天内** 的飞行，无需逐日申请 |

> 短期计划每日飞行开始前和结束后需及时报告。

### 需提交任务批准文件的特殊情形

- 飞出或飞入我国领空（公务飞行除外）
- 进入空中禁区或国（边）界线至我方一侧10公里之间地带上空
- 在我国境内进行航空物探或航空摄影活动
- 超出领海（海岸）线飞行
- 外国航空器或外国人使用我国航空器在我国境内进行通用航空飞行活动

## 空域使用责任与通信

| 维度 | 规定 |
|:---|:---|
| **安全责任主体** | 从事通用航空飞行活动的单位/个人**自行组织实施**，并对其安全负责 |
| **通信要求** | 与有关飞行管制部门建立可靠的通信联络；临时空域内保持空地联络畅通 |
| **管制服从** | 飞行管制部门可责令违反管制规定的航空器改正或停止飞行 |
| **飞行中特情** | 及时向民航管制单位提供信息，按指令采取措施 |

## 升放气球活动的特殊规定

> 升放无人驾驶自由气球和系留气球同样对空域安全存在影响，纳入本条例管理。

| 项目 | 规定 |
|:---|:---|
| 升放批准 | 设区的市级以上气象主管机构会同有关部门批准 |
| 自由气球空域申请 | 拟升放 **2天前** 持批准文件向飞行管制部门申请 |
| 自由气球批复 | 拟升放 **1天前** 作出决定 |
| 系留气球高度 | 不得高于地面 **150m**（低于距其50m范围内建筑物顶部除外） |
| 系留气球标识 | 超过地面 **50m** 须加装**快速放气装置**并设置识别标志 |
| 异常报告 | 非正常运行或意外脱离时须立即报告飞行管制部门和气象主管机构 |

## 与子课题3 的关联

| 条例要素 | 对容量评估的影响 |
|:---|:---|
| **临时空域 7工作日前申请** | 计划性容量调整的**最短提前期**——决定了长期规划阶段的输入窗口 |
| **飞行计划 15:00→21:00** | 次日容量**预分配截止时间**——战略阶段的关键时间节点 |
| **紧急计划 1h→15min** | 应急容量的**最快响应速度**——战术阶段的时效边界 |
| **临时空域最长12个月** | 容量模型的**长期规划时间窗** |
| **短期计划 15天** | 稳定运行期无需每日重新分配——预战术阶段的批量处理模式 |
| **安全责任主体自负** | G/W 类非管制空域内，容量管理的责任从 ATC 转移到运营人自身 |

> **核心洞察**：条例定义的运营时限（7天→3天→1天→1小时→15分钟）构成了容量管理的**时间粒度层级**——长期规划（周级）→ 战略（天级）→ 预战术（小时级）→ 战术（分钟级），与 DCB 五阶段流程形成时间对标。

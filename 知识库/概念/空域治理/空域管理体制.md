# 空域管理体制

## 定义

空域管理体制是指国家对空域资源进行规划、分配和使用的组织架构、权限划分和运行机制的总称。中国的空域管理体制以"国家统一管理、空军统一组织实施"为核心特征。

## 现行体制框架

### 领导机构
- **国务院、中央军事委员会空中交通管制委员会**领导全国飞行管制工作（《飞行基本规则》§4）
- **国家空中交通管理领导机构**统一领导全国无人驾驶航空器飞行管理工作（《无人驾驶航空器飞行管理暂行条例》§4）

### 执行机构
- **中国人民解放军空军**统一组织实施中华人民共和国境内的飞行管制（《飞行基本规则》§28）
- **国务院民用航空主管部门（民航局）**负责全国民用航空活动统一监督管理（《民航法》§4）
- **各级空中交通管理机构**负责本责任区内无人驾驶航空器飞行管理（《暂行条例》§4）

### 责任区划分（《飞行基本规则》§30）
```
飞行管制区 → 飞行管制分区 → 机场飞行管制区
高空管制区 → 中低空管制区 → 终端(进近)管制区 → 机场塔台管制区
```

## 空域分类体系

### 传统分类（《飞行基本规则》§12）
- 机场飞行空域、航路、航线
- 空中禁区、空中限制区、空中危险区
- 空中走廊、空中放油区、临时飞行空域

### 新分类标准（《国家空域基础分类方法》，部门规范性文件）
> ⚠️ 《国家空域基础分类方法》已发布但《空域管理条例》仍为征求意见稿，两者关系待明确

| 类别 | 描述 |

| B类 | 中低空管制空域 |
| C类 | 进近管制空域 |
| D类 | 机场管制空域 |
| E类 | 非管制空域 |
| G类 | — |
| W类 | — |

## 关键制度

- **飞行预先申请制度**："所有飞行必须预先提出申请，经批准后方可实施"（《飞行基本规则》§35）
- **隔离飞行原则**：无人驾驶航空器通常应当与有人驾驶航空器隔离飞行（《暂行条例》§22）
- **临时飞行空域**：通用航空可申请不超过12个月的临时飞行空域（《通用航空飞行管制条例》§10）

## 体制改革方向

- 新《民航法》§225要求"优化低空空域资源配置"
- 《空域管理条例（征求意见稿）》若正式通过，将可能改革现有体制
- 浙江省（课题所在地）的低空经济示范区实践可能推动管理体制创新

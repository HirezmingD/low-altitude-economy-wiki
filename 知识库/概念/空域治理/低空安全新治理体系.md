# 低空安全新治理体系

## 定义

**低空安全新治理体系**是由董志毅（中国民航局原副局长）2025 年提出的低空安全治理框架，核心理念是"**审慎包容**"——"只有管得住才能放得开，管不住就放不开，管得好才能用得久"。该体系旨在统筹发展与安全，构建"行业管理+社会管理"的分级分类多元治理模式。

## 核心理念

```
       审慎 ←─────────────→ 包容
        │                      │
   安全可控                  激发活力
   管得住                   放得开
   管得好                   用得久
        └──────────┬──────────┘
             高水平安全保障
             高质量发展
```

## 体系性安全挑战

低空安全涵盖四个维度：

| 维度 | 内容 | 对子课题3 的影响 |
|:---|:---|:---|
| **国家空防安全** | 敏感区域保护、空域管控 | 容量模型的禁飞区约束 |
| **航空器飞行安全** | 冲突避撞、安全间隔 | ★ 容量模型的饱和度上限 |
| **社会公共安全** | 天津机场事件、隐私保护 | ★ 饱和度预警的触发阈值 |
| **赛博空间安全** | 网络安全、数据安全、内生安全 | 容量模型的数据安全约束 |

## 安全事件实证

### 天津滨海机场无人机扰航事件（2024.09.11）

- 中国**大型枢纽机场首次因无人机**导致长时间停航
- 持续时间：**近 11 小时**
- 性质：公共安全原因
- 意义：为饱和度预警的"红色"触发条件提供了真实参照

## 在子课题3 中的定位

低空安全新治理体系为子课题3 的"评估-预警-调控"闭环提供了**安全治理维度的顶层框架**：

| 治理体系支柱        | → 子课题3 技术需求      |
| :------------ | :--------------- |
| 空域资源释放（网格化剖分） | → 容量评估的空间单元定义    |
| 数字飞行规则（人在回路外） | → 态势预测自动化 + 智能调控 |
| 安全管理体系（分级分类）  | → 红-黄-绿三级饱和度预警   |
| 内生安全（数字底座）    | → 容量模型的数据基础设施安全  |

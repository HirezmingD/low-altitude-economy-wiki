# 低空立体交通红绿灯系统

## 定义

**低空立体交通红绿灯系统**是由北京大学程承旗教授团队提出的低空空域管理技术方案，以《北斗网格位置码》国家标准为基础，将低空空域划分为 **10m 或 20m** 见方的立体网格，每个网格根据其占用状态显示红灯（禁飞）或绿灯（可飞）。该系统被程承旗称为"目前解决低空空域管理的**最佳方案之一**"。

## 工作原理

```
┌─────────────────────────────────────┐
│      低空立体交通红绿灯系统           │
├─────────────────────────────────────┤
│                                     │
│   立体网格（10m 或 20m 见方）         │
│   ┌───┬───┬───┬───┐                │
│   │ 🔴│ 🟢│ 🟢│ 🔴│                │
│   ├───┼───┼───┼───┤                │
│   │ 🟢│ 🟢│ 🔴│ 🟢│                │
│   ├───┼───┼───┼───┤                │
│   │ 🟢│ 🔴│ 🟢│ 🟢│ ← 10m 粒度      │
│   └───┴───┴───┴───┘                │
│                                     │
│   🔴 红灯 = 网格内有建筑/障碍物/禁飞   │
│   🟢 绿灯 = 网格空旷，可飞行          │
│   🟡 黄灯 = 饱和度警戒（子课题3 补充） │
└─────────────────────────────────────┘
```

## 核心判断逻辑

| 信号 | 条件 | 飞行许可 |
|:---|:---|:---|
| 🔴 **红灯** | 网格内有建筑、障碍物、禁飞区、临时管制 | 禁止飞行 |
| 🟡 **黄灯** | 网格内飞行器数量接近容量上限 | 限制准入（子课题3 饱和度预警） |
| 🟢 **绿灯** | 网格空旷，飞行器数量在安全容量内 | 允许飞行 |

> 注：程承旗原文仅提及红/绿两色。🟡 黄灯为子课题3 饱和度预警的自然扩展。

## 与子课题3 的直接映射

子课题3 的"红-黄-绿三级饱和度预警"与程承旗的红绿灯系统**高度吻合**：

| 红绿灯系统（程承旗） | 子课题3 饱和度预警 | 一致性 |
|:---|:---|:---|
| 🔴 红灯 = 网格占用/障碍 | 🔴 红色 = 空域超饱和/不可用 | ✅ 完全对应 |
| （未明确） | 🟡 黄色 = 饱和度警戒 | 子课题3 补充完善 |
| 🟢 绿灯 = 网格空闲 | 🟢 绿色 = 常态运行 | ✅ 完全对应 |
| 10m/20m 网格粒度 | 网格化剖分管理 | ✅ 完全对应 |

## 技术基础

- **编码标准**：《北斗网格位置码》（GB，2021.06.01）
- **理论基础**：GeoSOT 地球立体网格编码理论（北大，24 年研究）
- **产品实现**：低空伏羲 iwhereSky1.0（北斗伏羲公司）
- **试点区域**：北京、浙江、安徽、上海、成都成华区（西南首个低空融合飞行示范项目）

# 无人机分类管理制度

## 定义

无人机分类管理制度是指根据无人驾驶航空器的重量、速度、高度等性能指标将其划分为微型、轻型、小型、中型、大型五类，并基于类别实施差异化监管的法律制度。该制度由[《无人驾驶航空器飞行管理暂行条例》](知识库/政策/中国/无人驾驶航空器飞行管理暂行条例.md)确立（2024年施行）。

## 五级分类标准（《暂行条例》§62）

| 类别 | 空机重量 | 最大起飞重量 | 最大速度 | 其他特征 |
|:---:|:---:|:---:|:---:|:---|
| **微型** | <0.25kg | — | ≤40km/h | 真高≤50m，微功率无线电，全程人工介入 |
| **轻型** | ≤4kg | ≤7kg | ≤100km/h | 空域保持+可靠被监视，全程人工介入 |
| **小型** | ≤15kg | ≤25kg | — | 同上（不含微/轻型） |
| **中型** | — | ≤150kg | — | 不含微/轻/小型 |
| **大型** | — | >150kg | — | — |

> 另有"农用无人驾驶航空器"专门定义：真高≤30m，速度≤50km/h，半径≤2000m，全程人工介入（§62(八)）

## 分类监管要求对比

| 监管要求 | 微型 | 轻型 | 小型 | 中型 | 大型 |
|:---|:---:|:---:|:---:|:---:|:---:|
| 适航许可 | ✗ | ✗ | ✗ | ✓ | ✓ |
| 实名登记 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 操控员执照 | ✗ | ✗ | ✓ | ✓ | ✓ |
| 运营合格证 | ✗ | ✓ | ✓ | ✓ | ✓ |
| 责任保险 | ✗ | ✓ | ✓ | ✓ | ✓ |
| 一体化平台报送 | ✗ | ✓ | ✓ | ✓ | ✓ |
| 广播式识别 | ✓ | ✓ | ✓ | ✓ | ✓ |

## 管制空域与适飞空域

- **管制空域**：真高120m以上、机场周边、军事禁区等区域的空域（§19）
- **适飞空域**：管制空域以外的空域 = 微型/轻型/小型无人机的可飞空域（§19末款）
- 未经批准不得在管制空域内飞行（§19）
- 临时管制空域可在重大活动/紧急任务时增设（§20）

## 融合飞行规则（§22）

| 融合情形 | 条件 | 需批准 |
|:---|:---|:---:|
| 微/轻型在适飞空域 | 自动满足 | ✗ |
| 常规农用无人机 | 自动满足 | ✗ |
| 警/海/应急内部 | 同一单位 | ✓ |
| 大型无人机 | 取得适航许可 | ✓ |
| 中型/小型/轻型 | ≤真高300m | ✓ |

## 特殊飞行免申请情形（§31）

在适飞空域内的微/轻/小型飞行、农用常规作业、警海应急驻地飞行等**无需向空中交通管理机构提出飞行活动申请**，但存在以下情形之一的仍需申请：
- 通过通信基站/互联网中继飞行
- 运载危险品或投放物品
- 飞越集会人群上空
- 移动交通工具上操控
- 分布式操作或集群飞行

## 对课题的意义

- 无人机分类标准直接影响低空物流配送的机型选择和监管路径
- 管制空域划设规则是低空航路规划的关键约束
- 融合飞行制度是多场景共存运行的法律基础
- 农用无人机特殊规则为农林场景提供便利

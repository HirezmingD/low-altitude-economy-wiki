# 网格化剖分管理

## 定义

**网格化剖分管理**是指将城市低空适飞空域按照统一的空间网格单元进行精细划分，实现对低空空域的分区、分层、分时管理。董志毅（2025）明确提出要"对城市适飞空域进行网格化剖分管理，构建全新的时空数据管理引擎，提升低空空域的精细分配与动态管理能力"。

## 网格尺寸标准

| 来源 | 网格粒度 | 编码标准 |
|:---|:---|:---|
| 程承旗（北大，2024） | **10m 或 20m** 见方立体网格 | **北斗网格位置码（GB）** / GeoSOT 编码 |
| 任和（2026） | 20m 或 200m 垂直分层间隔 | — |

> ★ 程承旗团队的 10m/20m 粒度是目前公开文献中最精确的低空网格尺寸参数，基于 GeoSOT 地球立体网格编码理论（973 计划，1997 年起 24 年研究）。

## 核心要素

| 要素       | 说明                                                                                 | 容量评估参数       |
| :------- | :--------------------------------------------------------------------------------- | :----------- |
| **空间网格** | 将空域划分为统一的三维网格单元                                                                    | 空间分辨率、单元基础容量 |
| **高度分层** | G 类（300m 以下）/ W 类（120m 以下）/ 上层管制空域；任和（2026）提出 3000m 以下以 **20m（细粒度）或 200m（粗粒度）** 分层 | 垂直容量分布       |
| **时间切片** | 不同时段的差异化空域配置                                                                       | 时变折减系数       |
| **动态分配** | 基于实时需求的网格资源调度                                                                      | 动态容量参数       |

## 网格的容量属性

每个网格单元承载以下容量相关属性：

| 属性 | 说明 | 来源 |
|:---|:---|:---|
| **静态容量上限** | 基于安全间隔的最大同时飞行器数量 | 空域分类标准 |
| **动态折减因子** | 气象/电磁/风险等因素的容量折扣 | 多因素耦合模型 |
| **时段权重** | 不同时间段的容量波动系数 | 历史流量数据 |
| **优先级标记** | 应急/优先飞行器的容量预留 | 调度策略 |
| **状态指示** | 绿/黄/红三级饱和度 | 实时监测 |

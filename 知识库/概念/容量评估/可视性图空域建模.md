# 可视性图空域建模方法

## 定义

Zhang & Charkhgard (2021) 提出的低空空域航路网络构建方法：基于计算几何中的**可视性图**（visibility graph），以障碍物顶点和起降点为节点，以不被障碍物阻挡的连线为边，构建稀疏但完整连通的高效节点网络——相比栅格化方法大幅减少节点数和计算量。

## 与栅格化方法的对比

| 维度 | 栅格化（Grid-based） | 可视性图（Visibility graph） |
|------|:------------------:|:-------------------------:|
| 节点数 | 极高（分辨率↑→指数增长） | 少（仅顶点+起终点） |
| 最短路径 | 近似（受分辨率限制） | 精确（图上保证） |
| 计算复杂度 | 高（大规模求解困难） | 低（稀疏图） |
| 适用场景 | 全域精细评估 | 高密度航路规划 |

## 构建流程

```
LiDAR数据 → 3D城市地图 → 障碍物多边形提取
        ↓
每飞行层：障碍物轮廓→顶点集合
        ↓
起降点 + 障碍物顶点 → 图节点
        ↓
节点间连线不被障碍物阻挡 → 图边
        ↓
最短路径算法（Dijkstra/A*）→ OD对最短路径
        ↓
全部OD对路径汇总 → 航路网络 + 交叉点数据库
```

## 关键性质

1. **最短路径保证**：任意OD对的最短路径一定在可视性图的边上
2. **稀疏性**：节点数 = 起降点数 + 障碍物顶点数（远少于栅格单元数）
3. **可分层**：每个飞行高度层独立构建可视性图，层间通过起降点连接
4. **精确避障**：边定义即保证不穿过障碍物

## Tampa Bay实例参数

| 参数 | 取值 |
|------|------|
| 起降点 | 30个 |
| 飞行层 | 10层 (500-1400ft) |
| 障碍物 | 建筑物群→长方体近似 |
| 禁飞区 | 7个机场周边 |
| LiDAR | 2007年佛罗里达州数据 |

## 与子课题3的关系

- 可视性图为承载力评价提供**高效的空间拓扑基底**
- 节点-边网络天然支持容量/流量分析
- 相比栅格化，更适合高密度场景的承载力计算

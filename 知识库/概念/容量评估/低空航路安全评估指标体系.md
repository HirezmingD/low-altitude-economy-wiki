# 低空航路安全评估指标体系

## 定义

低空航路安全评估指标体系是指对低空航路运行安全能力进行系统化、量化评价的多维度指标体系。该体系由中国团体标准《[低空航路运行安全能力评估规范](知识库/政策/中国/低空航路运行安全能力评估规范.md).md)》（T/GITIF 028-2025，征求意见稿）提出，涵盖空域环境、地理环境、通信能力、导航性能、监视能力、电磁环境、基础气象、反制能力共8大类基础静态指标和1类动态气象指标，合计76项二级指标。

> ⚠️ **说明**：本页引用标准为**团体标准征求意见稿**，尚未正式发布，仅供参考研究使用。

## 指标体系总览

```
评估指标体系（76项二级指标）
├── 空域环境（8项）     ← 法规性约束
├── 地理环境（16项）    ← 物理环境约束
├── 通信能力（9项）     ← 信息连通能力
├── 导航性能（7项）     ← 定位精度能力
├── 监视能力（8项）     ← 态势感知能力
├── 电磁环境（6项）     ← 信号纯净度
├── 基础气象（12项）    ← 气候风险统计
├── 反制能力（4项）     ← 安全防护能力
└── 动态气象（6项）     ← 实时运行条件
```

## 8大类指标详解

### 1. 空域环境指标（8项）
评估航路所在空域的法规性约束条件：
- 禁飞区覆盖率、禁飞区与航线间隔
- 空域高度限制、航线交叉点数量、航线垂直最小间隔
- 空域周期规律性（永久/周期/临时）
- 航线管理复杂度、空域管理复杂度（军地民管理部门数量）

### 2. 地理环境指标（16项）
评估地形、障碍物、人口风险、应急设施：
- 地形相对高差、平均坡度、坡度变化率
- 水体/绿地覆盖率
- 竖向超障余度、障碍物密度、障碍物距离
- 平均人口密度、高峰人口密度、人口波动系数
- 重点设施类型/数量/间隔（低/中/高三风险等级）
- 迫降点密度、迫降点面积、迫降点等级

### 3. 通信能力指标（9项）
评估4G/5G/专网通信覆盖质量：
- 通信平均场强(RSRP)、通信覆盖率、平均信噪比(SINR)
- 平均时延、上行/下行平均速率
- 切换成功率、业务掉线率、正常连接率

### 4. 导航性能指标（7项）
评估北斗/GNSS定位精度：
- PDOP/HDOP/VDOP（精度因子）
- 使用/搜索的导航卫星数
- 平均载噪比、导航卫星信号覆盖率（卫星数≥4且PDOP≤6且载噪比≥35dB-Hz）

### 5. 监视能力指标（8项）
评估态势感知系统性能：
- 监视要素完整性（机型、速度、位置、飞手位置等）
- 监视覆盖区域、监视覆盖宽度
- 监视要素精度（位置/速度误差0.8分位数）
- 监视反应时间、监视更新频率

### 6. 电磁环境指标（6项）
评估射频信号质量与干扰程度：
- 背景噪声电平
- 目标信号出现率、目标信号载干比
- 其他信号出现数量、平均强度、时长占比

### 7. 基础气象指标（12项）
评估航路所在区域的气候统计风险：
- 年不利风速日数、年有利风速频率
- 年不利气温日数、年有利气温频率
- 年不利降水日数、年有利降水频率
- 气象要素完整性（7类）、时间更新频率、时间连续性
- 高度空间覆盖能力、水平空间覆盖能力、要素精度

### 8. 反制能力指标（4项）
评估非法无人机防御能力：
- 反制设备布设密度
- 反制频段覆盖能力（100MHz-7000MHz）
- 反制有效防区范围
- 反制处置时间

## 动态气象指标（6项）
实时气象条件修正，用于动态安全评分：
- 平均风速、能见度、降水量(10min)、温度、云底高度、低空风切变

## 与容量评估的关系

该指标体系与空域容量评估的关系如下：

| 维度 | 安全评估指标 | 容量评估对应 |
|:---|:---|:---|
| 空域环境 | 禁飞区覆盖率、高度限制、交叉点 | 可用空域面积、容量基准线 |
| 地理环境 | 障碍物密度、人口密度 | 安全缓冲系数、折减系数 |
| 通信/导航/监视 | 覆盖质量、精度、反应时间 | 技术能力约束、动态容量折扣 |
| 基础/动态气象 | 风速、能见度、降水 | 气象折减系数、动态容量 |
| 综合评价 | 四级安全分级(A/B/C/D) | 容量等级划分 |

> **核心区分**：安全评估回答"航路是否安全"（安全能力），容量评估回答"空域能容纳多少飞行器"（承载上限）。两者互为输入——安全评估指标中的约束条件可直接转化为容量模型的输入参数。

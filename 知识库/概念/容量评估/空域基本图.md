# 空域基本图

## 定义

Mahmassani等（2023）将地面交通流理论的核心概念——**基本图**（fundamental diagram）引入AAM空域：描述空域中航空器密度k与有效流量Q_e之间的**抛物线关系**，存在一个**临界密度**使得流量最大，超过临界密度后流量崩溃——该临界密度即为**空域容量**。

## 数学表达

```
Q_e(k) = k·e_max - √2·a·D_sep·v(k)·k²·T
```

其中：
- Q_e: 有效流量（吞吐量）
- k: 航空器密度
- v(k): 密度依赖的实际速度
- a: 每次冲突的有效速度损失
- D_sep: 间隔要求的横截面积
- T: 时间窗口

## 三段式流量-密度曲线

```
Q_e ↑
  │       ╱‾‾‾╲
  │      ╱      ╲
  │     ╱        ╲
  │    ╱          ╲_______
  │   ╱
  │  ╱
  └────────────────────────→ k
     自由流  过渡区  临界  拥堵区
     Q∝k    Q缓增  Q_max  Q↓
```

| 区域 | 特征 | 物理意义 |
|------|------|---------|
| 自由流 | 低密度，冲突少，Q∝k | 每增加一架即增加流量 |
| 过渡区 | 冲突增加，速度下降 | 边际流量递减 |
| 临界密度 | Q达到最大值 | **= 空域容量** |
| 拥堵区 | 超临界，冲突过多 | 流量崩溃 |

## 与格林希尔兹模型的区别

传统格林希尔兹（Greenshields）模型：v(k)=v_f·(1-k/k_j)，**线性**速度-密度
空域模型：v(k)=v_max/(1+√2·b·D_sep·k·T)，**曲线**关系

**原因**：速度下降由冲突驱动，冲突本身依赖速度——形成自反馈循环。

## 核心洞察

1. **密度↑→冲突∝k²↑**：幂律关系意味着高密度下边际冲突急剧增加
2. **间距是关键杠杆**：减少D_sep直接→减少冲突→提高容量
3. **速度的双刃剑**：更高最大速度→更高容量但也→更低临界密度
4. **容量≠固定值**：取决于间距、速度、冲突解决算法等运行参数

## 与子课题3承载力评价

空域基本图直接对应承载力函数：给定空域参数(D_sep, v_max, a, b)→Q_e(k)曲线→临界密度=承载力上限。

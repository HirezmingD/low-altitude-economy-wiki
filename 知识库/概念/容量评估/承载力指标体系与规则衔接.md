# 子课题3 空域资源承载力 — 指标体系与规则衔接
> 统一梳理子课题3「动态复杂环境下低空空域资源承载力评价与量化技术」的容量等级、运行模式、指标衔接规则。整合知识库中所有容量评估相关文献的核心方法论。

## 一、容量等级统一框架（四阶段递进模型）

现有文献中容量分级散落在不同论文中（李诚龙三阶段、张洪海四阶段、廖小罕结构化/非结构化），统一整合为**四阶段递进模型**：

| 等级 | 密度特征 | 运行模式 | 管控方式 | 安全间隔模型 | 容量度量方法 | 理论锚点 |
|:----:|---------|---------|:----:|:-----------:|------------|---------|
| **L1 稀疏** | 单类飞行器、低密度 | 目视飞行、固定航路、点对点直飞 | VLOS/基础通信监视 | 静态间隔 ≥500m | 等待时间法 Tw≤180s | [[eVTOL航空器UAM交通管理综述\|李诚龙(2020)]] 低密度阶段 |
| **L2 中等** | 2类混行(SPV+HPV)、中密度 | 仪表规则、结构化航路、分层空域 | 准移动闭塞 + 红绿灯 | `H=v²/(2a)+D` | [[CNN-ConvLSTM空域复杂度预测\|SHC复杂度预测]] R²=0.870 | [[eVTOL航空器UAM交通管理综述\|李诚龙(2020)]] 中密度 |
| **L3 高密** | 多类混行、高密度、异质飞行流 | 动态空域配置、柔性航路、三层协同调度 | 移动闭塞 + 航向分离(45°) | `C(n)=20n−0.8^(n−1)` | [[异质飞行流多尺度协同调控\|包杰三层调度]] + Bulusu阈值法 | [[未来UAM管理综述\|张洪海(2021)]] 高级阶段 |
| **L4 饱和** | 全自主AAV、极限密度 | 全动态网络、无固定航路、自主避障 | 机载自主感知与避让 | 基本图 `Q(k)=k·e(k)` | [[空域基本图\|Mahmassani(2023)]] 临界密度 | [[未来UAM管理综述\|张洪海(2021)]] 成熟阶段 |

### 容量等级递进逻辑

```
L1 ──密度增加──→ L2 ──密度增加──→ L3 ──密度增加──→ L4
目视             调度             配置             自主
静态             半动态           动态             全动态
```

每阶段跃迁的触发条件 = SHC复杂度预测值触达当前等级容量上限 → 启动下一等级运行模式。

## 二、规则衔接链：从物理空间到容量输出

承载力评估的完整计算链分为五个步骤，每步有明确的输入→处理→输出：

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  Step 1      │    │  Step 2      │    │  Step 3      │    │  Step 4      │    │  Step 5      │
│  限制区识别   │ →  │  适飞空域计算 │ →  │  安全间隔约束 │ →  │  容量函数    │ →  │  容量等级判定 │
│  (冯明翔)    │    │  (安诣彬)    │    │  (李艳华/召悦)│    │  (包杰/Bulusu)│    │  (综合)      │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
    负空间             正空间             安全瓶颈             容量供给             等级输出
```

### Step 1: 限制区识别（负空间量化）

**来源**：[[多源数据限制区识别|冯明翔等(2025)]]

| 限制因素 | 约束来源 | 定量化方法 | 输出 |
|---------|---------|-----------|------|
| 城市建筑 | 地形图建筑基底+层数 | 建筑占据格网直接剔除 | 建筑约束栅格 |
| 噪声 | 飞行器噪声 A_uav + 传播衰减 f(R) | 敏感区(医院/学校) ≤50dB | 噪声避让栅格 |
| 电磁 | 高压走廊/变电站 | 垂直30m安全间隔 | 电磁约束栅格 |
| 人群聚集 | 人口密度 >1人/m² | 避让距离50m | 人群约束栅格 |

**输出**：限制体栅格集合 **R** = R_building ∪ R_noise ∪ R_em ∪ R_crowd

### Step 2: 适飞空域计算（正空间量化）

**来源**：[[空—地协同低空空域划设技术|安诣彬等(2026)]]

```
适飞空域 = 全域 − ∪R
```

三层指标体系叠加：

| 评估层 | 指标 | 输出类别 |
|:---:|------|:---:|
| 容量 | 障碍物分布 + 冲突避让 + 飞行高度 | — |
| 风险 | 军用空域 + 机场空域 + 敏感要素 | — |
| 需求 | 地面功能 + 产业布局 + 使用需求 | — |

**叠加结果**：禁用区 / 限用区 / 适用区 → **可用空域体积 V_avail**

三维时空管理维度：
- **竖向分层**：0-300m / 300-600m / 600-1000m
- **平面分区**：禁飞 / 物流 / 执法 / 应急 / 商业 / 居民 / 生态 / 交通枢纽
- **分时管控**：高峰 / 平峰 / 低峰

### Step 3: 安全间隔约束

**来源**：[[移动闭塞低空交通系统|李艳华等(2025)]]、[[城市风场栅格化路径优化|张召悦等(2026)]]

#### 3a. 准移动闭塞间隔（L1-L2）

```
自由区(绿灯) → 缓冲区(黄灯) → 闭塞区(红灯)
```

$$H = \frac{v^2}{2a} + D$$

- v：飞行速度，a：制动减速度，D：静态安全余量
- 每分区独占一架航空器

**单航道理论容量**：

$$C_{\text{lane}} = \frac{3600 \cdot v}{H + L_{\text{ac}}} \quad \text{(架次/小时)}$$

#### 3b. 空域分层标准

| 来源 | 分层方案 | 适用 |
|------|---------|:---:|
| [[移动闭塞低空交通系统\|李艳华(2025)]] | 0-500 / 500-1000 / 1000-3000m | 机型+业务分层 |
| [[空—地协同低空空域划设技术\|安诣彬(2026)]] | 0-300 / 300-600 / 600-1000m | 国土空间规划 |
| [[eVTOL航空器UAM交通管理综述\|Metropolis]] | 每90m一层，45°航向区间 | 安全-容量平衡 |

⚠️ **待统一**：子课题3承载力评价选哪个分层标准？

#### 3c. 风场环境约束

**来源**：[[城市风场栅格化路径优化|张召悦等(2026)]]

- CFD三维风场建模 → 立方体栅格化(2m最优)
- 每栅格绑定风速/障碍物/风险等级
- 超风速风险区 → 标记为不可用 → 从 V_avail 中剔除

**风场折减系数**：`β_wind = N_safe / N_total`（安全栅格占比）

### Step 4: 容量函数计算

三条技术路线并行，分别适用于不同时间尺度和应用场景：

| 路线 | 方法 | 时间尺度 | 适用等级 | 输出指标 | 核心公式 |
|------|------|:---:|:---:|---------|---------|
| **规划级** | 冯明翔+安诣彬 适飞空域体积法 | 长期(年/月) | L1-L4 | 静态容量上限 `C_static` | `C_static = V_avail / V_occ` |
| **战术级** | [[CNN-ConvLSTM空域复杂度预测\|SHC复杂度预测]] | 中期(180s) | L2-L3 | 实时复杂度等级 → 预警 | CNN-ConvLSTM, R²=0.870, 26ms |
| **实时级** | [[异质飞行流多尺度协同调控\|包杰三层调度]] + Bulusu阈值 | 短期(实时) | L3-L4 | 可接受延误容量 `C_dyn` | `C(n)=20n−0.8^(n−1)`, 延误<5% |

#### 4a. 包杰三层递进调度性能

| 模型 | 调控维度 | 延误架次 | 空域利用率 |
|------|---------|:---:|:---:|
| Ⅰ | 仅起飞时刻 | 79 | 基准 |
| Ⅱ | +柔性航路 | 31 | +18.2% |
| Ⅲ | +动态空域 | **4** | **+33.7%** |

#### 4b. 三种容量度量范式对比

| 范式 | 核心逻辑 | 优势 | 局限 | 适用等级 |
|------|---------|------|------|:---:|
| **冲突率相变法**(Bulusu) | 冲突率突变=容量极限 | 物理意义清晰 | 依赖特定解脱算法 | L3-L4 |
| **复杂度预测法**(SHC) | ML预测态势→预警容量 | 快速(26ms) | 不给出绝对容量值 | L2-L3 |
| **等待时间法**(赵嶷飞) | Tw≤阈值=容量 | 面向实际操作 | 阈值选取主观 | L1-L2 |
| **基本图法**(Mahmassani) | Q(k)=k·e(k) | 统一理论框架 | 参数需标定 | L4 |

### Step 5: 容量等级判定

综合多指标进行等级判定：

| 判定条件 | 等级 | 运行模式切换 |
|---------|:---:|------------|
| SHC < θ₁ 且 Tw < 180s 且 密度 < k₁ | **L1 稀疏** | 固定航路 + 静态间隔 |
| SHC ∈ [θ₁, θ₂) 且 延误比例 < 5% | **L2 中等** | 准移动闭塞 + 分层空域 |
| SHC ≥ θ₂ 且 延误比例 < 15% 且 C_cross < θ_cross | **L3 高密** | 动态空域 + 柔性航路 + 三层调度 |
| 冲突率趋近相变点 或 Q(k) 趋近峰值 | **L4 饱和** | 全自主避障 + 流量限制 |

> ⚠️ 阈值 θ₁、θ₂、θ_cross 需要通过仿真（BlueSky）和真实数据标定，目前文献中仅有 R² 和相对指标，缺绝对数值标定。

## 三、SHC三层复杂度分量的规则映射

[[CNN-ConvLSTM空域复杂度预测|张云景等(2026)]] 的 SHC 框架与子课题3指标的映射：

| SHC分量 | R² | 物理含义 | 承载力指标映射 | 等级关联 |
|---------|:---:|------|--------------|:---:|
| C_spv (SPV层) | 0.745 | 物流无人机密度+冲突 | 低空物流通道饱和度 | L1→L2 |
| C_hpv (HPV层) | 0.863 | eVTOL航路时序复杂度 | 载人航路容量利用率 | L2→L3 |
| **C_cross (跨层)** | 0.645 | SPV×HPV交互随机性 | **跨层冲突风险度** | L2→L3 关键瓶颈 |
| SHC (综合) | 0.870 | 全域复杂度态势 | **承载力综合预警指数** | 判定等级跃迁 |

**关键发现**：C_cross 是容量瓶颈（精度最低、最难预测），当 C_cross 触达阈值时系统最可能从 L2 跃迁到 L3 或直接从 L3 进入饱和。

## 四、三级容量耦合框架

子课题3需要将三个层级的容量统一耦合：

```
终端节点容量         航路段容量          网络级容量
(赵嶷飞, 起降场)     (李艳华, 单航道)     (包杰, 组合栅格)
       │                  │                    │
       ▼                  ▼                    ▼
  93架次/15min      C=3600v/(H+L_ac)     C(n)=20n−0.8^(n−1)
       │                  │                    │
       └──────────────────┼────────────────────┘
                          │
                          ▼
                  min(终端, 航路, 网络) = 系统容量瓶颈
```

**耦合规则**：
- 终端节点容量（进场等待圈）是系统容量的第一道闸门
- 航路段容量（移动闭塞间隔）是网络流量的第二道闸门
- 网络级容量（栅格组合/动态配置）是整体承载力的上限
- **系统容量 = min(终端, 航路, 网络)**

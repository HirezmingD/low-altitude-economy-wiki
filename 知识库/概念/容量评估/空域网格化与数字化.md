# 空域网格化与数字化

## 定义

廖小罕等（2023）提出的低空空域精细化管理方法：采用**统一网格剖分系统**对格式和类型多样的约束要素进行多级网格剖分，为每一层级任一体块的空间位置赋予**唯一编码**，构建**数字化低空**——每个体块包含空间位置信息、空域性质、风险评级等属性。

## 核心要素

### 网格剖分
- 基于统一网格剖分系统
- 多级剖分：剖分单元大小适应航路宽度要求
- 对建筑物、地形、禁飞区、适飞区、大气边界层湍流等约束要素统一处理

### 唯一编码
- 每一层级的任一体块 → 唯一空间位置编码
- 类似地球剖分网格（如GeoSOT），但聚焦低空垂直维度

### 属性标注
每个体块除空间位置外还包括：
- 空域性质（禁飞/限飞/适飞/缓冲）
- 风险评级
- 障碍物信息
- 气象条件（可附加）

## 与现有概念的关系

| 概念 | 提出者 | 关系 |
|------|--------|------|
| 空域栅格化 | 包杰等(2025) | 空域栅格化是网格化的运营级应用，网格化是栅格化的数据基础 |
| 风场感知栅格 | 张召悦等(2026) | 网格化后可叠加风场层，形成气象感知栅格 |
| 三维栅格限制区 | 冯明翔等(2025) | 场模型+三维栅格与网格化属同一技术路线 |
| 空—地协同划设 | 安诣彬等(2026) | 网格化提供划设的空间数据基底 |

## 对子课题3的意义

1. **承载力评价基础单元**：网格化体块 = 承载力评价的栅格单元
2. **动态属性更新**：风险评级/空域性质可动态更新 → 支持动态承载力评估
3. **多源数据融合**：统一网格编码 → 不同数据源可对齐 → 多因素耦合承载力建模
4. **容量约束空间化**：每个网格的"属性"可包含容量参数（如最大航空器数量）

## 实现路径（天路图）

```
低空空域 → 统一网格剖分 → 唯一编码体元栅格
                              ↓
遥感AI解译 ← 地理约束要素特征库
    ↓
净空边界低空地理网格数据库
    ↓
多级航路网迭代优化
    ↓
三维仿真验证 → 实际飞行验证 → 天路图
```

# 受限空域交叉口容量分析模型

## 定义

Ellerbroek & Knoop (2023) 提出的受限城市空域容量分析模型：当空域被约束为沿道路/水道的单向航路网络时，交叉口成为容量瓶颈——不同来源流的间隔需求差异（S∥=Sh < S+=Sh√2）决定了交叉口最大吞吐量。

## 空域约束假设

- 二维正交网格航路（沿城市道路）
- 单向飞行（对向冲突不可解）
- 速度冲突解脱（无法水平绕行）
- 所有航空器等速巡航V_NR
- 分散式战术间隔管理

## 间隔模型

```
冲突自由飞行距离 S∠(Δψ) = Sh / cos(|Δψ|/2)

同源流间隔：S∥ = S∠(0) = Sh           ← 最小
正交交叉：  S+ = S∠(π/2) = Sh·√2      ← 约1.41倍
```

## 交叉口突破容量

| 条件 | 吞吐量上限 |
|------|:--------:|
| 只有同源流 | q_max = V / Sh |
| 异源流交替 | q_max 下降（因S+>S∥） |
| 含转弯交通 | 进一步下降（跟车需S+间隔） |

**关键假设**：交叉口上游来源交替越少（即同一方向连续通过多架）→有效吞吐量越大。

## 排队效应

当流入率超过交叉口容量→上游排队累积：
- 排队长度L(t) = ∫(q_in - s)·dt
- 延迟d ≈ L/V
- 临界密度点：排队开始无限增长→MFD崩溃

## 与MFD的衔接

```
q_in ↑ → 密度k ↑ → 交叉口饱和 → 排队 → 速度↓ → q_out↓ → MFD峰值→崩溃
```

分析模型聚焦MFD的自由流段和临界密度点（拥堵段假设可通过流入控制避免）。

## 设计启示

| 参数 | 容量优化方向 |
|------|:----------:|
| Sh | 在安全前提下最小化 |
| 交叉口间距 | 增大→减少交叉口数量→提高总容量 |
| 来源交替 | 设计"绿波"批处理→同源连续通过 |
| 转弯 | 减少交叉口转弯需求→纯直行最大化容量 |

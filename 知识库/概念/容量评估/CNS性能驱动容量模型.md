# CNS性能驱动的空域容量模型

## 定义

**CNS性能驱动的空域容量模型**是指将通信（Communication）、导航（Navigation）、监视（Surveillance）三大技术基础设施的性能指标作为空域容量的核心决定因素，建立"CNS 性能→间隔保证→可用容量"的定量传导链条。该概念由 Pongsakornsathien et al.（2025）系统阐述，是目前 LAAM 文献中最完整的 CNS-容量理论框架。

## 理论框架

### 核心传导链条

```
CNS 性能指标
    │
    ├── 通信延迟 → 冲突解决总时间 t_(SA/CA) ↑
    │        └── 安全间隔需求 ↑ → 容量 ↓
    │
    ├── 导航不确定性 σ_GNSS → 位置估计误差 ↑
    │        └── 间隔体积 ↑ → 容量 ↓
    │
    └── 监视跟踪误差 σ_tracking → 入侵检测不确定性 ↑
             └── 间隔体积 ↑ → 容量 ↓
```

### 容量约束的范式转变

| 传统 ATM | LAAM |
|:---|:---|
| 容量约束 = **管制员认知负荷** | 容量约束 = **CNS系统性能极限** + 自动化系统计算负荷 |
| 扇区容量 = 管制员可同时处理的飞机数 | 网格单元容量 = CNS性能允许的最小间隔下的最大通行量 |
| 静态扇区划分 | 基于性能的动态空域准入 |

## 核心方法/模型

### 1. 通信延迟→容量折减

UAM 通信需求（Pongsakornsathien et al.）：
- 低速率 C2 通信：语音和基本遥控
- **高速率遥控驾驶**：高达 100 Mbps
- **延迟要求**：低至 **10 ms**（因运营节奏快、特征距离短）
- **可靠性要求**：99.999%

通信延迟 L 对容量的影响路径：

```
通信延迟 L ↑ → 冲突解决总时间 t_(SA/CA) ↑
    → 安全间隔增大 → 单位时间内可通过的飞行器数 ↓
    → 有效容量 ↓
```

### 2. 导航不确定性→间隔体积→容量

GNSS 用户等效距离误差（UERE）模型：

```
σ_UERE = √(σ²_clk&eph + σ²_iono + σ²_tropo + σ²_noise + σ²_multipath)
```

位置不确定性 = σ_UERE × PDOP

**城市峡谷阈值**：σ_GNSS ≥ W（峡谷宽度，如澳大利亚市中心 W=25m）→ 导航性能判定不足 → **该网格容量 = 0 或受限**

基于性能导航（PBN）适配 LAAM：
- 高 CNS 性能飞行器 → 更小间隔 → 更高容量准入
- 低 CNS 性能飞行器 → 仅限农村/低密度空域运行
- 概念延伸：基于性能的通信和监视（PBCS）→ 基于性能的运行（PBO）

### 3. 监视跟踪不确定性→间隔体积→容量

总跟踪不确定性：

```
σ_tracking = √(σ²_NAV + σ²_com)
```

其中 σ_NAV = GNSS 位置不确定性，σ_com = 通信延迟引起的不确定性。

一次雷达监视误差来源：
- 距离测量误差（σ_RDR_range）：与带宽 B 和 SNR 相关
- 角度测量误差（σ_RDR_angle）：与波束宽度 ν 和单脉冲差斜率 k_m 相关
- 这些误差传播到笛卡尔位置不确定性中

## 在子课题3 多因素耦合模型中的定位

CNS 性能是子课题3 多因素耦合模型的**第六维度**（技术基础设施维度）：

| 因素维度 | 已有覆盖 | CNS 性能维度的补充 |
|:---|:---|:---|
| 气象 | 风速、降水、能见度 | — |
| 生态 | 鸟类活动、栖息地（宦吉娥等，2025） | — |
| 电磁 | 通信干扰、精密仪器保护区 | **CNS 信号质量作为量化指标** |
| 地面风险 | 人口密度、建筑物分布 | — |
| 噪声 | 居民区约束、夜间限飞 | 社会接受度与 CNS 性能无关 |
| **技术基础设施**（新增） | — | **通信延迟、导航精度、监视可靠性 → 折减系数** |

## 在不同文献中的表述差异

| 来源 | 表述 | 侧重点 |
|:---|:---|:---|
| Pongsakornsathien et al. (2025) | CNS 性能是 LAAM 空域建模的关键输入 | 学术综述，提供完整公式 |
| ICAO PBN 手册 | 基于性能导航（PBN） | 传统 ATM，尚未适配 LAAM |
| NASA AAM 倡议 | 基于性能的运行（PBO） | 强调性能差异化准入 |
| 亚马逊提案 | 低配置飞行器→偏远地区；城市需高标准 | 行业实践视角 |
| 董志毅 (2025) | 时空数据管理引擎 | 中国方案的数据底座层 |

## 与本课题的关联

1. **为"电磁"因素提供量化路径**：不再是简单的"禁飞/限飞"二元判断，而是通过 CNS 性能指标的连续变化来折减容量
2. **差异化容量分配**：不同 CNS 性能等级的飞行器可在同一空域中以不同间隔运行，实现精细化容量管理
3. **实证校验**：城市峡谷 W=25m、延迟 10ms、可靠性 99.999% 等具体数值可作为折减系数的标定基准

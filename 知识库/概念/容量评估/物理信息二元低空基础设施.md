# 物理-信息二元低空基础设施

## 定义

黄经南（2026）提出的概念：低空基础设施同时包含**实体物理设施**（起降场、航路）和**数字信息设施**（通信、监视、导航），二者缺一不可，是空地一体交通的核心载体。

## 四大核心约束

| 约束维度 | 具体表现 | 承载力影响 |
|----------|---------|-----------|
| 三维异质城市空间 | 高楼峡谷效应、突变风切变、建筑遮挡 | 有效空域被分割缩窄 |
| 通信监视缺陷 | 信号多径衰减、监控盲区 | 安全管控能力下降，限制密度 |
| 时空潮汐流量 | 日间物流密集、灾害应急过载 | 峰值容量需求远超均值 |
| 空间权属矛盾 | 屋顶起降场→噪声/坠物/隐私邻避 | 社会承载力约束 |

## 四大规划路径

1. **三维选址模型**：突破二维用地思维，统筹建筑高度+空域+通信+微气象多因子
2. **复合集约布局**：起降场地兼顾日常物流+应急救援多重功能
3. **多目标选址**：噪声+安全+公平纳入模型，减少弱势群体负面承载
4. **空域共享机制**：推动土地产权→三维空间资源治理转型

## 与承载力评价的关系

四大约束 = 承载力评价的**四维约束层**：

```
物理约束（建筑+风场） → 张召悦风场栅格
信息约束（通信监视） → 施闯北斗+5G通导一体
流量约束（时空潮汐） → 张云景SHC动态预测
社会约束（权属冲突） → 石春晖低空开发权
```

# 全覆盖路径规划的子区域剖分法

## 定义

徐博等（2015）提出的一种针对凸多边形区域的全覆盖路径规划方法：将作业区域沿指定方向按喷施幅宽**剖分为平行子区域**，通过在子区域边界提取航点生成往复覆盖航线，并通过改变方向角寻找最小多余覆盖率的**最优作业方向**。

## 核心思想

```
凸多边形区域 + 作业方向α
        ↓ 坐标系旋转
平行于α的等间距分隔线（间距=幅宽d）
        ↓ 与边界求交
各子区域起止航点
        ↓ 串联
全覆盖往复航线
        ↓ 遍历α
最优作业方向（最小多余覆盖率）
```

## 关键要素

| 要素 | 定义 | 作用 |
|------|------|------|
| 喷施幅宽d | 单次作业覆盖宽度 | 决定子区域数量 |
| 航向角α | 作业航线相对正北的夹角 | 决定剖分方向 |
| 多余覆盖率ε | (覆盖面积-区域面积)/区域面积 | 优化目标 |
| 子区域 | 两条相邻分隔线之间的条带 | 航线基本单元 |

## 优化逻辑

不同航向角α产生不同的子区域布局→不同的多余覆盖率。遍历α∈[0,π)（步长5°），选择ε最小的α作为最优方向。

## 与空域栅格化的类比

| 子区域剖分法 | 空域栅格化 |
|:----------:|:--------:|
| 剖分单元=幅宽d | 剖分单元=栅格尺寸 |
| 方向=航向角α | 方向=航路方向 |
| 目标=最小多余覆盖 | 目标=最大空域容量 |
| 约束=区域边界 | 约束=障碍物/禁飞区边界 |

⚠️ 方法原理相似但应用场景不同——农业全覆盖 vs 城市空域容量。

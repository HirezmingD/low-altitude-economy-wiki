# 阈值法空域容量评估

## 定义

Bulusu和Polishchuk（UC Berkeley，2017）提出的一种低空空域容量评估数学方法：**将空域容量定义为"随交通密度增加，使空域评估指标发生相变（phase transition）的空中交通量最小值"**。核心逻辑是找到让空域从"安全有序"状态跃迁到"不可接受风险"状态的密度临界点。

## 方法论框架

```
空中交通模型（仿真场景生成）
        ↓
空域评估指标（安全性/效益/吞吐量）
        ↓
随密度增加 → 指标发生相变
        ↓
相变点对应的最小交通量 = 空域容量
```

## 指标演进历程

### v1（2017）：单指标——多机冲突率
- 定义为≥4机同时发生冲突的概率
- 基础证明阈值法可行

### v2（2017）：双指标扩展
- 安全指标：每飞行小时危险接近率
- 效益指标：成本增加量
- **关键发现**：安全可能是空域容量的决定性因素

### v3（2018）：吞吐量指标
- 新增吞吐量空域容量评估指标
- 效益指标修改为飞行时间延长百分比
- 三种冲突解脱算法（悬停避让/人工势场/ICAROUS）对比实验
- **核心结论**：吞吐量比安全/效益更适合作为容量度量指标

## 延伸发现

### 合作 vs 非合作（2017）
- 合作类无人机可有效**提高空域容量**
- 同时减少机载冲突探测/解脱/避让系统的计算复杂度

### 地理围栏对容量影响（KAIST）
- **Geocaging**（禁止飞出围栏）→ 更强鲁棒性 + 最大空域容量
- **Geofencing**（禁止飞入围栏）→ 相对较弱
- 混合围栏未明显优于纯Geocaging

## 与子课题3的关联

| 维度 | 关联 |
|------|------|
| 承载力定义范式 | "相变点=承载力极限"→ 与"复杂度预测"互补（极限判定 vs 趋势预测） |
| 指标体系 | 吞吐量 > 传统安全指标 → 对承载力评价指标选取有方法论参考 |
| 仿真驱动 | 容量评估依赖仿真场景 → 与项目BlueSky仿真平台对接 |
| 合作效应 | 合作类提容 → 为调度优化（如包杰多尺度调控）提供容量上限参考 |

## 局限性

- 单指标阈值可能忽略多因素耦合效应
- 依赖特定冲突解脱算法，算法选择影响容量结果
- 未考虑天气/风场等动态环境因素

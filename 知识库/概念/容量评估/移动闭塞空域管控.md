# 移动闭塞空域管控

## 定义

将铁路列车运行控制中的**移动闭塞**技术引入低空交通，以每架航空器的实时状态（位置、速度）为依据，动态构建"自由区—缓冲区—闭塞区"三级空间结构，通过**红绿灯信号**自动调控航空器间距的管控模式。

## 核心机制

### 三级空间结构

| 区域 | 信号 | 含义 | 行为 |
|------|:--:|------|------|
| 自由区 | 🟢 | 前方安全 | 保持原速飞行 |
| 缓冲区 | 🟡 | 需准备减速 | 以闭塞区始端为目标点，计算制动曲线，择机制动 |
| 闭塞区 | 🔴 | 禁止进入 | 已被前机占用，严禁进入 |

### 准移动闭塞 vs 移动闭塞

| | 移动闭塞 | 准移动闭塞（本文采用） |
|------|----------|----------------------|
| 追踪目标 | 前机尾部 | 前机所在分区始端 |
| 是否需要分区 | 否 | 是（每分区仅一架） |
| 安全冗余 | 低 | **高** |
| 适用场景 | 高铁（可控环境） | **低空（扰动大、需冗余）** |

### 安全间隔公式

$$H = \frac{v^2}{2a} + D$$

其中：v=飞行速度，a=制动减速度，D=纵向安全间隔

### 五类航路场景规则

| 场景 | 特殊规则 |
|------|---------|
| 单一航路 | 后机以前机所在分区始端为追踪点 |
| 平行航路 | 保持横向间隔 Dh |
| 平面交叉口 | 先到先占，交叉分区+邻近分区锁定 |
| 汇聚点 | 两航道均需保持到汇聚点的安全距离 |
| 脱离点 | 脱离后两航道各自独立 |

## 对容量的影响

每分区独占一架航空器 → **单航路理论小时容量**：

$$C_{hourly} = \frac{v}{H + L_{ac}}$$

分区长度越短（更频繁的闭塞切换） → 容量越高，但安全冗余越小。

## 与子课题3的关联

移动闭塞提供了**安全约束维度**的量化模型。承载力评价需综合：(1)安全约束（移动闭塞间隔）+(2)空域供给（栅格容量）+(3)环境约束（风场限制）。

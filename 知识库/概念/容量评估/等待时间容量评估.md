# 进场航线等待时间容量评估

## 定义

赵嶷飞等（2024）提出的城市物流无人机进场航线容量评估方法：以系统**平均等待时间Tw**为度量指标，取Tw处于可接受范围时的**最大无人机架次**作为进场航线容量。

## 方法框架

```
进场航线设计方案参数 → 三维坐标转换
        ↓
生成泊松流进场序列（调整架次N）
        ↓
仿真飞行（顺序向内移动规则）
        ↓
计算Tw = (1/n)ΣΣt_ij
        ↓
Tw ≤ T_threshold? → YES: 增大N, NO: 容量=N
```

## 关键公式

**平均等待时间**：
```
Tw = (1/n) Σ(j=1→n) Σ(i=1→I) t_ij
```
其中：n=进场无人机数量，I=等待圈数，t_ij=第j架在第i圈等待时间

## 深圳实例参数

| 参数 | 取值 |
|------|------|
| 评估时间窗口 | 15分钟 |
| 等待时间阈值 | 180s |
| 到达流 | 泊松流（λ=6架/min额定） |
| 移动速度 | va=5m/s（圈间）, vl=3m/s（下降段） |
| 容量结果 | **93架次/15分钟** |

## 与Bulusu阈值法的对比

| 维度 | Bulusu阈值法 | 等待时间法 |
|------|:-----------:|:---------:|
| 容量定义 | 冲突率相变点 | 等待时间阈值 |
| 适用场景 | 航路空域整体 | 起降场终端 |
| 指标类型 | 安全类（冲突率） | 效率类（等待时间） |
| 仿真方法 | Monte Carlo | 泊松流序列 |

## 对子课题3的意义

- 起降场进场容量→可为承载力评价体系补充"终端节点"维度的容量参数
- 等待时间阈值法→提供了区别于冲突率的第二类容量度量范式
- 混合整数规划+仿真联合→为"设计-评估"一体化方法论提供参考

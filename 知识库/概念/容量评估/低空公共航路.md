# 低空公共航路

## 定义

由廖小罕（中科院地理所）于2017年首次提出：在低空和超低空空域内，为多航空器同时飞行划设的**公共空中通道**。根据低空地理信息约束要素、低空飞行环境、多种载运工具特性、UAM需求等因素综合划设的**结构化航路网络**，面向社会大众多类型航空器、多用户、多行业**共享使用**的固定UAM基础设施。

## 核心特性

| 特性 | 说明 |
|------|------|
| 公共性 | 非专用、非私有，多用户共享 |
| 结构性 | 固定航路网络，约束飞行路径/方向 |
| 基础设施属性 | UAM新型基础设施——IEEE 2021年首个国际标准 |
| 顶层规划性 | 由管理部门"自上而下"规划，非航空器自主规划 |
| 分级性 | 多级航路，不同级别有不同限速/限高/准入条件 |

## 发展历程

| 时间 | 事件 | 意义 |
|------|------|------|
| 2017.09 | 廖小罕首次提出概念 | 概念诞生 |

## 必要性论证

- **规模化需求**：自由飞行 → 航空器数量增加 → 冲突概率指数增长 → 需要结构化约束
- **资源稀缺**：有限低空空域资源 ≠ 庞大航空器空域需求 → 需要高效利用
- **安全底线**：低空公共航路 = "零冲突前提下容纳更多航空器"
- **经济带动**：航路网 → 可达性增加 → 城区规模扩大 → 产业集聚 → 城市沿航路轴向发展

## 与容量评估的关系

1. **航路结构决定容量上限**——水平过度结构化制约容量，垂直分层最大化容量
2. **航路网为容量评估提供空间边界**——没有结构化的航路网络，容量评估缺少物理载体
3. **公共航路约束飞行路径→降低冲突率→提升等效容量**
4. **多级航路网**：不同级别的航路对应不同的容量参数（限速/限流/间隔标准）

## 规划关键技术

1. **约束要素提取**：遥感影像→建筑物/地形/禁飞区/大气边界层湍流等
2. **空域网格化**：统一网格剖分系统→体元栅格→唯一空间编码
3. **路径规划**：改进蚁群算法（徐晨晨等）全局优化
4. **多级航路网**：地理约束要素迭代优化→不同级别的航路网

## 航路网布局三种方式（南洋理工）

| 方式 | 优势 | 劣势 |
|------|------|------|
| AirMatrix仿真 | 系统化管控 | 高自动化要求 |
| 建筑物楼顶 | 结合起降点 | 楼顶权限问题 |
| 道路沿线 | 自然规避建筑物 | 对地二次伤亡风险 |

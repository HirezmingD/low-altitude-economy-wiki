# 杭州低空交通管理服务平台与三张网架构

> **杭州低空交通管理服务平台 1.0**——杭州市级低空交通统一管理平台（已上线试运行）。以"**三张网**"（基础网+航线网+飞服网）为总体架构，覆盖275+起降场、500+航线（2027年目标），支撑79个应用场景、5万架次年飞行量。★场景驱动型低空经济的数字化底座。

## 三张网架构

```
              杭州低空交通管理服务平台
                        │
        ┌───────────────┼───────────────┐
        │               │               │
     基础网           航线网           飞服网
  （物理设施层）    （空域网络层）    （服务管理层）
        │               │               │
   ┌────┴────┐     ┌────┴────┐     ┌────┴────┐
   │         │     │         │     │         │
 起降场    CNS     市内     城际    飞行计划  实时
 (275+)   设施     航线     航线    审批     监控
```

| 网 | 定位 | 核心内容 | 2027目标 |
|:---|:---|:---|:---|
| **基础网** | 物理设施层 | 低空航空器起降场（点）+通信导航监视设施 | ≥275个起降场 |
| **航线网** | 空域网络层 | 市内低空航线+城际低空航线 | ≥500条航线 |
| **飞服网** | 服务管理层 | 统一低空交通管理服务平台——飞行计划审批+实时监控 | 全覆盖（1.0已上线） |

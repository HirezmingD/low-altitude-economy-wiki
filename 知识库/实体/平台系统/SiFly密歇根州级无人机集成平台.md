# SiFly 州级无人机系统集成平台（密歇根）

> **SiFly**——密歇根州OFME（未来出行与电气化办公室）主导的州级无人机系统集成平台。与五大湖无人机系统联盟合作推进，旨在建立覆盖密歇根全州的统一BVLOS测试与运营管理平台。★创下世界纪录——单次飞行26英里（约42km）运送10磅（约4.5kg）载荷。是密歇根AAM战略12个实施项目中的核心数字基础设施。

## 基本属性

| 属性 | 内容 |
|:---|:---|
| **名称** | SiFly（州级无人机系统集成平台） |
| **主导机构** | OFME（密歇根未来出行与电气化办公室） |
| **合作伙伴** | 五大湖无人机系统联盟 |
| **覆盖范围** | 密歇根州全州 |
| **平台类型** | ★州级UTM+BVLOS测试+运营管理 |
| **世界纪录** | 单次飞行26英里（~42km）运送10磅（~4.5kg）载荷 |
| **所属战略** | 密歇根AAM战略12个实施项目之一 |

## 核心能力

| 能力 | 功能描述 |
|:---|:---|
| **BVLOS测试管理** | 州级BVLOS飞行测试的统一审批+监控平台 |
| **走廊管理** | FAA批准的标准BVLOS走廊（物理+数字+数据三统一） |
| **多设施互联** | 连接MUASC/FLITE/Mcity/AAIR/DSPL五大测试设施 |
| **跨境协调** | 美加边境3+1条跨境通道的低空飞行协调 |
| **世界纪录验证** | 26英里/10磅→长距离BVLOS物流可行性实证 |

## 密歇根五大测试设施网络

| 设施 | 类型 | SiFly集成角色 |
|:---|:---|:---|
| **MUASC**（阿尔皮纳） | UAS飞行测试中心 | 测试数据→SiFly统一平台 |
| **FLITE**（大急流城） | 机场AAM试点 | 机场场景→SiFly管理 |
| **Mcity/M-air**（密歇根大学） | 城市环境测试场 | 城市场景→SiFly数据 |
| **AAIR**（底特律创新区） | 商业无人机枢纽 | 商业运营→SiFly协调 |
| **DSPL**（底特律） | 屋顶垂直起降场 | 起降管理→SiFly调度 |

# DACUS 动态容量管理系统（SESAR）

## 概述

**DACUS**（Demand and Capacity Optimisation for U-Space）是 SESAR（单欧洲天空空中交通管理研究计划）下属的专项项目，专门为 U-Space 开发**动态容量块（DCB）**概念和流程。它是目前全球低空容量管理领域最系统化的技术实现方案之一。

## 基本属性

| 属性 | 内容 |
|:---|:---|
| 全称 | Demand and Capacity Optimisation for U-Space |
| 所属体系 | SESAR JU（Single European Sky ATM Research Joint Undertaking） |
| 服务对象 | U-Space 空域（极低空 500-1000 ft） |
| 计划部署 | U3 级别（2027年）成为强制性服务 |
| 核心产出 | DCB 五阶段流程 + 四项核心服务 |

## 低空治理/技术概况

### 设计理念

以**服务为导向**，利用更高水平的自动化，允许实施多种新的商业模式。其核心创新在于：将传统 ATM 中需要数小时的 ATFM 流程压缩到**分钟级**，以适应 LAAM 的高节奏运营需求。

### 四项核心 DCB 服务

| 服务 | 功能 | 技术特点 |
|:---|:---|:---|
| **运营计划编制** | 初步计划起草→一致性验证→概率性 4D 轨迹生成 | 提交后自动验证，无需人工审批 |
| **战略冲突解决** | 与已批准计划比较→冲突风险超限→提出解决方案 | 在考虑任务目标的前提下生成替代方案 |
| **动态容量管理** | 按安全+社会影响指标评估 DCB 措施→监测对任务的影响 | 社会影响指标（噪音/隐私/视觉污染）是创新点 |
| **战术冲突解决** | 实时指令（Zu 区域）或建议（Zz 区域） | 分级响应：指令型 vs 建议型 |

### DCB 五阶段流程

| 阶段 | 时间尺度 | 核心任务 |
|:---|:---|:---|
| 长期规划 | 数月-数年 | 定义容量基线、空域结构 |
| 战略 | 数天-数周 | 运营计划审批、概率冲突预测 |
| 预战术 | 数小时-数天 | DCB 措施评估与选择 |
| 战术 | **数分钟** | 实时冲突解决、应急响应 |
| 后运营 | 事后 | 数据分析、模型校准、指标更新 |

## 关键技术参数

### DCB 措施分类

| 措施类型 | 说明 | 对子课题3的参照 |
|:---|:---|:---|
| **CNS 性能门槛** | 限制低性能飞行器准入 → 释放容量给高性能飞行器 | 多因素耦合模型的"技术基础设施"维度 |
| **任务优先级排序** | 应急>载人>物流>巡检的优先级容量配额 | "评估-预警-调控"的调度策略依据 |
| **临时空域重构** | 突发事件下临时改变空域分类/航线 | 紧急折减系数 |
| **需求平滑** | 通过经济信号（定价）引导飞行需求错峰 | 生产要素逻辑的经济工具化 |

### CNS 性能挑战

DACUS 识别的关键技术挑战：
- 城市环境中无人机密度高 → 通信干扰频率高
- 无人机紧急情况频繁 → 需要更高 LoA
- **高 CNS 性能 → 更小间隔 → 更多容量**（正向激励循环）
- 低 CNS 性能 → 仅能运行于低容量空域

## 演进时间线

| 时间 | 事件 | 意义 |
|:---|:---|:---|
| 2019 | U1 基础服务定义（400ft以下 G 类空域） | 低密度 VLOS 运行 |
| 2022-2024 | U2 初始服务（BVLOS、管制空域接口） | 中密度超视距运行 |
| 2027（计划） | **U3 高级服务 + DCB 成为强制性要求** | 密集郊区+UAM、动态容量管理 |
| 2035+ | U4 全面集成（极高 LoA、ATM-U-Space 融合） | 密集城市、全自主 |

## 与本课题的关联

DACUS 是子课题3 **"评估-预警-调控"闭环**最直接的国际对标系统：

| 子课题3 闭环组件 | DACUS 对应 | 可借鉴的设计要素 |
|:---|:---|:---|
| **评估**（容量量化） | 长期规划 + 战略冲突解决 | 概率性 4D 轨迹 + 冲突风险量化 |
| **预警**（饱和度监测） | 预战术 DCB 措施评估 | 安全+社会影响双指标体系 |
| **调控**（疏导联动） | 战术冲突解决 + 动态容量管理 | 指令型(Zu)/建议型(Zz)分级响应 |

> **差异化创新方向**：DACUS 以"计划驱动"为主（先有飞行计划再调容量），子课题3 可在此基础上增加**"感知驱动"**维度（实时态势→直接触发预警调控），实现更短时间尺度的闭环。

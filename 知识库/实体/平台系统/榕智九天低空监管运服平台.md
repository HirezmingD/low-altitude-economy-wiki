# 榕智九天低空监管运服平台（福州）

> **榕智九天**——福州市级低空监管运服平台，以可计算空域网格为核心技术，实现逐网格动态释放/回收。"军-地-民"三方协同机制下的供给侧空域管理标杆——适飞空域从<11%提升至~50%（约4.5倍增长）。

## 基本属性

| 属性 | 内容 |
|:---|:---|
| **名称** | 榕智九天（市级低空监管运服平台） |
| **部署区域** | 福州（地级市） |
| **核心技术** | 可计算空域网格——逐网格动态释放/回收 |
| **管理范围** | 全市1000m以内低空空域 |
| **核心成效** | 适飞空域占比 <11%→~50%（约4.5倍增长） |
| **治理模式** | "军-地-民"三方协同 |
| **安全框架** | "五位一体"：空域使用+法规制定+基建建设+技术防御+数据安全 |

## 核心能力

| 能力 | 功能描述 |
|:---|:---|
| **空域网格剖分** | 全市域统一网格剖分→按空域主管单位标准完成结构分析 |
| **逐网格动态管控** | 每个网格可独立释放/回收——颗粒度精细至网格级 |
| **动态灵活转换** | 按需求逐步释放→根据实时态势灵活调整 |
| **五位一体安防** | 空域使用+法规制定+基建建设+技术防御+数据安全五层防护 |
| **军地民协调** | ★三方协同机制→空域供给侧改革 |

## 技术路径

```
全市域统一网格剖分 → 按需求逐步释放 → 动态灵活转换
         │                  │                  │
    空域结构分析        供给侧扩容         主动防控模式
    （标准合规）       （<11%→~50%）      （替代被动管控）
```

## 制度创新——"四个率先"

1. **率先建立"军-地-民"三方协同机制**——空域协调的制度基础
2. **率先完成全市域空域网格剖分**——技术基础
3. **率先实现空域动态释放/回收**——管理模式创新
4. **率先构建"五位一体"安全框架**——安全保障体系

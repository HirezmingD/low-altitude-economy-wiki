# FMCI 未来交通园区试验台（爱尔兰）

> **FMCI**（Future Mobility Campus Ireland）——爱尔兰国家级未来交通实验基础设施。位于香农自由区（毗邻香农机场），构建**移动式无人机港口+4km开放试验台+数据中心+Skyports垂直起降枢纽**四位一体实验平台。通过EALU-AER欧洲项目推进载人/无人航空整合。为全球AAM实验验证提供"小国快跑"方法论范本。

## 基本属性

| 属性 | 内容 |
|:---|:---|
| **全称** | Future Mobility Campus Ireland（爱尔兰未来交通园区） |
| **简称** | FMCI |
| **位置** | 香农自由区（毗邻香农机场） |
| **实验空域** | 4km开放试验台 |
| **核心设施** | 移动式无人机港口+数据中心+Skyports垂直起降枢纽 |
| **欧洲框架** | EALU-AER项目（载人/无人航空整合） |
| **监管标准** | 符合EASA标准 |

## 核心设施

| 设施 | 功能 | 技术特点 |
|:---|:---|:---|
| **移动式无人机港口** | 灵活部署的无人机起降+充电站 | ★移动性→可适配不同测试场景和位置 |
| **4km开放试验台** | BVLOS飞行测试空域 | 真实环境→实证数据采集 |
| **数据中心** | 飞行数据采集+分析+模型训练 | 支持AAM数字孪生 |
| **Skyports垂直起降枢纽** | 固定式eVTOL起降+充电+乘客设施 | 商业运营级标准 |

# SILAS 低空智能融合基础设施系统（深圳）

> **SILAS**（Smart Integrated Low-altitude Airspace System）——深圳自主研发的城市级低空智能融合基础设施系统。全国首个实现"飞行计划申报→智能空域划拨→AI风险判别"全流程闭环的城市级UTM平台。国家-地方两级数据贯通，管理309个管制空域、≥1200个起降点、≥1000条商业航线。

## 基本属性

| 属性 | 内容 |
|:---|:---|
| **全称** | Smart Integrated Low-altitude Airspace System（低空智能融合基础设施系统） |
| **简称** | SILAS |
| **部署区域** | 深圳（特区） |
| **管理空域** | 309个低空管制空域 |
| **关联起降点** | ≥1200个（2026目标） |
| **关联航线** | ≥1000条商业航线（2026目标） |
| **架构模式** | 国家-地方两级平台数据贯通 |
| **年产值支撑** | ¥1300亿（2026目标） |

## 核心能力

| 能力 | 功能描述 | 子课题3关联 |
|:---|:---|:---|
| **飞行计划申报自动化** | 在线提交→自动审核→数字授权——★缩短审批时间 | 需求侧输入 |
| **空域资源智能划拨** | 基于实时态势的空域网格动态分配 | 供给侧调控 |
| **AI风险判别与预警** | AI驱动的飞行风险实时评估→分级预警 | ★"评估-预警-调控"闭环核心 |
| **国家-地方数据贯通** | 地方平台↔国家级UTM数据同步 | 制度摩擦→$f_{governance}$ |
| **全流程闭环** | 计划→审批→划拨→监控→预警→调控 | ★直接对标子课题3闭环 |

# Thales TopSky-AstraUTM 国家级无人机交通管理平台（新加坡）

> **TopSky-AstraUTM**——Thales（全球航空UTM领导者）的旗舰无人机交通管理产品。2026年5月，CAAS（新加坡民航局）授予Thales（牵头）+Deeeplabs（新加坡本地技术商）联合体合同，部署新加坡国家级UTM系统。733km²/570万人口/多机场终端区重叠的极端约束下，以**全国统一一站式平台**实现所有UA运行的安全可扩展管理。★全球-本地联合体模式为低空技术跨国输出提供范本。

| **合同时间** | 2026.05.26 |

| **应用场景** | 5大类（物流/基础设施巡检/海事/应急响应/城市交通） |

## 核心能力

| 能力 | 功能描述 |
|:---|:---|
| **统一注册** | 运营商+无人机电子身份——单一入口 |
| **数字飞行计划与授权** | 在线提交→自动审核→数字授权——★缩短审批时间 |
| **实时运行监控** | 全空域UA运行态势感知+自动化协调 |
| **全生命周期管理** | 注册→计划→授权→监控→数据——端到端闭环 |
| **多场景集成** | 物流+巡检+海事+应急+UAM——五大场景一站式管理 |

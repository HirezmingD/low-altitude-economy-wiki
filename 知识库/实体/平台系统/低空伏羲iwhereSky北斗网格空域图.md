# 低空伏羲 iwhereSky 1.0 北斗网格低空立体空域图（成都）

> **低空伏羲 iwhereSky 1.0**——北斗伏羲公司发布的**全球首款低空立体空域图产品**。基于北京大学程承旗团队GeoSOT地球立体网格编码理论（1997年起973计划支持），融合《北斗网格位置码》国家标准（2021.06.01实施），以10m或20m立体网格为最小单元，构建覆盖0-3000m的低空立体空域"红绿灯"系统。

## 基本属性

| 属性 | 内容 |
|:---|:---|
| **产品名称** | 低空伏羲 iwhereSky 1.0 |
| **开发方** | 北斗伏羲公司 |
| **理论基础** | GeoSOT地球立体网格编码理论（北京大学程承旗团队，1997-） |
| **国标基础** | 《北斗网格位置码》国家标准（2021.06.01实施） |
| **网格粒度** | 10m 或 20m 立体网格 |
| **覆盖高度** | 0-3000m |
| **首批部署** | 成都成华区（西南首个GeoSOT网格融合飞行示范区） |
| **推广区域** | 北京、浙江、安徽、上海、成都成华区等多地 |

## 核心能力

| 能力 | 功能描述 |
|:---|:---|
| **立体网格剖分** | 10m/20m立体网格——全球唯一将地球全域剖分为可计算网格单元的标准 |
| **低空立体空域图** | ★全球首款——将空域信息与地理信息融合为三维可视化产品 |
| **红绿灯系统** | 红灯（禁飞）/绿灯（可飞）——基于网格的动态空域状态可视化 |
| **功能分层** | 3000m（低空互联互通天路网）→1500m（县乡村电商快递物流）→1000m（智慧作业园+新型智慧城市） |
| **导航融合** | 北斗全球组网+GeoSOT网格=米级空间定位 |

| **0-1500m** | 县乡村电商快递物流 | 农村物流/农业 |
| **0-3000m** | 低空互联互通天路网 | 跨城通勤/区域运输 |

| 维度 | 内容 |
|:---|:---|

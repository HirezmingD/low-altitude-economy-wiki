# JAXA SKALE 可扩展空域管理模拟器（日本）

> **SKALE**（Scalable Airspace Management Simulator）——日本宇宙航空研究开发机构（JAXA）开发的可扩展空域管理模拟器。在福岛1km²测试空域内，以4G LTE蜂窝网络+GNSS（GPS/QZSS增强）为CNS配置，实现**146次/h/km²**的全球最高公开发表实测密度。为全球低空容量评估提供唯一有公开发表量化数据的实证锚点。

## 基本属性

| 属性 | 内容 |
|:---|:---|
| **全称** | Scalable Airspace Management Simulator（可扩展空域管理模拟器） |
| **简称** | SKALE |
| **开发机构** | JAXA（日本宇宙航空研究开发机构） |
| **测试区域** | 福岛县，1km²指定测试空域 |
| **空域类别** | 日本G类非管制空域+150m以下特别开放区 |
| **通信方案** | ★4G LTE蜂窝网络 |
| **导航方案** | GNSS（GPS/QZSS准天顶卫星增强） |
| **核心数据** | ★146次/h/km²——全球最高公开发表实测密度 |

## 核心能力

| 能力 | 功能描述 |
|:---|:---|
| **高密度多机模拟** | 1km²内同时管理多架异构无人机——模拟2030物流配送场景 |
| **4G LTE通信验证** | 验证商用蜂窝网络支撑低空飞行的可行性——延迟<50ms |
| **GNSS+QZSS导航** | 日本准天顶卫星增强→导航精度提升 |
| **CNS→容量实证** | ★唯一公开发表量化数据的CNS性能→容量传导实证 |
| **可扩展架构** | 从1km²→更大区域→更高密度的渐进式扩展设计 |

## 关键技术参数

| 参数 | 数据 | 意义 |
|:---|:---|:---|
| **飞行密度** | ★146次/h/km² | 全球最高公开发表实测密度 |
| **测试面积** | 1km² | 标准化空间单元 |
| **通信延迟** | <50ms（4G LTE） | CNS性能基线 |
| **导航系统** | GPS/QZSS增强 | 亚太区域最优GNSS配置 |
| **测试场景** | 物流配送（2030目标） | 商业应用导向 |
| **空域高度** | 150m以下（特别开放） | 日本低空制度特色 |

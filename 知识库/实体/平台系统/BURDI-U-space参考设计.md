# BURDI U-space参考设计（CISP+USSP+UTM三层架构）

> **BURDI**（Belgium-Netherlands U-space Reference Design Implementation）——欧洲首个跨境U-space参考设计项目。€990万预算/18个核心伙伴/3年期，构建**CISP（通用信息服务提供商）+USSP（U-space服务提供商）+UTM（无人机交通管理）**三层架构，达到TRL 8/9。实现BVLOS医疗配送从30分钟缩短至<13分钟（从英国远程操控），首个U-space空域落地安特卫普-布鲁日港口。

## 基本属性

| 属性 | 内容 |
|:---|:---|
| **项目全称** | Belgium-Netherlands U-space Reference Design Implementation |
| **简称** | BURDI |
| **预算** | €990万 |
| **核心伙伴** | 18个（覆盖全产业链） |
| **项目周期** | 3年 |
| **技术成熟度** | ★TRL 8/9（实际跨境运行环境验证） |
| **跨境范围** | 比利时-荷兰 |
| **监管框架** | EASA U-space法规 |
| **首个实施空域** | 安特卫普-布鲁日港口 |

## 三层架构

```
              BURDI U-space 三层架构
                      │
        ┌─────────────┼─────────────┐
        │             │             │
      CISP层        USSP层        UTM层
  （通用信息服务）  （U-space服务） （无人机交通管理）
        │             │             │
   ┌────┴────┐   ┌────┴────┐   ┌────┴────┐
   │         │   │         │   │         │
 空域信息   注册   飞行计划  授权   冲突    合规
 共享      管理   管理      管理   解决    监控
```

| 层 | 角色 | 核心功能 |
|:---|:---|:---|
| **CISP** | 通用信息服务提供商 | 空域信息共享、注册管理、跨成员国数据交换 |
| **USSP** | U-space服务提供商 | 飞行计划管理、授权管理、动态空域配置 |
| **UTM** | 无人机交通管理 | 冲突解决、合规监控、跨境移交协调 |

## 关键成就

| 成就 | 详情 |
|:---|:---|
| **ConOps获批** | ★运营概念获得EASA和两国CAA正式批准 |
| **BVLOS医疗配送** | 医院间样本运输——30min→**<13min**（缩短57%+） |
| **远程操控** | ★从**英国**远程操控比利时上空的无人机 |
| **首个U-space空域** | 安特卫普-布鲁日港口——欧洲首个正式划设的U-space空域 |
| **TRL 8/9** | 在实际跨境运行环境中完成完整系统验证 |
| **跨境法规协调** | 两国U-space法规互认——建立跨境UTM操作先例 |

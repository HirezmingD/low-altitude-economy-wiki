# 深圳市低空经济示范区

## 概况

深圳市是中国低空经济最领先的城市之一，定位"全球低空经济第一城"。依托深圳经济特区立法权，已出台《深圳经济特区低空经济产业促进条例》专项法规，并配套实施《深圳市低空基础设施高质量建设方案（2024-2026年）》。

## 关键数据（2026年目标）

| 指标 | 目标值 |
|:---|:---:|
| 低空起降点 | 1200个以上 |
| 低空商业航线 | 1000条以上 |
| 低空经济产值 | 突破1300亿元 |
| 无人机适飞空域(120m以下) | >75% |
| 直升/eVTOL起降1km覆盖建成区 | >50% |
| 低空快送覆盖人口 | >70% |

## 核心项目

- **SILAS系统**：全球首个低空智能融合系统，支撑1000条航线、300万架次/年
- **低空经济运行试验区**：南山、宝安、龙岗、龙华、光明5个
- **起降设施网络**：通用机场+283个载人起降点+205个物流起降点+413个社区配送点+360个城市治理点
- **气象监测网**：百米级分辨率、分钟级预警、数字孪生平台

# 福岛高密度无人机测试（2020年代-）

> 日本宇宙航空研究开发机构（JAXA）在福岛设立的无人机高密度运行实证测试区，是全球少数有公开发表量化数据的低空高密度飞行试验场之一。

## 一、空域条件

| 维度 | 详情 |
|:---|:---|
| **测试区域** | 日本福岛县，JAXA 指定无人机测试空域 |
| **空域面积** | **1 km²** |
| **空域类别** | 日本 G 类非管制空域 + 150m 以下特别开放区 |
| **日本空域制度背景** | 日本采用 ICAO A-G 六类，低空非管制空域为 G 类 + 150m 以下特别开放空间；DIPS（无人机信息平台系统）支撑申报 |

## 二、技术方案

| 维度 | 详情 |
|:---|:---|
| **测试平台** | JAXA **SKALE**（Scalable Airspace Management Simulator）模拟器 |
| **通信链路** | **4G LTE** 蜂窝网络 |
| **导航系统** | **GNSS**（GPS/QZSS 增强） |
| **CONOPS 体系** | JAXA AAM 路线图——2030 配送场景，政企协同模式 |
| **空域结构** | 日本垂直空域重构：150m 以下非管制 + 150-300m JAXA 测试层 |

## 三、运营数据

| 指标 | 数据 | 说明 |
|:---|:---|:---|
| **飞行密度** | **146 次/h/km²** | 全球公开发表的最高密度实测数据之一 |
| **测试场景** | 物流配送模拟（2030 目标场景） | 高密度、多机型、异构飞行 |
| **通信方式** | 4G LTE 蜂窝网络 | 验证商用蜂窝网络支撑低空飞行的可行性 |

## 四、动态约束

| 约束类型 | 详情 |
|:---|:---|
| **通信约束** | 4G LTE 延迟和可靠性——蜂窝网络非为航空专用设计，延迟波动影响冲突解决时间 |
| **导航约束** | GNSS 在福岛山区/城市边缘的定位精度——QZSS 增强可部分缓解但非完全解决 |
| **CNS 性能→容量** | 146次/h 是在特定 CNS 配置下达成的上限——CNS 性能变化将改变该值 |

## 五、制度机制

| 维度 | 详情 |
|:---|:---|
| **治理模式** | 日本"政企协同型"——JAXA（国家级研究机构）+ 私营企业联合测试 |
| **AAM 路线图** | 日本经济产业省 + 国土交通省联合发布，2030 配送场景为第一阶段目标 |
| **空域管理** | DIPS（无人机信息平台系统）——日版 UTM，强调国家层面统一平台 |
| **国际定位** | 与美国 FAA UTM、欧盟 U-Space 并列为全球六大 CONOPS 体系之一 |

## 六、子课题3 启示

| 维度 | 启示 |
|:---|:---|
| **容量基准实证** | 146次/h/km² = 当前可达到的实证容量上限——子课题3 容量模型的标定锚点 |
| **CNS 性能标定** | 4G LTE + GNSS 配置下的容量值——为"CNS 性能→容量折减系数"提供国际实证 |
| **密度对标** | 可作为中国城市低空容量评估的对比基准（如：中国某城区在相似 CNS 配置下理论上限） |
| **CONOPS 参照** | JAXA 2030 配送场景的容量需求 = 子课题3 预测模型的目标量级参照 |
| **空域面积标准化** | 1km² 标准化测试区域——为容量评估提供可复用的空间单元尺度参照 |

# 密歇根州AAM战略（2025-2030）

> 美国密歇根州未来出行与电气化办公室（OFME）2025年度AAM倡议报告。依托汽车制造+国防空域+跨境地理三大优势，提出2030七大愿景和六大战略支柱。**首个美国州级AAM系统性战略案例。**

## 六维提取

### ① 空域条件

| 参数 | 数值 |
|:---|:---|
| 特殊用途军事空域 | **17,000平方英里**（密西西比河以东最大陆上军事训练空域） |
| 训练区域面积 | **148,000英亩**（NADWC全域作战中心） |
| 航空网络 | **200+** 机场，42座自动化航空气象站 |
| 持牌无人机/垂直起降场 | **15+** 座 |
| 跨境通道 | 美加边境3条（大使桥/底特律-温莎隧道/蓝水大桥）+ 第4条2026年开通（戈迪·豪国际大桥） |
| BVLOS走廊 | 规划中——FAA批准的标准化走廊（物理+数字+数据系统三统一） |
| 空域管理 | 2016年UAS法——州级统一规则，禁止地方自行制定政策→监管确定性高 |

### ② 技术方案

| 设施 | 类型 | 核心能力 |
|:---|:---|:---|
| **MUASC**（阿尔皮纳） | UAS联盟+飞行测试中心 | 飞行测试→研发→培训→制造一体化 |
| **FLITE**（大急流城机场） | 机场场景AAM试点 | 全美最早机场AAM试点之一，自动化/电动化/安全/旅客体验 |
| **Mcity/M-air**（密歇根大学） | 城市环境测试场 | 32英亩全尺寸室外实验场，86+项目/1,740万美元，向AAM扩展 |
| **DSPL**（底特律） | 屋顶垂直起降场 | 从地面停车→屋顶垂直起降场，满足AAM测试需求 |
| **AAIR**（底特律中央创新区） | 商业无人机枢纽 | 真实商业应用试点，BVLOS审批支持，社区参与+技能培训 |

**CNS配置**：GPS拒止环境测试能力 + 远距离加密通信系统（重型无人机）+ 雷达/通信网络既有国防基础设施

**供应链技术映射**：汽车供应商→轻/中/重型无人机关键部件全覆盖（机体材料/电机/ESC/飞控/电池/传感器/通信）

### ④ 动态约束

| 约束类型 | 具体内容 | 容量意义 |
|:---|:---|:---|
| **多用户空域竞合** | 军事训练+商业测试+公共安全+跨境——四类用户在17,000平方英里共存 | 需建立多用户优先级模型——军事/公共安全对商业容量的挤压效应 |
| **供应链转型风险** | 汽车供应商从"大批量标准化"转向"高混合低批量敏捷制造"——转型失败则产能不足 | 制造产能→飞行量增长→容量需求预测的不确定性 |
| **地缘政治** | 美国对华零部件限制→本土供应链加速但成本上升 | 供应链成本→飞机价格→部署规模→容量需求 |
| **GPS拒止环境** | 密歇根专门建设GPS拒止测试场景 | 导航降级条件下的容量折减——与CNS性能驱动模型直接关联 |
| **跨境协调** | 美加边境AAM走廊需两国监管协同 | 跨国境容量模型的制度复杂度——两套空域规则的接口 |
| **公众接受度** | 报告明确承认公众对隐私/安全的担忧呈"分化"状态 | 社会接受度→部署密度约束——农村地区可能成为早期部署突破口 |
| **冬季运行** | 密歇根五大湖地区极端冬季条件 | 类似GCC气候约束——低温→电池性能降额→冬季容量折减 |

### ⑤ 制度机制

| 制度要素 | 内容 |
|:---|:---|
| **核心法律** | 2016年《无人驾驶航空系统法》——全州统一遵循FAA指南，**禁止地方自行制定UAS政策** |
| **UAS工作组** | 2017年报告建议：清晰规则+联邦-州UTM协同+地方教育外联 |
| **航空委员会** | 《航空法典》赋予排他性审批权——商业运营仅限公共用途航空设施 |
| **州级统筹** | OFME（未来出行与电气化办公室）跨部门协调六大支柱 |
| **联邦对接** | FAA UAS-CTI高校网络 + DoD认证UAS制造（蓝名单）+ 国会代表团联邦资金窗口 |
| **公私协同** | FLITE（机场+创投+航空服务商）、AAIR（创新区+交通厅+空域互联+Newlab） |
| **跨境框架** | 与安大略省及加拿大联邦机构长期合作→跨境AAM监管衔接 |

### ⑥ 子课题3 启示

| 维度 | 启示 |
|:---|:---|
| **治理层级→容量粒度** | 密歇根"州级统一规则+禁止地方碎片化"→空域管理粒度标准化→容量建模的空间分辨率可控。对比：中国省级统筹+地级市差异化→容量模型需要多分辨率框架 |
| **多用户优先级模型** | 军事训练(17,000平方英里)+商业测试+公共安全+跨境——需建立**四维空域竞合模型**：时间（军事演习窗口/商业高峰）+空间（管制区/测试区/开放区）+用户类型+优先级 |
| **BVLOS走廊标准化** | FAA批准的标准化走廊含物理+数字+数据三层——为子课题3走廊容量公式提供完整的参数模板（CNS规格/数据协议/安全间隔） |
| **制造→容量需求** | 汽车供应链→无人机放量→空域需求密度非线性增长——需建立**产业驱动因子**：供应商数量×转型率×产能→飞行量预测→容量需求 |
| **跨境容量** | 美加边境AAM走廊→两国空域规则的接口容量损失——跨境容量折减因子 f_crossborder |
| **GPS拒止→CNS折减** | 密歇根专门测试GPS拒止环境→直接为CNS性能驱动容量模型提供退化场景参数 |

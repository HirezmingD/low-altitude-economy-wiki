# 爱尔兰AAM市场潜力与FMCI实验（2024-）

> ★ 全球首个**国家层面AAM市场潜力全量化预测**案例——174条UAM航线/103个人口中心/50条区域航线/16机场/目标市场7800万乘客/年/时间节省经济效益€1.92亿。同时依托FMCI（爱尔兰未来交通园区）构建实验基础设施：移动式无人机港口+4km开放试验台+数据中心+Skyports垂直起降枢纽。定量预测+实验验证——为全球中小国家/紧凑岛国AAM部署提供方法论范本。

## 核心定位

| 维度 | 定位 |
|:---|:---|
| **全球地位** | ★ 首个国家层面AAM市场潜力全量化预测——50条区域+174条UAM航线 |
| **核心机构** | EAM（Electric Aviation Maven·咨询）+ FMCI（Future Mobility Campus Ireland·实验） |
| **方法论价值** | 需求侧（人口中心/出行数据）→航线推导→经济影响量化——可复制的国家AAM市场预测方法 |
| **实验验证** | FMCI——移动式无人机港口+4km开放试验台+数据中心+Skyports垂直起降枢纽 |
| **欧洲框架** | 符合EASA标准 + EALU-AER欧洲项目（载人/无人航空整合） |

## 一、空域条件

| 维度 | 详情 |
|:---|:---|
| **国土特征** | ★ 紧凑岛国——面积7万km²，气候温和——为eVTOL和短途电动航空提供理想环境 |
| **出行现状** | **87%**出行由汽车完成——亟需可持续替代方案 |
| **机场网络** | **16个**机场可纳入区域AAM网络 |
| **人口中心** | **103个**城市人口中心——都柏林为核心枢纽 |
| **空域监管** | 符合EASA欧洲标准 + FMCI通过EALU-AER项目推进载人/无人航空整合 |
| **试验区** | 香农自由区（毗邻香农机场）——FMCI实验基地 |

## 二、技术方案

### 2.1 市场预测方法论（EAM）

| 步骤           | 内容                          | 输出                      |
| :----------- | :-------------------------- | :---------------------- |
| **① 需求侧分析**  | 人口中心分布+出行OD数据+出行模式占比（87%汽车） | 潜在航线走廊识别                |
| **② 航线网络推导** | 城市间距离+旅行时间→eVTOL/电动固定翼替代可行性 | UAM：174条/RAM：50条        |
| **③ 经济影响量化** | 时间节省×时间价值×乘客量               | €1.92亿（RAM）+€9600万（UAM） |
| **④ 基础设施匹配** | 16个机场+规划垂直起降场→网络节点          | 机场→UAM网络节点              |

### 2.4 FMCI 实验基础设施

| 设施 | 功能 | 技术细节 |
|:---|:---|:---|
| **移动式无人机港口** | 可扩展+可移动——支持测试与运营 | 模块化集装箱飞行运营中心+无线电/通信设备 |
| **开放试验台** | ★ 4km公共道路网络（香农工业区） | 光纤网络+多传感器+CCTV+交通信号灯+高精度定位系统 |
| **数据中心与控制室** | 实时监控+数据驱动可视化分析 | 视听系统+移动数据深度监控 |
| **车间与实验室** | 客户私有安全空间 | 高速宽带+私有虚拟网络+面部识别门禁+硬件生产 |

## 四、动态约束

| 约束类型 | 详情 | 子课题3 映射 |
|:---|:---|:---|
| **电网容量** | 电动飞机大规模运营→电网需求剧增——FMCI明确指出"确保电网能够满足电动飞机需求是关键步骤" | ★ 新增 $f_{grid}$——电网供给能力→充电速率→周转率→容量——GCC太阳能+储能之外的另一能源约束维度 |
| **岛国隔离** | 爱尔兰为岛国→跨境AAM仅连接英国（北爱尔兰+大不列颠）→国际网络扩展受限 | 岛国拓扑→外部连通性低→$C_{international}$ 仅1条陆地走廊 |
| **气候温和但多雨** | 爱尔兰多雨雾→低能见度天气频率高→VFR运行受限 | 气象折减——不同于GCC高温/沙尘和英国多雨，爱尔兰=高湿+低云+多雾 |
| **基础设施空白** | 垂直起降场网络从零建设→16个机场改造+新建垂直起降场→基建周期长 | 基础设施起步→$C(t)$初始为零→增长速率取决于基建投资速度 |
| **监管对齐** | 需符合EASA欧洲标准+EALU-AER项目推进——监管节奏受欧盟层面影响 | 多层监管（国家+欧盟）→制度摩擦→$\frac{dC}{dt}$ 受双重审批约束 |
| **紧凑国土→短距优势** | 7万km²紧凑国土→航线短→eVTOL单程无需充电→周转率优势 | ★ 紧凑国土→平均航线长度短→$C_{throughput}=v/L_{avg}$——$L_{avg}$小→单位时间起降架次↑ |

### 5.1 治理架构

| 层 | 主体 | 职能 |
|:---|:---|:---|
| **欧盟层** | EASA | 适航标准+空域管理框架+U-Space体系 |
| **国家层** | 爱尔兰航空管理局 | 国内适航审批+空域管理 |
| **产业层** | FMCI | 实验验证+技术测试+标准验证 |
| **咨询层** | EAM | 市场预测+可行性研究+路线图 |
| **国际层** | EALU-AER项目 | ★ 欧洲载人/无人航空整合——FMCI为协调方 |

### 5.2 FMCI 模式：研发中心+试验台+产业孵化

```
FMCI 爱尔兰未来交通园区
      │
      ├── 无人机港口（移动式+模块化）
      ├── 开放试验台（4km公共道路+传感器网络）
      ├── 数据中心+控制室（实时监控+可视化）
      ├── 车间+实验室（企业入驻+硬件生产）
      │
      └── ★ Skyports 垂直起降枢纽（香农机场）
```

### 5.3 实施挑战

| 挑战 | 内容 | FMCI应对 |
|:---|:---|:---|
| **基础设施** | 垂直起降场网络+电网升级 | FMCI × Skyports合作开发垂起枢纽 |
| **监管** | 低空空域管理框架+EASA标准 | EALU-AER项目→载人/无人航空安全协调 |
| **整合** | 载人+无人航空在共享空域的安全共存 | FMCI核心工作方向 |

## 六、子课题3 启示

| 维度 | 启示 |
|:---|:---|
| **国家尺度市场预测→容量需求推导** | 174 UAM + 50 RAM = 224条航线→每条航线的预期乘客量→飞行密度→容量需求——**需求侧→容量需求**的完整推导链，为子课题3提供"市场规模→容量需求"的经济学驱动 |
| **紧凑岛国→短航程高周转容量** | 爱尔兰7万km²→平均航线长度$L_{avg}$短→单机周转率↑→$C_{throughput}$高——与新疆（超大国土/长航程）形成**国土尺度→航线长度→容量密度**的对照 |
| **电网约束→新增 $f_{grid}$** | 电动飞机大规模运营→电网供给能力→充电速率→周转率→$C_{vertiport}$——与GCC太阳能+储能互补——**电网容量=低空基础设施容量的能源根源约束** |
| **网络枢纽分布→异质图拓扑** | 都柏林74条（中心枢纽）+利默里克29条+科克27条+其他分散→幂律分布——典型的**无标度网络（scale-free network）**——少数枢纽承载大部分流量→枢纽容量=系统瓶颈 |
| **时间节省→经济价值→容量支付意愿** | 时间节省€1.92亿→单位时间价值→乘客对节省时间的支付意愿→对容量溢价的承受能力——为**容量定价模型**提供经济参数 |
| **FMCI试验台→容量模型验证** | 4km试验台+传感器网络+数据中心→为容量模型提供**可控实验环境**——可在试验台验证容量公式后再推广至全国网络 |

# 巴黎eVTOL可持续性评估（2024-）

> 2024年巴黎奥运会期间展示全球首个计划内商业eVTOL空中出租车服务。本案例基于DLR × Axalp联合研究的16条量化航线数据，评估eVTOL在巴黎城市和区域交通中的时间效益与碳排放。

## 六维提取

### ① 空域条件

| 参数 | 数值 |
|:---|:---|
| 飞行高度 | **1000m**（研究设定） |
| 城市范围 | 法兰西岛大区，1230万人口，占法国18.3% |
| 航线类型 | UAM（<50km，城市内部）+ RAM（<300km，跨区域） |
| 始发点 | 协和广场（Place de la Concorde，巴黎市中心） |
| UAM航线数 | **8条**（1.9–29km：埃菲尔铁塔→戴高乐机场） |
| RAM航线数 | **8条**（69–240km：博韦→加来） |
| 空域特征 | 巴黎大区承担法国70%火车交通，每日500万人通勤；每人日均出行3.8次，时间预算90min |

### ② 技术方案

| 机型 | 巡航速度 | 电池 | η_H | η_c | L/D | 适用场景 |
|:---|:---|:---|:---|:---|:---|:---|
| **多旋翼** | 100 km/h | 180 kg | 0.70 | 0.50 | 4 | UAM <50km |
| **升力+巡航** | 180 km/h | 200 kg | 0.70 | 0.50 | **9** | RAM 50-300km |

- **飞行剖面**：垂直起降悬停（各30s）+ 高空巡航（1000m），两阶段模型
- **能耗模型**：基于射流理论（悬停功率）+ 升阻比（巡航功率）
- **电池**：锂离子 250 Wh/kg（当前技术 150-350），2名乘员（含飞行员）
- **对比机型**：Robinson R44 / Airbus H135 / H145 传统直升机 + 五类地面车辆

### ③ 运营数据

#### 时间节省

| 场景 | vs 汽车 | vs 公共交通 | 最佳航线 |
|:---|:---|:---|:---|
| UAM（8条均值） | **-23 min** | -22 min | — |
| RAM（8条均值） | **-76 min** | -69 min | 巴黎→加来（240km）**>100 min** |

#### 碳排放（以欧洲平均电网 226 g/kWh 计）

| 场景 | vs EV | vs 汽油车 | vs 直升机 |
|:---|:---|:---|:---|
| UAM 多旋翼 | **+388%** ❌ | +123% | **-47%** ✅ |
| RAM 升力+巡航 | +67% | **-47%** ✅ | **-77%** ✅ |

#### 典型航线排放（戴高乐机场，29km）

| 交通方式 | 人均CO₂ |
|:---|:---|
| 纯电动汽车 | 1.15 kg |
| 混合动力车 | 2.14 kg |
| 柴油车 | 3.45 kg |
| 汽油车 | 3.62 kg |
| **多旋翼eVTOL** | **4.19 kg** |

### ④ 动态约束

| 约束类型 | 具体内容 | 容量意义 |
|:---|:---|:---|
| **机型-航程匹配** | 多旋翼短途高排放（L/D=4），升力+巡航长途低碳（L/D=9） | 短途走廊能耗折减显著高于长途——机型错配导致容量浪费 |
| **电网碳强度** | 法国 57 / 欧洲 226 / 德国 508 g/kWh——差异可达 **9倍** | 同一航线在不同电网下的可持续性约束完全不同 |
| **理想条件假设** | 10°C / 0 m/s——冬季防冰/除霜/备降冗余将显著推高能耗 | 实际能耗可能远高于研究估算 |
| **全流程时间侵蚀** | 安检/登机/垂直起降场接驳时间未计入 | 纯飞行时间节省可能被地面流程大幅侵蚀 |
| **悬停能耗惩罚** | 起降阶段功率需求远超巡航——短途航线悬停占比高→效率极差 | UAM场景下悬停能耗占总能耗比例是核心容量折减因子 |
| **噪声与占地** | 垂直起降场土地占用+低空噪声（未量化） | 社会接受度约束——城市密集区的额外容量限制 |

### ⑤ 制度机制

| 制度要素 | 内容 |
|:---|:---|
| **政策框架** | 巴黎《气候行动计划》（2018）——目标2050年碳中和城市，100%可再生能源 |
| **示范契机** | 2024年巴黎奥运会——全球首个计划内商业eVTOL空中出租车服务展示 |
| **交通规划** | 新地铁线路2030年连接城市与机场——地面轨道持续升级将压缩eVTOL竞争优势 |
| **公私合作** | 公共与私营利益相关方合作推动AAM发展 |
| **欧盟语境** | 本研究采用欧洲平均电网排放因子（226 g/kWh）作为泛欧参考基准 |

### ⑥ 子课题3 启示

| 维度 | 启示 |
|:---|:---|
| **能耗-航程非线性** | 短途悬停占比高→能耗惩罚→容量折减大；长途巡航占比高→机翼升力→效率逆转。容量模型需按航程分段建模 |
| **碳排放→容量约束** | f_sustainability = f(grid_carbon, route_length, aircraft_type)——新增独立折减维度 |
| **机型-走廊匹配** | 不同空域走廊指定最优机型类型，避免多旋翼飞长途或升力+巡航飞短途的错配损失 |
| **替代直升机优先** | 减排47-77%——现有直升机走廊是eVTOL部署的最优切入点，容量增量最可控 |
| **电网敏感性** | 中国各省电网碳排放因子差异巨大（如云南水电 vs 华北煤电），容量模型的可持续性参数需按省级电网定制 |
| **"绿色"叙事的边界** | UAM短途排放远超EV（+388%）——子课题3容量规划应以RAM长途和直升机替代为优先场景，审慎推进城市短途客运 |

## 研究局限

- 仅计算运行阶段直接排放，缺全生命周期分析（制造/电池回收/基建）
- 基于10°C理想条件，冬季实际能耗将显著更高
- 未计入垂直起降场接驳/安检时间
- 仅含2名乘员（含飞行员），商业运营需更大机型

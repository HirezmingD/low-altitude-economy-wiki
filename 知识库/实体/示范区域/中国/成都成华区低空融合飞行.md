# 成都成华区低空融合飞行示范（2024-）

> 四川是全国首个低空空域协同管理试点省份（2017年12月启动），成华区是西南首个基于 GeoSOT 北斗网格编码的低空融合飞行示范区。

## 一、空域条件

| 维度 | 详情 |
|:---|:---|
| **所在省份适飞空域** | 四川全省适飞空域占比 **80%**（2026年全国第二，仅次于广西84.26%） |
| **空域约束** | 成都有 2 个民用机场 + 多个军用机场，空域结构复杂，"低空空域开放难度相比一般城市更大"（纵横股份董事长任斌） |
| **空域管理改革** | 四川 2017.12 起为全国首个低空空域协同管理试点；2018-2023 第三轮试点核心省份之一 |
| **试点层级** | 成华区——城区级 GeoSOT 网格化低空融合飞行试点 |

## 二、技术方案

| 维度 | 详情 |
|:---|:---|
| **空域网格编码** | **GeoSOT 地球立体网格编码理论**（北京大学程承旗团队，1997年起 973 计划支持） |
| **国标基础** | 《北斗网格位置码》国家标准（2021.06.01 实施） |
| **网格粒度** | 10m 或 20m 立体网格 |
| **低空空域图产品** | **低空伏羲 iwhereSky1.0**（北斗伏羲公司发布）——全球首款低空立体空域图产品 |
| **红绿灯系统** | 红灯（禁飞）/ 绿灯（可飞），基于网格的动态空域状态可视化 |
| **功能分层** | 3000m（低空互联互通天路网）→ 1500m（县乡村电商快递物流）→ 1000m（智慧作业园+新型智慧城市） |

## 三、运营数据

| 指标 | 数据 |
|:---|:---|
| 四川试点启动 | 2017 年 12 月（全国首个） |
| 审批优化 | 原军航/民航/飞行计划 3 个审批环节 → 飞行计划 1 个环节 |
| 试点扩展 | 已推广至北京、浙江、安徽、上海、成都成华区等多地 |
| 成都重点项目 | 2024 大会现场签约 8 个低空经济重大产业项目 |

## 四、动态约束

| 约束类型 | 详情 |
|:---|:---|
| **军用空域冲突** | 成都辖区内多军用机场，空域划设需协调军方 |
| **民用机场干扰** | 双流 + 天府两场，低空飞行需避开终端管制区 |
| **城区建筑环境** | 城市核心区高楼密集，GPS 信号遮挡（城市峡谷效应）——GeoSOT 网格提供精准定位补偿 |

## 五、制度机制

| 维度 | 详情 |
|:---|:---|
| **军地民协同** | 四川率先实现"军-地-民"三方一体化办公；低空空域协同管理运行中心（军/空/地三方合署） |
| **管理权下放** | 马剑（中国城市临空经济研究中心秘书长）：300 米以下空域移交地方，"以后各个地方的交通局不仅管理地面交通，还管理低空交通" |
| **试点策略** | "冷静下来做试点，避免一哄而上导致资源浪费、产业泡沫化"（马剑） |
| **因地制宜** | 闫楚良（中科院院士）："低空经济发展要城乡分类施策"——城市侧重智慧城市/应急，乡村侧重电商物流/植保 |

## 六、子课题3 启示

| 维度 | 启示 |
|:---|:---|
| **空间网格标准** | GeoSOT + 北斗网格位置码国标 → 子课题3 容量评估的空间单元划分可直接采用 10m/20m 网格 |
| **饱和度可视化** | 红绿灯系统 = 饱和度预警的可视化工程实现 → 直接对标子课题3 "评估-预警-调控"闭环 |
| **垂直功能分层** | 3000/1500/1000m 三层架构 → 容量评估的垂直维度分层基准 |
| **复杂空域建模** | 成都"2民用+多军用"约束 = 多机场冲突场景下的容量折减实证案例 |
| **空域产品化** | iwhereSky1.0 = 容量评估系统的产品化对标——从学术模型到工程产品的参照路径 |

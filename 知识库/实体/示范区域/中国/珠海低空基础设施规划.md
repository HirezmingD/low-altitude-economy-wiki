# 珠海低空基础设施规划（2025-）

> ★ 国内首个设立"低空起降设施用地（S5）"地类的城市——从土地分类制度源头为低空基础设施落地提供法定依据。17条措施覆盖规划统筹、用地保障、土地供应、审批简化、场景应用、数据赋能六大维度，形成低空基础设施规划管理的"珠海方案"。

## 核心创新

| 创新点 | 内容 | 全国地位 |
|:---|:---|:---|
| **S5 地类** | 在国土空间规划用地分类中新增"低空起降设施用地（S5）" | ★ **全国首个** |
| **报建豁免清单** | 符合条件的低空设施设备纳入规划报建豁免清单 | ★ 大幅提升审批效率 |
| **复合建设** | 鼓励用地混合兼容、自有用地/既有建筑附设、塔杆资源复合 | ★ 拓宽建设渠道 |
| **实景三维赋能** | 构建高精度数字空间底座，服务航线规划与飞行管理 | ★ 地理信息→低空运营 |

## 一、空域条件

| 维度 | 详情 |
|:---|:---|
| **通用机场** | 2个A1类通用机场 + 4个备案通用机场 |
| **起降点** | 多个起降点 + 通航飞行服务站 |
| **城市环境** | 珠江口西岸核心城市，毗邻澳门——海域+海岛+陆地三维空间结构 |
| **产业基础** | 航空航天、通航、无人机等领域企业近80家——涵盖制造、保障、飞行、综合服务全产业链 |
| **目标愿景** | 打造"天空之城"——构建低空交通网络空间基础 |

## 二、技术方案

| 维度 | 详情 |
|:---|:---|
| **国土空间规划统筹** | 将低空交通网络纳入全市国土空间规划体系——为低空各类建设主体提供规划建设指引 |
| **S5 地类设立** | 在现行用地分类体系中增设"低空起降设施用地（S5）"——从源头保障设施用地合法性与专用性 |
| **实景三维底座** | 构建高精度、可分析的数字空间底座——支撑航线规划、飞行服务、安全监管 |
| **航线科学设计** | 支持企业结合市场需求科学设计运营航线——规划引领+市场驱动双轮并行 |
| **复合建设技术** | ①用地混合兼容（S5与其他地类混合使用）②自有用地/既有建筑附设 ③塔杆资源复合建设（通信塔+起降点一体化） |

### 规划管理技术架构

```
国土空间规划统筹
      │
      ├─→ 用地分类创新（S5地类）──── 源头保障
      ├─→ 土地供应优化（指标+地价）── 降低成本
      ├─→ 审批流程简化（豁免清单）── 提升效率
      ├─→ 复合建设指引（混合兼容）── 拓宽渠道
      └─→ 数据底座支撑（实景三维）── 精细管理
```

## 三、运营数据

| 指标 | 数据 |
|:---|:---|
| A1类通用机场 | **2 个** |
| 备案通用机场 | **4 个** |
| 产业链企业 | 近 **80 家**（全产业链） |
| 措施数量 | **17 条**（规划统筹+用地保障+土地供应+规划审批+场景应用+数据支撑） |
| 政策发布时间 | 2025年底征求意见 → 2026年4月正式发布 |

## 四、动态约束

| 约束类型 | 详情 | 子课题3 映射 |
|:---|:---|:---|
| **用地供给约束** | 城市土地资源紧缺→低空基础设施面临"无地可用"困境——S5地类正是对此约束的制度回应 | 垂直起降场可用土地面积→起降点密度上限→**地面侧容量瓶颈** $C_{ground} = f(A_{available}, n_{vertiports})$ |
| **审批摩擦** | 传统规划报建审批周期长→抑制企业投资意愿——豁免清单是对审批摩擦的削减 | 制度摩擦→建设速度折减→**容量释放时间函数**受影响 |
| **海岛环境** | 珠海147个海岛（含无人岛）→低空基础设施需适应海洋环境（盐雾、海风） | 海岛环境折减因子——不同于内陆城市的特殊气象+物流约束 |
| **跨境邻近** | 毗邻澳门→涉及跨境空域协调（澳门机场终端区） | 跨境制度边界→对深圳-珠海航线的空域容量有跨境约束 |
| **复合建设约束** | S5与其他地类混合使用时→兼容性要求和邻避效应 | 复合建设→设施非专用化→**有效容量 < 名义容量** |

## 五、制度机制

### 5.1 五大制度支柱

| 支柱 | 核心措施 | 制度创新点 |
|:---|:---|:---|
| **①规划统筹** | 低空交通网络纳入国土空间规划；为企业提供规划建设指引 | 规划引领、规范有序 |
| **②用地保障** | 用地指标规模优先保障；土地供应方式优化创新；企业增资扩产地价减免 | ★"组合拳"——指标+供应+地价三维联动 |
| **③规划审批** | ★ 增设S5地类；报建豁免清单；鼓励复合建设 | **全国首个S5地类**——制度源头创新 |
| **④场景应用** | 无人机配送试点住宅；无居民海岛低空基础设施；自然资源领域低空场景 | 珠海特色场景（海岛+住宅配送） |
| **⑤数据赋能** | 实景三维数字空间底座；地理信息服务保障 | 精细化管理的技术基础 |

### 5.2 土地要素保障"组合拳"

```
用地指标规模优先保障 ──→ 指标侧
土地供应方式优化创新 ──→ 供应侧    ──→ 降低企业开发建设成本
企业增资扩产地价减免 ──→ 价格侧        激发市场活力
```

### 5.3 治理模式定位

> **"规划管理制度创新型"**——不同于深圳的"特区立法+产业基金"模式、福州的"军地民协同+空域供给侧改革"模式，珠海从**土地与规划管理制度**维度切入低空经济，解决低空基础设施"落地难"的源头问题，形成了独特的制度供给路径。

### 5.4 与广东兄弟城市的分工

| 城市 | 定位 | 制度创新方向 |
|:---|:---|:---|
| **深圳** | 特区标杆·全产业链 | 特区立法、产业基金、SILAS系统、标准体系 |
| **珠海** | ★ 基础设施规划管理先行 | **S5地类、报建豁免、复合建设、实景三维底座** |
| 广州 | 大湾区核心枢纽 | （待追踪） |

## 六、子课题3 启示

| 维度 | 启示 |
|:---|:---|
| **S5地类→地面侧容量约束** | S5地类从制度上解决了低空基础设施的"土地使用合法性"问题——但可划拨的S5用地总量构成垂直起降场密度的**硬上限**：$C_{vertiport\_network} \leq f(S5_{area}, S5_{distribution})$。此为容量评估模型中尚未建模的**地面侧土地约束**维度 |
| **审批豁免→容量释放时间函数** | 报建豁免清单降低制度摩擦→缩短设施建设周期→加速容量释放曲线——$C(t)$ 的 $t_{build}$ 参数受审批制度直接影响——审批效率是可量化的容量释放速率因子 |
| **复合建设→专用容量vs共享容量** | 用地混合兼容+塔杆复合→低空基础设施从"专用独立"走向"共享嵌入"——容量模型需区分 $C_{dedicated}$（独立垂直起降场）与 $C_{shared}$（复合设施），后者受共用资源竞争约束 |
| **实景三维→容量评估数据底座** | 高精度数字空间底座直接为子课题3的**低空环境数字模型**提供数据输入——3D建筑模型+地形+电磁环境→城市峡谷效应量化→GNSS信号遮挡折减 |
| **海岛场景→特殊拓扑约束** | 珠海147海岛→节点稀疏+航线跨海+备降场有限——容量模型中节点间连通性（graph connectivity）的特殊退化场景 → 对网络鲁棒性评估有方法论价值 |
| **土地指标→经济-容量耦合** | 土地供应指标与低空经济产值目标挂钩→用地指标约束可作为经济密度→飞行密度→容量需求的传导链中的**供给侧调节变量** |

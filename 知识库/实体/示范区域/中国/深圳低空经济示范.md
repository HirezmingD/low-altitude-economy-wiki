# 深圳低空经济示范（2023-）

> 国内制度化、标准化、产业化程度最高的城市级低空经济标杆。全国首个融合空域运行示范基地、首个城市级低空经济标准化技术委员会、首条 eVTOL 跨城跨湾航线——三重"全国首个"构筑特区先行先试优势。

## 一、空域条件

| 维度 | 详情 |
|:---|:---|
| **空域分类** | G 类（<300m）+ W 类（<120m）非管制空域——深圳作为第三轮试点城市（6城之一），600m 以下管理权下放地方 |
| **管制空域网络** | 初步划设 **309 个**低空管制空域，覆盖物流、文旅、通勤、巡检等场景——形成精密空域网络 |
| **融合空域基地** | 东部通航低空融合飞行示范基地（盐田）——**全国首个**融合空域运行示范基地（2025.04.15 动工） |
| **城市环境** | 粤港澳大湾区核心引擎——超高密度城市建成环境 + 深圳湾海域 → 陆海空三栖空域结构 |
| **SILAS 系统** | 低空智能融合基础设施系统——国家+地方两级平台为核心，实现飞行计划申报→空域智能划拨→AI风险判别**全流程闭环** |

## 二、技术方案

| 维度 | 详情 |
|:---|:---|
| **空域管理平台** | **SILAS**（Smart Integrated Low-altitude Airspace System）——低空智能融合基础设施系统 |
| **SILAS 核心能力** | ①飞行计划申报自动化 ②空域资源智能划拨 ③AI 风险判别与预警 ④国家-地方两级平台数据贯通 |
| **起降网络** | 2026 年目标 ≥1200 个起降点；2035 远景 1500+——国内最密集的低空起降网络规划 |
| **航线网络** | 2026 年目标 ≥1000 条商业航线——覆盖物流、通勤、巡检、文旅等多元场景 |
| **eVTOL 验证** | 国内首条 eVTOL 跨城跨湾航线"深圳蛇口—珠海九洲港"——验证跨城 AAM 技术可行性 |
| **CNS 支撑** | 深圳 5G 基站密度全国最高 + 大湾区 GNSS 增强系统 → 城市级 CNS 性能最优区域之一 |

## 四、动态约束

| 约束类型 | 详情 | 子课题3 映射 |
|:---|:---|:---|
| **城市密度** | 深圳建成区密度国内最高之一——高楼峡谷效应、GNSS 信号遮挡严重 | 城市峡谷导航不确定性 σ≥25m——CNS 折减系数的高值场景 |
| **海陆界面** | 深圳湾+珠江口海域——海风、盐雾、海陆风切变 | 海洋气象折减因子——不同于内陆城市的特殊气象约束 |
| **多机场冲突** | 深圳宝安国际机场 + 香港国际机场（相距<50km）+ 珠海金湾机场 + 澳门机场 | 大湾区多机场终端区→低空飞行需协调 4 个主要机场的进近/离场程序 |
| **跨境协调** | 深港边境——跨境低空飞行涉及两地空域管理制度的对接 | 制度差异→跨境容量管理的管辖权重叠问题 |
| **高密度航线** | 1000+ 航线在有限空域内同时运行 | ★ 城市级高密度容量建模的极限压力测试场景 |

## 五、制度机制

| 维度 | 详情 |
|:---|:---|
| **治理模式** | **特区先行先试**——依托深圳经济特区立法权，率先突破制度壁垒 |
| **顶层设计** | 2023.05 成立深圳市低空经济专家委员会（空管/研发/运营/法规/政策全国顶级专家） |
| **资金保障** | 20 亿元低空经济产业基金 + 最高 2000 万单项奖励——覆盖研发制造、运营支持、首飞补贴、基础设施建设 |
| **标准引领** | 2024 年成立**全国首个城市级低空经济标准化技术委员会**——30+ 地方标准涵盖空域建设、航线管理、运行安全等关键领域 |
| **基建先行** | 《低空基础设施高质量建设方案（2024-2026）》+《起降设施布局规划（2026-2035）》——从"规划"到"落地"的完整时间表 |
| **法规保障** | 《深圳经济特区低空经济产业促进条例》——全国首个低空经济专项地方立法（2023） |
| **发展模式** | "高发展+高规范"动态平衡——在鼓励创新与守住安全底线之间寻求最优解 |

## 六、子课题3 启示

| 维度 | 启示 |
|:---|:---|
| **SILAS 闭环** | "飞行计划申报→智能空域划拨→AI风险判别"全流程闭环 → **直接对标**子课题3 "评估-预警-调控"自动化闭环——SILAS 是最接近产业实现的技术参照 |
| **高密度建模** | 309空域+1200节点+1000航线——为 ST-GNN 态势预测提供**理想的城市级训练数据拓扑**（节点=起降点，边=航线，流量=航班） |
| **容量需求推导** | 1300亿元产值目标 → 可换算经济密度→飞行密度→容量需求——为容量预测提供**经济学驱动的需求侧推导** |
| **多机场约束** | 深圳+香港+珠海+澳门四场——多机场终端区低空容量模型——验证 CNS 性能折减在高密度空域的实际影响 |
| **标准→评估** | 30+ 地方标准涵盖空域建设+航线管理+运行安全——为标准驱动的容量评估提供**规范化的指标体系** |
| **跨境维度** | 深港边境——跨境低空容量管理的管辖权重叠 → 容量模型需增加**制度边界约束层** |

# 福州低空空域改革（2024-2025）
> 知识库首篇国内地级市低空改革量化实证案例。来源：姚俊臣（2026），引述中国交通运输协会低空交通与经济专委会秘书长酒海燕。
## 核心数据
| 指标 | 改革前 | 改革后 |
|:---|:---|:---|
| 适飞空域占比 | **<11%**（集中在偏远郊区） | **~50%** |
| 市中心核心经济区 | 全部管制空域 | 动态释放可用 |
| 空域管理高度 | — | 1000m 以内全市域 |
| 管理模式 | "被动管控" | **"主动防控"** |
## 一、空域条件
- **改革前痛点**：福州市空域状况复杂，适飞空域不足全市面积的 11%，且主要分布在偏远郊区，市中心核心经济区全部为管制空域
- **改革后**：低空空域资源利用率提升至约 50%
- **空域范围**：全市 1000m 以内低空空域
- **技术基础**：按空域主管单位标准完成全市低空空域结构分析和**空域网格剖分**，以可计算空域网格为核心技术
## 二、技术方案
| 维度 | 内容 |
|:---|:---|
| **核心平台** | "榕智九天"——市级低空监管运服平台 |
| **空间编码** | 可计算空域网格（逐网格动态释放/回收） |
| **技术路径** | 全市域统一网格剖分 → 按需求逐步释放 → 动态灵活转换 |
| **安全框架** | "五位一体"：空域使用 + 法规制定 + 基建建设 + 技术防御 + 数据安全 |
## 三、运营数据
| 指标 | 数据 |
|:---|:---|
| 适飞空域占比提升 | <11% → ~50%（约 4.5 倍增长） |
| 空域释放覆盖高度 | 1000m 以内全市域 |
| 管理颗粒度 | 空域网格级（逐网格可独立释放/回收） |
## 四、动态约束
- **空域复杂度**：市中心核心经济区原为全管制空域，适飞空域仅限偏远郊区
- **管理瓶颈**：传统"被动管控"模式无法灵活调配空域资源
- **突破方式**：通过"军-地-民"协调机制实现空域动态化管理和灵活转换
## 五、制度机制——"四个率先"
### ① "军-地-民"三方协同，建章立制
- 出台四份文件，形成低空飞行服务保障 **"3+1"** 顶层制度设计
- 《福州市低空飞行服务保障管理办法》等
- 依托"军-地-民"三方协同管理机制，率先实现**地方政府与空域主管单位协同管理**低空空域资源释放和飞行计划审批
- 建成"榕智九天"市级低空监管运服平台
### ② 全市域统一规划，逐步释放
- 率先以地级市为单位进行低空空域规划与改革
- 全市低空空域结构分析 + 空域网格剖分
- 可计算空域网格为核心，逐步完成全市 1000m 以内空域资源动态释放
### ③ 精细化动态化管理，灵活转换
- 率先在全国范围内实现低空空域**动态化管理和灵活转换**
- 适飞空域从 <11% 大幅提升至 ~50%
- 显著提升飞行器承载能力
### ④ 全方位保障，"被动管控"→"主动防控"
- 从空域使用、法规制定、基建建设、技术防御、数据安全**"五位一体"**整体推进
- 率先实现从传统"被动管控"向"主动防控"策略转变
## 六、子课题3 启示
| 维度 | 启示 |
|:---|:---|
| **静态容量基准** | 福州"可计算空域网格"直接为容量评估提供空间单元划分方案——网格粒度和释放策略影响静态容量基准 |
| **动态折减** | "动态释放/回收"机制验证了 DCB"评估-预警-调控"闭环在实际管理中的可行性，为自动化容量调度提供制度先例 |
| **饱和度分级** | "被动管控→主动防控"转变对应红-黄-绿三级饱和度中的"绿→黄"状态切换逻辑——常态释放、预警回收 |
| **制度接口** | "军-地-民"三方协同为容量评估平台的角色定位提供参照——容量评估结果需同时服务于军方（安全）、地方（经济）、民航（效率）三方 |
## 与其他案例的关系
- **与成都成华区**：成都侧重技术示范（GeoSOT 网格 + iwhereSky1.0 空域图），福州侧重**制度创新**（军地民协同 + 管理流程再造）。两者互补，共同构成中国低空改革的"技术+制度"双轮驱动图景
- **与王凯博（2026）央地关系理论**：福州是"中央统领，地方主导"在**地级市层面**的首个量化落地验证

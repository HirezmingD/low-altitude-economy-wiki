# 安徽低空经济示范（2024-）

> 长三角地区唯一全域低空空域管理改革试点省份。eVTOL 制造集群 + 基础设施先行 + 村集体购机全国首例 + 物流/医疗/巡检/植保四场景常态化——**制造驱动型**省级低空经济模式。

## 一、空域条件

| 维度 | 详情 |
|:---|:---|
| **改革地位** | 长三角地区**唯一**全域低空空域管理改革试点省份（第三轮试点核心省份之一） |
| **试点空域** | 累计划设 **54个**低空试点空域 |
| **低空航线** | 已开辟 **43条**低空航线 |
| **空域类别** | G 类（<300m）+ W 类（<120m）非管制空域——600m 以下管理权下放地方（6试点城市含合肥） |
| **机场设施** | 3个通用机场运营 + 1个 A 类通航飞行服务站——"运输+通用"双轨体系 |
| **地理特征** | 长三角腹地，江淮丘陵+皖南山区+长江/淮河/巢湖水域——多地形复合空域 |

## 二、技术方案

| 维度 | 详情 |
|:---|:---|
| **管理平台** | 省级飞行服务 + 无人机监管 + 航空应急救援——**三平台打通**（全国省级层面整合度最高之一） |
| **飞行服务站** | A 类通航飞行服务站——数字化手段实现空域动态调配、飞行计划自动审批、低空实时监控 |
| **CNS 覆盖** | 低空通信+导航+监视设施——重点区域全覆盖，支撑"飞得起、看得见、管得住" |
| **eVTOL 制造** | 亿航智能（全球首个自动驾驶 eVTOL 适航认证机型生产基地，芜湖）+ 零重力飞行器（"天行"系列，合肥）+ 中电科芜湖钻石（航空材料/动力系统） |
| **产业链密度** | 芜湖湾沚区 **200+**低空经济企业——国内密度最高的低空产业集聚区之一 |
| **巡检技术** | 国网安徽无人机巡检——覆盖 10万+公里输电线路，智能化故障识别 |

## 四、动态约束

| 约束类型 | 详情 | 子课题3 映射 |
|:---|:---|:---|
| **多地形复合** | 江淮丘陵+皖南山区+长江水域——地形起伏大，低空飞行需应对山谷风、水域气象 | 多地形气象折减系数——复杂地形下的差异化容量参数 |
| **人口密度梯度** | 皖北平原人口密集 → 皖南山区人口稀疏——省内需求密度非均匀分布 | 省内非均匀密度建模——介于城市级（均匀高密度）和大尺度（新疆绿洲）之间 |
| **长三角空域协同** | 与江苏/浙江/上海空域接壤——跨省低空飞行需协调四地空域管理制度 | 省际边界约束——容量模型的行政边界条件 |
| **制造业密集** | 合肥/芜湖城市群——工业电磁干扰、建成区 GNSS 信号遮挡 | 工业区 CNS 性能退化→容量折减 |

## 五、制度机制

| 维度 | 详情 |
|:---|:---|
| **改革定位** | 长三角唯一全域低空空域管理改革试点省——中央授权+省级统筹 |
| **平台整合** | 飞行服务+无人机监管+应急救援三平台打通——全国省级层面制度整合的标杆 |
| **产业政策** | 200+企业集聚芜湖湾沚区——从"招商引资"到"产业集群"的制度支撑 |
| **村集体模式** ★ | **全国首例**村集体购置飞机投入商业运营（"永兴号"，103.9万）——低空经济的"基层民主化"创新模式：村集体出资→航空公司运营→收益反哺乡村 |
| **基础设施先行** | A 类飞行服务站 + 3通用机场 + 54试点空域 + 43航线——"先修路再跑车"的基建驱动策略 |
| **人才培养** | 航空研学 3万人次——从基础教育培育低空消费市场 |

## 六、子课题3 启示

| 维度 | 启示 |
|:---|:---|
| **中尺度建模** | 54空域+43航线——省级中尺度空域网络拓扑，为容量模型提供**介于城市级（数十km²）和大尺度（166万km²）之间**的中间尺度参照 |
| **制造→飞行量预测** | 3家 eVTOL 头部企业+200+产业链企业——产业化→飞行量指数增长→为容量预测提供**产业驱动因子**（可量化为"制造业产值→飞行量"换算系数） |
| **效率→容量换算** | 75%/60%/8x/30x 四组效率数据——为效率提升→飞行量增长→容量需求提供**定量推导的实证参数** |
| **多场景常态化** | 物流+医疗+巡检+植保四场景——多场景耦合容量建模的**第四组实证案例**（继福州/新疆/深圳之后） |
| **非均匀密度** | 皖北密集→皖南稀疏的省内梯度——为容量模型提供**渐进式密度变化**的实证场景（不同于新疆绿洲的极端非均匀） |
| **村集体分布式需求** | 分布式基层需求激活→容量模型需处理**"集中+分散"混合需求模式**——未来百万级无人机同时在线的重要需求来源 |

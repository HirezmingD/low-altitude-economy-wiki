# 美国低空治理体系

## 概述

美国拥有全球最成熟的通用航空体系与最活跃的低空经济风险投资生态。其治理模式属于**市场主导型**，FAA 主导国家空域系统（NAS）与城市空中交通（UAM）架构，强调资本驱动下的产业化推进。

## 低空治理/经济概况

### 空域分类

美国国家空域系统（NAS）采用 A-G 六类（不含 ICAO F类）+ 特殊用途空域：

| 空域类别 | 飞行规则 | 管制服务 | 低空关联 |
|:---|:---|:---|:---|
| A类 | 仅 IFR | 全程管制 | 高空 |
| B类 | IFR + VFR | 全程管制 | 主要机场周边 |
| C类 | IFR + VFR | 全程管制 | 中型机场周边 |
| D类 | IFR + VFR | 全程管制 | 小型机场周边 |
| **E类** | IFR + VFR | IFR管制/VFR交通情报 | **低空空域主体，覆盖最广** |
| **G类** | IFR + VFR | 仅飞行情报（请求时） | **非管制空域，无人机核心运行区** |

- **E类空域**是通用航空运行的核心区域，覆盖范围最广
- **G类空域**为无人机提供最灵活、宽松的运行环境，无需ATC许可

### 无人机管理

- **Part 107**（小型无人驾驶航空器系统规则）：适用于<55磅（约25kg）的商业/政府无人机
- **G类空域**：无需事先获得 ATC 许可
- **B/C/D/E类空域**：须取得 ATC 授权

### LAANC 系统（低空授权与通知能力）

- 核心创新：通过桌面端和移动端应用程序实现**近乎实时的空域准入授权**
- 覆盖范围：全美 530+ FAA直属空中交通管制设施，726+ 机场
- 审批效率：绝大多数授权申请在**提交后数秒内获批**
- 意义：有力支撑大规模、高频次的无人机作业需求

| 2016 | FAA 发布 Part 107 | 小型无人机商业运行法规基础 |

| 2025+ | AAM 产业化持续推进 | Joby、Archer 等 eVTOL 企业适航认证推进 |

## 治理模式特征

**市场主导型**：成熟通用航空体系 + 活跃风投生态 + FAA 技术标准化 + LAANC 自动化授权

## 最新运营数据（截至2024）

> 来源：王凯博（2026），整合FAA公开数据。

| 指标 | 数据 | 说明 |
|:---|:---|:---|
| 无人机注册量 | **320万架**（2024年底） | 所有超过0.55磅（约250g）须注册 |
| Remote ID 覆盖率 | **85%**（2024） | 无人机实时传输位置+身份信息 |
| 事故率下降 | **↓60%**（2018→2024，0.15‰→**0.06‰**） | 归因于 Remote ID + DroneZone 平台 |
| 监管平台 | **DroneZone** | FAA 全国统一监控平台 |
| 高度限制（小型无人机） | **400ft（≈122m）** | FAR Part 107规定 |

### 联邦-地方治理特征

| 维度 | 联邦（FAA） | 州/地方 |
|:---|:---|:---|
| 职责 | 全国性标准、注册系统、Remote ID | 本地补充标准、日常监管、执法协作 |
| 示例 | FAR Part 107, DroneZone | 加州禁飞优胜美地、纽约州禁飞曼哈顿、迈阿密警方2024年查处120起 |

### 现存问题

- **监管套利**：部分州为吸引企业降低标准（如得州允许500ft，高于FAA的400ft）
- **州联邦冲突**：科罗拉多州要求州级证书，与FAA联邦证书冲突，需法院解决
- **治理模式**：市场化监管型——"风险分层"降低合规成本，促进产业发展

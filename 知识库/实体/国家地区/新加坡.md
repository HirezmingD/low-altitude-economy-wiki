# 新加坡低空治理体系

> ★ 2026-07-01 从框架页升级为完整治理页面。2026年5月，CAAS授予Thales（泰雷兹）+Deeeplabs联合体合同——部署基于TopSky-AstraUTM的国家级无人机交通管理（UTM）系统，为新加坡所有无人机运行审批和跟踪提供**一站式集成门户**。城市密集型治理模式获得首个量化制度支撑。

## 概述

新加坡采用**城市密集型**治理模式——在极度受限的城市国家空域条件下，通过高效数字化手段实现精细化管理。作为全球人口密度最高的国家之一（~8,000人/km²），新加坡空域资源极为有限（国土仅733km²），必须通过**数字化一站式管理**在有限空间中实现最大化的空域利用。

> **治理模式**：城市密集型——**数字化一站式UTM** + 全球-本地联合体 + 智慧国家战略嵌入

## 治理模式特征

| 维度 | 特征 |
|:---|:---|
| **监管机构** | CAAS（新加坡民航局）——无人系统技术、工程与规划局 |
| **核心平台** | ★ Thales TopSky-AstraUTM——2026年5月合同授予 |
| **交付模式** | ★ 全球-本地联合体：Thales（全球航空UTM领先）+ Deeeplabs（新加坡本地技术） |
| **平台功能** | 一站式门户——运营商/无人机注册+数字飞行计划与授权+实时运行监控 |
| **应用覆盖** | 物流+基础设施巡检+海事作业+应急响应+城市交通——全场景集成 |
| **核心约束** | 城市国家——733km²/570万人口——★全球最极端的空域密度约束 |

## TopSky-AstraUTM 核心功能

| 功能 | 内容 | 制度效率 |
|:---|:---|:---|
| **统一注册** | 运营商+无人机电子身份注册 | 一站式——消除多部门重复登记 |
| **数字飞行计划与授权** | 在线提交→自动审核→数字授权 | ★ 简化申请流程+缩短监管审批时间 |
| **实时运行监控** | 全空域无人机运行态势感知 | 增强态势感知+自动化协调 |
| **全生命周期支持** | 注册→计划→授权→监控→数据存档 | 端到端数字化闭环 |

## 城市密集型治理的极端约束

| 约束 | 参数 | 容量含义 |
|:---|:---|:---|
| **国土极小** | 733km²——东西~50km/南北~27km | ★ 空域纵向分层必须极致精细化——单位面积容量需求全球最高 |
| **人口极密** | ~8,000人/km² | ★ 地面风险敞口极大——$f_{risk}$→$s_{min}$最大化 |
| **机场密度** | 樟宜国际机场+实里达机场+多个军事机场 | 多个机场终端区重叠→有效低空空域<国土面积50% |
| **邻国毗邻** | 马来西亚（北）+印度尼西亚（南） | ★ 跨境空域协调——与马来西亚柔佛仅1km海峡之隔 |
| **海事叠加** | 全球最繁忙港口之一+新加坡海峡 | 海上+空中双重交通→海事无人机与城市无人机空域共享 |

## 全球-本地联合体模式

| 维度 | 全球方（Thales） | 本地方（Deeeplabs） |
|:---|:---|:---|
| **贡献** | 全球领先UTM技术+航空专业知识+AstraUTM多国部署经验 | 本地部署+运营服务+本地数字化能力 |
| **优势** | 技术成熟+产品标准化+全球最佳实践 | 本地监管理解+快速响应+文化适配 |
| **模式** | 产品输出+技术转移 | 本地化落地+持续运维 |

> ★ 这一模式为中国低空企业出海提供参照——"全球技术+本地伙伴"联合体→降低准入壁垒+加速本地化。

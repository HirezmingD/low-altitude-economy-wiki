# 中国低空治理体系

## 概述

中国低空空域管理正处于从传统**统一管制型**向**制度创新型**转型的关键期。以2023年《国家空域基础分类方法》和《空域管理条例（征求意见稿）》为标志，中国建立了**A-G+W七类**空域分类体系，并正在推进"中央统领，地方主导"的央地协同管理体制改革。

> **治理模式演变**：统一管制型（军航-民航二元）→ 制度创新型（军-民-地三方协同）

## 治理模式特征

| 维度 | 现行体制 | 改革方向 |
|:---|:---|:---|
| **空域分类** | A-G+W 七类（2023），G(<300m)/W(<120m) 为非管制空域 | G/W 管理权逐步下放地方 |
| **管理体制** | 军航4级 + 民航3级 分层管理 | 军-民-地三方协同，"管用分离" |
| **授权时效** | 前1日12时前申请 | 向"即报即飞"演进 |
| **数字化程度** | 建设中（GeoSOT+北斗网格） | 国家-省-市三级低空智能网联系统 |

## 空域分类体系

> 详见：[空域分类制度](/知识库/概念/空域治理/空域分类制度.md)

- **A-G+W 七类**：全球唯一在ICAO基准上增设**W类**（<120m，无人机专用友好空域）的国家
- **水平三分法**（管制/监视/报告）与**垂直七分法**（A-G-W）双维并行
- G类（<300m）和W类（<120m）为非管制空域，由军-民-地三方协同管理

## 管理体制

> 详见：[低空空域管理体系](/知识库/概念/空域治理/低空空域管理体系.md)、[央地低空空域协同管理](/知识库/概念/空域治理/央地低空空域协同管理.md)

### 军民航分层结构

| 体系 | 管理层级 | 职责范围 |
|:---|:---|:---|
| **军航** | 空军 → 军区空军 → 军师级航空单位 → 军航机场 | 全国 → 飞行管制区 → 飞行管制分区 → 机场管制区 |
| **民航** | 民航空管局 → 地区空管局 → 空管分局/站 | 区域管制 → 进近管制 → 机场管制 |

### 央地协同框架

- **中央统领**：战略谋划、标准制定、国家安全统一管控
- **地方主导**：细化监管制度、承担具体管理职能、因地制宜促产业
- **"管用分离"原则**：《空域管理条例（征求意见稿）》核心创新
- **渐进转移**：物流无人机先行下放 → 载人eVTOL暂保留中央

## 改革时间线

| 时间 | 里程碑 |
|:---|:---|
| 2010 | 《关于深化我国低空空域管理改革的意见》——改革正式启动 |
| 2010-2014 | 第一轮试点：空域分类化管理（14省约33%低空空域） |
| 2015-2018 | 第二轮试点：空域精细化管理（珠三角+海南） |
| 2018-2023.02 | 第三轮试点：空域协同化管理（四川/湖南/江西/安徽） |
| 2023 | 《国家空域基础分类方法》发布；《空域管理条例（征求意见稿）》 |
| 2024 | 《无人驾驶航空器飞行管理暂行条例》施行；第四轮试点（UAM）启动 |
| 2025 | 中央空管委专项文件：国家-省-市三级空管系统建设标准 |
| 2026 | 新修订《民用航空法》首次纳入"低空经济" |

## 核心挑战

| 挑战 | 描述 |
|:---|:---|
| **空间错配** | "西多东少、冷热不均"——经济发达区可飞空域极少（长株潭120m以下几无适飞空域） |
| **管控短板** | 传统雷达网络难以实现低空全覆盖 |
| **立法滞后** | 改革成果未能及时固化，政策连续性差 |
| **权责交叉** | 多头管理体制影响系统性推进 |
| **"三化"冲击** | 信息化（数据风险）、智能化（算法→风险因子）、规模化（百万级同时在线） |

# 英国低空治理体系

> ★ 2026-07-01 新建。首届素材为Skyway低空高速公路项目——全球首个大规模地面传感器驱动无人机专用走廊网络。治理模式定位：**政企协作型**——政府基金引导 + 企业技术主导 + 民航局（CAA）监管审查。

## 概述

英国低空治理采用 **"政府基金引导 + 企业技术主导 + 监管渐进审查"** 的政企协作型模式。以 Innovate UK（BEIS下属）基金为引导，Altitude Angel等科技企业为技术核心，CAA（民航局）为监管审查主体——三方协作推动BVLOS（超视距）无人机运营的商业规模化。

## 治理模式特征

| 维度 | 特征 |
|:---|:---|
| **治理模式** | 政企协作型——政府引导+企业驱动+监管渐进 |
| **核心机构** | BEIS（商业/能源/产业战略部）→ Innovate UK 基金；CAA 民航局监管审查 |
| **关键计划** | Skyway项目（265km无人机高速公路）+ £2.73亿航空航天投资计划 |
| **技术路径** | ★ 地面传感器网络（ARROW）+ 4G/5G蜂窝连接 + UTM——不同于日美CNS机载性能驱动路径 |
| **监管模式** | 现有许可先行（2023试飞）→ 数据提交CAA审查（2023底）→ 安全协议整合（2024.07前）——渐进式监管验证 |
| **中国启示** | ①地面传感器走廊——不同于国内北斗/5G空天一体的技术路径，提供替代方案 ②渐进式监管审查——"试飞→数据→审查→整合"可作为中国低空基础设施安全验证流程参照 |

## Skyway 技术架构

### ARROW 系统

| 组件 | 功能 | 技术细节 |
|:---|:---|:---|
| **地面传感器网络** | 沿高速公路安装——持续监控低空空域 | 提供无人机实时位置视图 |
| **交通管理系统（UTM）** | 分析传感器数据——引导无人机沿航线飞行+避免碰撞 | Altitude Angel 专利技术 |
| **蜂窝连接** | BT/EE 4G+5G网络——连接传感器与服务器 | 英国最大最可靠网络 |
| **态势感知** | 无人机接收ARROW战术防撞指令 | 自主避撞+有人机共存 |
| **指挥中心** | 初期人工监督所有航班 | 逐步向自动化过渡 |

### Skyway 技术路径 vs 其他走廊范式

| 维度 | 英国Skyway | 日本AAM走廊 | 美国NASA/FAA管道 |
|:---|:---|:---|:---|
| **传感器主体** | ★ 地面传感器网络 | 机载CNS+ANSP | 机载+UTM |
| **通信骨干** | 4G/5G蜂窝 | 多链路（卫星+地面+机载） | ADS-B+UTM |
| **主要对象** | 无人机（BVLOS） | eVTOL（载人+货运） | eVTOL+无人机 |
| **准入机制** | 走廊注册+CAA许可 | CNS性能门槛 | 特定规则+程序+性能标准 |
| **避撞责任** | ARROW地面系统→无人机执行 | ANSP→机体自主（渐进） | UTM协调 |

# 沙特阿拉伯低空治理体系

> ⚠️ 框架页。基于 LYNEports《海湾地区AAM运行概念》（2026.05）白皮书提取。待后续沙特专项素材补充。

## 概述

沙特阿拉伯是GCC中**最大的AAM潜在市场**，以主权资本直接投入和绿色城市规划嵌入为双引擎，采用与阿联酋互补的**主权资本驱动型**治理模式。GACA（沙特民航局）采用与FAA/EASA并行验证的监管路径，同时通过监管沙盒机制允许有限早期运行。

> **治理模式**：主权资本驱动型（PIF直接投资飞机+基础设施，"资本+产业"双轮驱动）

## 治理模式特征

| 维度 | 特征 |
|:---|:---|
| **监管机构** | GACA（沙特民航局）——主动制定认证路径，非被动等待 |
| **资本模式** | PIF（公共投资基金）直接投资飞机制造商和起降基础设施 |
| **城市开发** | NEOM、新穆拉巴、红海全球、奇迪亚、迪里耶门——规划设计阶段嵌入AAM |
| **航空基础** | 2025年旅客量 >**1.4亿**，年增长 >9%；萨勒曼国王国际机场（57km²/6跑道/1.2-1.85亿容量） |
| **AAM路线图** | 基础设施、飞行运行、适航性、空域集成四个专项工作组 |

## 重点城市与项目

### 利雅得——网格化城市

- 人口预计 2030年超 **1500万**
- 正交主干道网格 + 四大项目（新穆拉巴、奇迪亚、迪里耶门、体育大道）重塑城市形态
- 网格化结构为可预测AAM走廊规划提供良好基础
- **气候约束**：7月平均 ~45°C，峰值 >48°C，停机坪 >65°C

### NEOM——原生AAM城市

- "线性城市"The Line、Trojena、Sindalah、Oxagon——从零设计综合垂直+水平交通
- 全球极少数的**原生AAM城市**案例

### 吉达——密集历史核心

- 保留密集历史核心和沿海走廊
- 采用**外围垂直起降场策略**——沿沿海环路或外环干道布置
- 历史核心区仅限紧急/公共服务/高度受控移动

### 红海全球——高端旅游AAM

- 机场、度假村、遗产地之间天然点对点几何形态
- 高支付意愿需求集中
- 主权支持的航空运营商与大型项目开发商合作

## 优先用例

| 优先级 | 用例 | 锚点 |
|:---|:---|:---|
| ★★★ | 医疗与应急响应 | 沙特红新月会、三甲医院网络 |
| ★★★ | 军事与政府运行 | 内政部、国防部、边境监视 |
| ★★★ | 货运与物流 | 利雅得/吉达/达曼工业区、NEOM物流走廊 |
| ★★ | 近海油气物流 | 沙特阿美（加瓦尔、萨法尼亚油田） |
| ★★ | 旅游与高端出行 | 红海全球、NEOM、阿乌拉 |
| ★★ | 朝觐与宗教出行 | 麦加/麦地那/吉达——全球密度最高的出行流之一 |

## 特殊运行约束

| 约束 | 影响 |
|:---|:---|
| 极端高温 | 利雅得峰值 >48°C，有效载荷降额 10-20% |
| 沙尘事件 | 每年 20-35 次重大事件，维保成本占运营成本 30-40% |
| 朝觐出行 | 全球密度最高的时间敏感出行流——需主权主导协调和严格控制路由 |
| 隐私文化 | "家庭私密性"——避免直接飞越住宅区是首要社会约束 |

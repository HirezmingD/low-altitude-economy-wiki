# 中国低空治理

## 概况

中国低空治理是指在中国法律框架下，对低空空域资源、通用航空活动、无人驾驶航空器运行和低空经济发展进行的规划、管理、监管和服务活动。2026年新《民航法》施行标志着中国低空治理进入新发展阶段。

## 治理模式特征

根据课题分析框架，中国属于**政府主导型**低空治理模式：
- 空域管理由空军统一管制，民航局分工负责
- 法律法规体系自上而下构建
- 地方政府在通用机场规划、低空经济发展中有积极角色

## 治理结构

```
国家空中交通管理领导机构（顶层协调）
├── 中央军委（空军统一飞行管制）
└── 国务院民用航空主管部门（民航局）
    ├── 政策法规司（立法协调）
    ├── 空管行业管理办公室（空域/空管）
    └── 地区民用航空管理机构（辖区管理）
        └── 省级人民政府（通用机场/低空经济）
```

# 欧盟低空治理体系

## 概述

欧盟在低空治理领域以**规则制定引领全球**，其 SESAR（单一欧洲天空空中交通管理研究）联合体与 U-Space 体系代表了**规则引领型**治理模式。欧盟强调通过标准输出参与全球规则博弈，注重公众参与与隐私保护。

## 低空治理/经济概况

### ECAC 空域分类（对 ICAO 的本地化调整）

欧洲民航会议（ECAC）在「欧洲单一天空」计划下，对 ICAO A-G 分类进行本地化调整，提出面向无人航空器运行的三类空域：

| ECAC 类别 | 含义 | 对应 ICAO 标准 |
|:---|:---|:---|
| **U类** | 未知空中交通环境 | ≈ G类 |
| **K类** | 已知空中交通环境 | ≈ D类 + E类 |
| **N类** | 已知交通意图环境 | ≈ A类 + C类 |

### U-Space 体系

U-Space 是欧盟构建的**高度数字化、自动化、可持续且具备强交互能力的低空空域生态系统**，核心特征：

- **定位**：一套可为大规模无人机运行提供服务的体系，依托先进数字技术支持大量无人机在复杂低空环境中安全、高效、可靠的协同运行
- **法律属性**：U-Space 空域本质上属于 ICAO 术语中的**限制区**，不属于 ICAO 附件11 定义的 A-G 类空域，飞行活动无需遵循 IFR/VFR
- **四大核心功能**：身份认证、智能空管、分级响应、去中心化服务

### X/Y/Z 三类空间（2023年 CONOPS v4）

2023年发布的《U-space运行概念（第四版）》将低空空域按风险等级划分为：

| 空间类别 | 特征 |
|:---|:---|
| **X类** | 低风险/低密度，基本飞行信息服务 |
| **Y类** | 中等风险/中等密度，主动交通管理 |
| **Z类** | 高风险/高密度，全流程协同管理 |

### 城市空域运行原则

- 建议沿**现有城市交通廊道**（轨道、高速公路、河道、街道）上方飞行——这些区域已有既有噪音环境，新增噪音影响相对较小
- 避免飞越私人住宅或敏感私有财产上空（隐私保护）
- 城市空中交通有望融入多模式交通系统，缓解地面拥堵

## 治理模式特征

**规则引领型**：SESAR 标准体系 + U-Space 法律框架 + 分类监管（运营风险分级）+ 隐私/公众接受度管理 + 标准输出参与全球规则博弈

### 成员国执行差异

| 维度 | 核心国（德/法/西） | 东欧成员国（波兰/罗马尼亚） |
|:---|:---|:---|
| 执行能力 | 完全执行EASA高标准 | 产业基础薄弱，无法完全执行 |
| 本地补充 | 德国禁飞柏林市中心（历史建筑）、法国禁飞埃菲尔铁塔 | — |
| 合规成本 | 某意大利小企业**€10万/年** | 更高相对负担 |

### 治理模式特征

- **超国家统一标准**：EASA统一规则确保欧盟内部市场统一，避免成员国间标准冲突
- **协同监管**：U-Space 实现跨成员国实时数据共享
- **问题**：中小企业合规成本高；成员国发展不均导致执行差异
- **治理模式**：协同监管型

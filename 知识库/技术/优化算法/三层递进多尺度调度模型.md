# 三层递进多尺度调度模型

## 概述

包杰等（2025）提出的针对城市低空高密度运行的**整数规划**三层递进优化模型，从单尺度起飞时刻调整逐步扩展到包含动态空域配置的三尺度协同调控。

## 模型结构

### 模型Ⅰ：起飞时刻优化

| 要素 | 内容 |
|------|------|
| 目标函数 | min Σ总延误时长 |
| 约束 | 飞行时序、栅格容量上限 C(n)、0-1整数变量 |
| 求解器 | Gurobi 12 |
| 效果 | 延误架次79（39.5%延误率） |

### 模型Ⅱ：起飞+柔性航路双尺度

| 新增 | 内容 |
|------|------|
| 决策变量 | 每架运输类航空器的航路选择（多条备选） |
| 惩罚项 | 额外飞行时长加权 |
| 约束 | 单飞行器仅选一条航路 |
| 效果 | 延误架次31，空域利用率+18.2% |

### 模型Ⅲ：起飞+航路+动态空域三尺度

| 新增 | 内容 |
|------|------|
| 决策变量 | 组合栅格激活0-1变量 |
| 约束 | 同时间窗唯一激活、栅格容量动态切换 |
| 效果 | 延误架次**4**，空域利用率**+33.7%** |

## 求解性能

| 模型 | 求解耗时 |
|------|----------|
| Ⅰ | 3.2 s |
| Ⅱ | 2.3 s |
| Ⅲ | **8352.6 s（≈2.3h）** |

模型Ⅲ求解耗时剧增，是向实时应用转化时的主要瓶颈。

## 参数敏感性

- 额外飞行成本越高 → 倾向调起飞时间、减少绕路
- 组合栅格最优合并数 = **4**（超过后优化收益微弱）

## 技术栈

- **求解器**：Gurobi 12（商业整数规划求解器）
- **硬件**：i5-14600KF / 16G内存
- **几何处理**：Graham扫描算法（凸包过滤）
- **语言**：Python + Gurobi API

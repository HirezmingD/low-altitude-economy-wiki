# 气体定律空域冲突预测模型

## 概述

Mahmassani等（2023）借鉴化学中气体分子碰撞理论，提出AAM空域冲突预测的**气体定律模型**——将航空器类比为气体分子，基于相对速度、密度和间隔体积来估算冲突率。这是构建空域基本图的核心前置模型。

## 基本原理

```
单机搜索体积 = 相对速度 × 间隔横截面积 × 时间窗口
              × 密度
              = 预期冲突数
```

航空器以速度v飞行，在其前方"搜索"一个体积：截面=间隔要求的横截面积D_sep，长度=v·T。该体积内其他航空器数量=密度×体积≈预期冲突数。

## 核心公式

### 单机冲突率
```
C_i = √2 · v_i · D_sep · k
```
- v_i: 航空器i的实际速度
- D_sep: 间隔要求的横截面积（椭球体）
- k: 航空器密度

### 空域总冲突数
```
C = (√2/2) · v · D_sep · k² · T · Vol
```
- v: 平均实际速度
- T: 前视时间窗口
- Vol: 空域总体积

## 关键特征

### 幂律关系：C ∝ k²
冲突数随密度**二次方**增长——核心非线性来源：
- 新增一架航空器不仅自己产生冲突
- 还与空域中已有的**所有**航空器产生潜在冲突
- 高密度下边际冲突急剧增加

### 速度的双重作用
- v直接增加冲突（搜索更多空域）
- 但冲突又降低v→形成负反馈循环

### 间距的放大效应
- D_sep↑→冲突↑→需要更多解脱→速度↓→容量↓
- 即使小幅降低间距也能显著减少冲突

## 从冲突到速度下降

每次冲突需要机动解脱→偏离最优路径→速度损失

```
实际速度损失: v = v_max - b·C/n
有效速度损失: e = e_max - a·C/n
```

其中a≥b（有效速度损失≥实际速度损失，因为绕行偏离目标方向）

## 参数校准

速度损失参数a、b依赖：
- 冲突解脱算法(c)
- 相对航向(h)
- 间隔体积(V_sep)
- 附近密度(k)
- 航空器速度(v)

可通过低密度场景的仿真结果外推校准。

## 在基本图中的位置

```
气体定律
   ↓ C(k, v, D_sep)
速度-密度 v(k) = v_max/(1+√2·b·D_sep·k·T)
   ↓
有效速度 e(k)
   ↓
基本图 Q_e(k) = k·e(k)
```

## 对子课题3的应用

- 可直接用于承载力建模：给定空域参数→冲突预测→速度下降→临界密度=容量
- D_sep校准：可通过实验测定不同飞行规则下的等效间隔→承载力上限
- T窗口选择：反映预测/感知能力→技术成熟度影响容量

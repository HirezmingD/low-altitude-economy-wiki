# AFPS自动飞行规划系统

## 概述

Zhang & Charkhgard (2021) 提出的面向高密度UAM的自动飞行规划系统，由**LAMS**（空域管理）和**LTMS**（交通管理）两子系统组成，实现从障碍物避让到多运营商公平调度的全链路自动化。

## 系统架构

```
┌─────────────────────────────────────────┐
│              AFPS                       │
│  ┌──────────────┐  ┌──────────────┐     │
│  │    LAMS      │  │    LTMS      │     │
│  │              │  │              │     │
│  │ LiDAR 3D地图 │  │ 冲突检测     │     │
│  │ 可视性图     │→│ 整数规划     │     │
│  │ 最短路径库   │  │ 高度层分配   │     │
│  │ 交叉点数据库 │  │ Nash公平     │     │
│  └──────────────┘  └──────────────┘     │
└─────────────────────────────────────────┘
```

## LAMS流程

1. LiDAR数据构建3D GIS地图，确定可飞行空域
2. 每飞行层构建可视性图（障碍物顶点+起降点→节点，无障碍阻挡连线→边）
3. 最短路径算法获取各OD对在各飞行层的3D轨迹
4. 预处理所有轨迹，识别交叉点，存入数据库

## LTMS冲突检测

**三类空间交叉**：

| 类型 | 描述 | 最小时间间隔 |
|------|------|:----------:|
| Type1 | 纯交叉(θ>0) | Dˢ√(vf²+vk²-2vf·vk·cosθ)/(vf·vk·|sinθ|) |
| Type2 | 同向共线 | Dˢ/va |
| Type3 | 对向共线 | 两机通过重叠段无时间重叠 |

**检测逻辑**：4D轨迹时间重叠检查 → 间隔<S_fk → 冲突

## LTMS数学优化

### 整数规划变量
- φ_f^h ∈ {0,1}：航班f是否分配高度层h
- y_fkhp ∈ {0,1}：Type3冲突选择第一/第二关系

### 约束
- 每航班一个高度层
- 同层同交叉点：间隔≥S_fk（大M法）
- Type3对向：到达时刻+间隔约束

### 目标函数
- **求和模型**：min Σ C_f^h·φ_f^h（总飞行成本最小）
- **乘積模型(Nash)**：max Π(d_o - Σcost_o)（运营商收益乘积最大）

## Nash社会福利公平性

**UBR (Unit Benefit Ratio)**：
```
UBR_i = (d_i - actualCost_i) / (d_i - minCost_i)
```
范围[0,1]，越接近1表示越受益。Nash解使各运营商UBR尽量接近。

**实验结论**：
- 求和模型：市场越集中(NHHI↑)，UBR分布越宽→不公平
- 乘積模型：即使NHHI=0.5，UBR仍集中→公平
- 系统成本牺牲<0.5%，高密度场景公平收益更显著

## Tampa Bay实例参数

| 参数 | 值 |
|------|-----|
| 起降点 | 30 |
| 飞行层 | 10 (500-1400ft, 100ft间隔) |
| 巡航速度 | 130 knots |
| 爬升/下降率 | 1000 fpm |
| 最小横向间隔 | 0.3 NM |
| 实验密度 | 5min/takeoff(270架) / 3min/takeoff(450架) |
| 运营商 | 2/4/6 |
| 市场集中度 | NHHI 0.01/0.1/0.25/0.5 |

## 关键结果

- 两端模型均求解至最优（秒级）
- 450架次/45min无冲突4D航迹生成
- 平均飞行时间≈9.7分钟
- 计算时间：低密度<1秒，高密度3min场景数秒至数十秒

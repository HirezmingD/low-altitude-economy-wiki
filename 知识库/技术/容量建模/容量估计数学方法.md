# 空域容量估计的数学方法

## 概述

本文梳理 Pongsakornsathien et al.（2025）综述中提出的三种主要空域容量估计数学方法。这些方法分别适用于不同的空域结构范式，为子课题3 的容量评估模型提供了公式化的技术输入。

## 方法一：分层空域容量公式

### 适用场景

基于大都市项目（Metropolis）的分层空域结构。

### 公式

$$Capacity = f(L, CR_{max}, k, f(\alpha))$$

其中：
- $L$ = 垂直层数
- $CR_{max}$ = 最大可接受全局冲突率
- $k$ = 其他影响系数（环境、CNS 性能等）
- $f(\alpha)$ = 相对速度降低效应函数
- $\alpha$ = 航向角

### 全局冲突率定义

$$CR_{global} = \binom{n}{2} \times P_{conflict\_per\_pair}$$

即：两架飞机可能组合的数量 × 任意给定配对的冲突概率。

### 输入输出

| 项目 | 说明 |
|:---|:---|
| **输入** | 层数 L、最大可接受冲突率 CR_max、交通航向分布 α、环境系数 k |
| **输出** | 各层及总体的最大可安全容纳飞机数 |
| **适用条件** | 分层空域结构；层间天然分隔、层内需间隔保证 |
| **局限性** | 未考虑 CNS 性能差异；未考虑飞行器性能混合；网格大小估计"没有明确界定" |

### 与子课题3 的关系

可作为**静态容量基准**的公式化起点。子课题3 需要扩展：
- 将 k 系数展开为多因素耦合（气象、生态、电磁、地面风险、噪声、CNS）
- 引入时变因子实现动态化

## 方法二：基于图论的密度容量估计

### 适用场景

杜尚（Doosan）提出的基于密度的分区空域。

### 方法

采用**图论或随机几何图**，核心考虑因素：
- 交通密度 $\rho$
- 最小安全间隔 $d_{min}$
- 冲突检测与解决能力 $C_{CD\&R}$

### 输入输出

| 项目 | 说明 |
|:---|:---|
| **输入** | 目标区域的交通密度、最小间隔标准、冲突检测能力参数 |
| **输出** | 空域分区的最大可支持飞行器数量 |
| **适用条件** | 分区或混合空域结构；拥堵城市区域→多层图节点、低密度区域→低分辨率图 |
| **局限性** | 对无人机性能异质性的建模不足 |

### 与子课题3 的关系

适用于 GeoSOT 网格化容量评估——每个网格单元可建模为图节点，相邻网格间的交通流为图的边，容量 = 图的最大可维持流。

## 方法三：基于风险的完全混合空域容量

### 适用场景

完全混合（自由飞行）空域。与分层/分区方法不同，该方法从安全角度反推容量。

### 方法

- 定义无人机周围半径为 $r$ 的安全区圆盘
- 将空域离散化为三维网格
- 采用 **Bron-Kerbosch 算法**进行团计算（clique computation）——识别所有可能同时占据网格而互不侵犯的无人机集合
- 容量 = 最大团的大小

### 输入输出

| 项目 | 说明 |
|:---|:---|
| **输入** | 安全区半径 r、三维网格分辨率、空域边界 |
| **输出** | 同时可安全容纳的最大无人机数量 |
| **适用条件** | 自由飞行空域、低密度场景 |
| **局限性** | 网格大小估计过程"没有明确界定"；计算复杂度随网格分辨率指数增长 |

## 容量决定因素体系

综合三种方法，容量由以下因素共同决定：

| 因素 | 影响方式 | 子课题3 对应维度 |
|:---|:---|:---|
| **空域几何形状** | 可飞行体积 → 基础容量 | 三维时空编码 |
| **交通组合** | 异质性 → 等效交通量 | 场景分类 |
| **间隔标准** | 最小间隔 → 单位体积容量 | CNS 性能驱动的间隔模型 |
| **冲突解决能力** | 检测延迟 + 解决时间 → 动态安全裕度 | SACA 过程延迟 |
| **环境约束** | 禁飞区/限飞区 → 可用空域收缩 | 多因素耦合折减 |
| **自动化水平** | 人类监督 vs 自主 → 决策延迟差异 | LoA 分级影响分析 |

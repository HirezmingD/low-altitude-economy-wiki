# 空域资源量空间-经济测度模型

## 概述

廖小罕等（2021）提出的低空空域资源量双层测度数学框架：**空间度量**（有多少空域可供开发）+ **经济度量**（可产生多大效益）。

## 四大级联原则

```
Q = Q_raw × 非冲突 ∩ 安全 ∩ 效益 × 公平衰减
```

### 1. 非冲突原则
$$Q = \complement(Q_O(V,t))$$
低空空域资源量是其他资源/活动的时空补集。

### 2. 安全保障原则
$$Q = Q \times W_{NS} \times W_{PS}$$

- W_NS ∈ {0,1}：涉及国家安全→0（禁止开发）
- W_PS = 1 − 事故率：公共安全衰减系数

### 3. 效益优先原则
$$Td = f(UAS, Uts)$$

交通密度受无人系统技术(UAS)和交通服务技术(Uts)共同决定。

### 4. 兼顾公平原则
$$Q = Q \times (1 - a_{noise}) \times (1 - a_{ap})$$

噪声污染衰减 a_noise + 大气污染衰减 a_ap。

## 空间度量公式

$$Q_{space}(S,H,t) = V(S,H) \times sv(DEM,DSM) \times Fl(TR,SR) \times W_{meteorology} \times W_{disaster}$$

| 参数 | 含义 |
|------|------|
| V(S,H) | 四维时空体物理体积 |
| sv(DEM,DSM) | 地形空间体积影响系数 |
| Fl(TR,SR) | 地表起伏+粗糙度影响系数 |
| W_meteorology | 气候损失系数 |
| W_disaster | 极端灾害损失系数 |

## 经济度量公式

$$Q_{eco}(S,H,t) = \max(Td(UAS,Uts)) \times \rho$$

| 参数 | 含义 | 单位 |
|------|------|:--:|
| max(Td) | 单位时空体最大交通密度 | 架次/(m³/h) |
| ρ | 单架次飞行效益 | 元/架次 |
| Q_eco | 单位时空体资源价值量 | 元/(m³/h) |

## 承载力转化链

```
物理空间(V) → 扣除自然约束 → 扣除社会约束 → 乘以技术系数 → 得到容量(Td) → 乘以单位效益(ρ) → 经济承载力(Q_eco)
```

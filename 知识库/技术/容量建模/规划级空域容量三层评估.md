# 规划级空域容量三层评估

## 技术概述

规划级空域容量三层评估是安诣彬等（2026）在临沂实证中提出的低空资源综合评估方法，通过容量、风险、需求三个维度并行评估，最终整合输出全域低空资源适用性区划（禁用区/限用区/适用区）。

## 三层指标体系

### 第一层：容量评估
| 指标 | 内容 |
|------|------|
| 障碍物分布 | 建筑物三维形态、构筑物分布 |
| 冲突避让 | 安全间隔距离、飞行冲突域 |
| 飞行高度分析 | 可用高度层的空间范围 |

→ 回答：空域"能飞多少"？

### 第二层：风险评估
| 指标 | 内容 |
|------|------|
| 军用空域 | 军事训练区、禁飞区 |
| 机场空域 | 机场净空区、进近面 |
| 敏感要素 | 政府机关、涉密单位、危化品库 |

→ 回答：空域"哪里不能飞/受限飞"？

### 第三层：需求评估
| 指标 | 内容 |
|------|------|
| 地面功能 | 城镇/农业/生态空间分布 |
| 产业布局 | 物流枢纽、产业园区分布 |
| 使用需求 | 各类低空活动频次和空间偏好 |

→ 回答：空域"需要飞什么/在哪飞"？

## 评估流程

```
数据整合 → 并行评估 → 综合叠加 → 区划输出
    │           │              │           │
实景三维   容量评估 ─┐    图层叠加    禁用区
格网地形   风险评估 ─┼→  权重综合  →  限用区
建筑白模   需求评估 ─┘    分级分类    适用区
```

## 输入数据

- 实景三维数据（地形、建筑、地物）
- 低空障碍物数据库
- 军用/民用空域边界数据
- 国土空间规划用地分类
- 产业布局与低空活动需求数据
- 物联感知数据（辅助）

## 输出

- **禁用区**：刚性约束（军事、机场、敏感目标）
- **限用区**：有条件使用（生态敏感、居民密集）
- **适用区**：优先发展（产业匹配、空间充裕）

## 与本课题子课题3的关系

| 维度 | 规划级三层评估（本文） | 课题动态容量模型（子课题3） |
|------|----------------------|--------------------------|
| 层级 | 宏观规划 | 微观运营 |
| 时间尺度 | 静态/阶段性 | 实时/动态（0-30分钟） |
| 核心方法 | 多指标叠加分析 | 多因素耦合+机器学习+ST-GNN |
| 输出 | 空间区划 | 实时容量值+预警信号 |
| 关系 | **规划基底** — 为动态模型提供空间约束前提 | **运营层** — 在规划框架内实现实时调控 |

> ⚠️ 三层评估可作为子课题3动态容量模型的规划级输入约束，两者构成"宏观区划→微观计算"的递进关系。

## 局限性

- 偏静态评估，缺少时间维度上的动态容量变化
- 权重分配依赖专家判断，标准化程度待提高
- 未考虑气象等实时环境因素的动态影响

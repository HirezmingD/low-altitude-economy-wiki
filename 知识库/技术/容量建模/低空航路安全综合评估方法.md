# 低空航路安全综合评估方法

## 概述

本方法基于《[低空航路运行安全能力评估规范](知识库/政策/中国/低空航路运行安全能力评估规范.md).md)》（T/GITIF 028-2025，征求意见稿），采用"静态基准评分 + 动态气象修正"的综合评价模型，对低空航路运行安全能力进行量化评估。

> ⚠️ 本页引用标准为**团体标准征求意见稿**，尚未正式发布。

## 评价模型

### 基础评价（静态基准）

```
基础分值 = Σ(基础指标得分 × 权重)
```

其中：
- 基础指标 = 70项（空域8 + 地理16 + 通信9 + 导航7 + 监视8 + 电磁6 + 基础气象12 + 反制4）
- 单指标采用100分制量化风险，按分段阈值评分（通常100/80/60/40/20五分段）
- 权重按安全优先级分配

### 动态评价（实时修正）

```
动态分值 = 基础分值 × 气象修正系数
```

其中气象修正系数由6项动态气象指标的加权分值计算得出。

**设备失效处理**：通信、导航、监视设备失效时，对应指标分值置0，直至设备恢复后重新计算基础分值。

## 评价流程

### 步骤1：测试航线规划
- 确定起止点，结合空域、地理、历史气象划定可行飞行走廊
- 按最短路径确定测试轨迹
- 匹配待评估航路实际飞行高度

### 步骤2：数据分类归集
| 数据类型 | 来源 | 内容 |
|:---|:---|:---|
| 基础数据 | 静态来源 | 空域、地理、感知设施信息 |
| 实测数据 | 实地飞行采集 | 通信、导航、监视、电磁、反制、气象 |
| 历史数据 | 权威渠道 | 多年气象统计数据 |

### 步骤3：数据预处理
- 数据清洗：剔除异常值并标注原因
- 数据补全：关键导航定位缺失率≥10%需全路段重测

### 步骤4：多维度数据处理
- 实测数据量化打分，标注强弱路段
- 基础/历史静态数据加权打分
- 动态气象计算修正系数，生成动态分值

## 飞行测试法

### 测试条件
- 起飞前设备、环境验证
- 起点3个固定点位预测试
- 环境要求：平均风速≤10m/s、无降水雷电

### 测试执行
- 飞行器标准速度：40~60km/h
- 航线变更需书面记录原因
- 采集时段覆盖航路高频运营场景

### 异常处理
- 电磁干扰异常：环境恢复后同时段全程复测
- 气象恶化：立即暂停，恢复后同条件复测

## 安全分级（四级）

| 等级 | 分值范围 | 基础评价描述 | 动态评价描述 |
|:---:|:---:|:---|:---|
| **A** | ≥80 | 状态良好 | 正常飞行 |
| **B** | 70~79 | 提示风险，加强监视 | 限制飞行 |
| **C** | 60~69 | 限制使用，限期优化 | 谨慎飞行 |
| **D** | <60 | 隔离飞行 | 不建议飞行 |

> 航路开通前评估结果宜达到**B级及以上**。

## 评估场景

| 评估类型 | 触发条件 | 要求 |
|:---|:---|:---|
| **规划预评价** | 航路规划建设阶段 | 优化选址与设备布局 |
| **开通前全评** | 航路开通前 | 全维度评价，结果宜≥B级 |
| **月度核查** | 常态化运营 | 核查基础指标更新 |
| **年度复评** | 每年一次 | 全指标全面评估 |
| **专项临时评价** | 空域调整/航线改道/新增重点设施/极端天气/设备大修后 | 即时评估 |

## 评价应用

1. **规划阶段**：优化航路选址和基础设施布局
2. **开通前**：作为航路准入审批参考依据
3. **常态化运维**：月度/年度报告支撑设备升级
4. **流量管控**：指标数据支撑航路容量测算、动态流量调节
5. **档案管理**：评估报告归档，用于长期安全管理和监管核查

# 北斗网格位置码与 GeoSOT 编码

## 定义

**北斗网格位置码**是基于 **GeoSOT（Geographic Spatial Orientation Transformation）地球立体网格编码理论**建立的国家标准（GB），由北京大学程承旗团队自 1997 年起在国家"973 计划"等项目支持下经历二十余年研究提出，2021 年 6 月 1 日正式实施。它为地球全域空间提供统一的立体网格划分和编码体系，是低空立体交通管理的**空间编码基础**。

## GeoSOT 编码理论

### 核心原理

GeoSOT 将地球全域空间（包括地下、地表、空中）划分为多级立体网格，每个网格具有唯一的全球统一编码。

| 特征 | 说明 |
|:---|:---|
| 覆盖范围 | 地球全域空间（地下 → 地表 → 空中） |
| 网格形状 | 立方体/长方体立体网格 |
| 编码方式 | 全球唯一标识，支持多级嵌套 |
| 低空粒度 | **10m 或 20m** 见方的立体网格 |
| 理论基础 | 973 计划等国家项目，1997-2021（24 年） |

### 在低空空域中的应用

```
地球全域空间
    └── 低空空域（3000m 以下）
            └── GeoSOT 立体网格划分
                    ├── 10m 粒度（精细管理）
                    └── 20m 粒度（宏观管理）
                            ↓
                    每个网格 = 唯一的北斗网格位置码
                            ↓
                    低空立体交通红绿灯系统
                            ↓
                    低空立体空域图（iwhereSky1.0）
```

## 与子课题3 的关系

北斗网格位置码是子课题3 容量评估模型的**空间编码基础设施**：

| 子课题3 技术 | 北斗网格位置码的作用 |
|:---|:---|
| 多因素耦合容量评估 | 以网格为单元，每个网格具有唯一的编码标识 |
| ST-GNN 态势预测 | 以网格编码为节点 ID 构建时空图 |
| 饱和度监测预警 | 以网格为单元显示红-黄-绿状态 |
| 三维时空编码 | 直接采用 GeoSOT 编码体系 |

## 国家标准地位

| 项目 | 内容 |
|:---|:---|
| 标准名称 | 《北斗网格位置码》 |
| 标准类型 | 中华人民共和国国家标准（GB） |
| 实施日期 | 2021 年 6 月 1 日 |
| 归口单位 | 全国北斗卫星导航标准化技术委员会 |
| 创始人 | 程承旗（北京大学） |
| 试点区域 | 北京、浙江、安徽、上海、成都成华区 |

## 技术优势

1. **全球统一**：不受行政边界限制，适合跨区域低空飞行
2. **多级嵌套**：粗粒度（20m）↔ 细粒度（10m）可灵活切换
3. **天然三维**：同时编码水平位置和高度，无需额外高度编码
4. **国标基础**：国家标准的法律效力确保统一推广

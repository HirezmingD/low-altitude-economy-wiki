# CNS性能指标量化模型

## 概述

本文梳理 Pongsakornsathien et al.（2025）综述中提供的 CNS（通信/导航/监视）性能量化指标和数学模型。这些模型构成了"CNS 性能→间隔→容量"传导链条的**第一环节**——CNS 性能的量化表达。详细指标表见原文 Table 6，本文聚焦于可计算的数学模型。

## 通信系统模型

### 蜂窝网络延迟模型（墨尔本 CBD 示例）

**假设条件**：
- 4G LTE 蜂窝网络，地面基站（BS）+ 空中用户
- 频段 5% 预留给空中用户
- 基站为半径 0.5 km 的六边形小区，共 90 个节点
- 每个节点随机处于发送/接收/睡眠三种状态（概率 $P_T$, $P_R$, $P_S$）

**数据包传输延迟**：

$$L_{p_i} = \frac{L_p}{\sum_{j \in E(i)} S_{(i,j)}}$$

其中：
- $L_p$ = 每个节点数据包传输延迟（秒）
- $S_{(i,j)}$ = 无冲突时隙数
- $E(i)$ = 节点传输区域内的网络链路

**简化形式**（假设 $P_T = 1/(n_j+1)$, $P_R = 1 - 1/(n_j+1)$，所有链路成功率相同 T = 0.999）：

$$L_p ∝ \frac{1}{T \cdot (n_j+1)}$$

典型参数：数据包 1500 B，吞吐量 7.5 Mbps。

### UAM 通信性能要求

| 参数 | 要求 | 依据 |
|:---|:---|:---|
| 延迟（Latency） | ≤ **10 ms** | 运营节奏快、特征距离短 |
| 可靠性（Reliability） | **99.999%** | 导航和监视应用 |
| 数据速率 | C2：低速率；遥控：≤ **100 Mbps** | 不同应用差异化需求 |
| 连接方式 | 视距（LOS）+ 超视距（BLOS） | 城市障碍物多 |

### 非地面网络（NTN）通信架构

空间-空中-地面异构网络：LEO卫星 + 高空平台 + 地面蜂窝 + 无人机自组网。

## 导航系统模型

### GNSS 用户等效距离误差（UERE）

$$\sigma_{UERE} = \sqrt{\sigma^2_{clk\&eph} + \sigma^2_{iono} + \sigma^2_{tropo} + \sigma^2_{noise} + \sigma^2_{multipath}}$$

| 误差分量 | 来源 | 对城市 UAM 的影响 |
|:---|:---|:---|
| $\sigma_{clk\&eph}$ | 卫星时钟和星历误差 | 均质影响 |
| $\sigma_{iono}$ | 电离层残余误差 | 均质影响 |
| $\sigma_{tropo}$ | 对流层残余误差 | 均质影响 |
| $\sigma_{noise}$ | 热噪声和干扰 | 城市电磁环境复杂 → 更差 |
| $\sigma_{multipath}$ | **多径效应** | **城市峡谷最严重的误差源**，难以建模 |

### 位置精度因子（PDOP）

导航位置误差：

$$\sigma_{NAV\_position} = \sigma_{UERE} \times PDOP$$

位置不确定性协方差矩阵：

$$\Sigma_{NAV} = \sigma^2_{UERE} \cdot (G^T G)^{-1}$$

其中 G 为卫星几何矩阵。

### 城市峡谷性能阈值

$$\sigma_{GNSS} \geq W \Rightarrow \text{导航性能不足}$$

其中 W = 最小峡谷宽度（澳大利亚市中心：**25 m**）。

该阈值可作为容量折减的**阶跃函数**：当 $\sigma_{GNSS} < W$ → 正常容量；$\sigma_{GNSS} \geq W$ → 容量受限或 = 0。

### 基于性能导航（PBN）适配

- PBN + PBCS → PBO（基于性能的运行）
- 飞行器性能等级 → 空域准入权限 → 差异化容量配额
- 高 CNS 性能 → 更小间隔 → 更多容量：这是**市场化容量分配的技术基础**

## 监视系统模型

### 一次雷达（PSR）误差模型

**距离测量误差**（与 SNR 相关）：

$$\sigma_{RDR\_range} = \frac{c}{2B\sqrt{2 \cdot SNR}}$$

其中 B = 波形带宽，c = 光速，SNR = 信噪比。

**角度测量误差**（与波束宽度和单脉冲差斜率相关）：

$$\sigma_{RDR\_angle} = \frac{\nu}{k_m \sqrt{2 \cdot SNR}}$$

其中 $\nu$ = 雷达波束宽度，$k_m$ = 单脉冲方向图差斜率。

**跟踪协方差**：距离和角度的测量误差传播到笛卡尔位置不确定性中形成误差椭球体。

### ADS-B 监视误差

当 ADS-B 为主要监视手段时：

$$\sigma_{tracking} = \sqrt{\sigma^2_{NAV} + \sigma^2_{com}}$$

其中 $\sigma_{NAV}$ = GNSS 位置不确定性，$\sigma_{com}$ = 通信延迟引起的不确定性。

### SACA 总时间

冲突解决总时间 $t_{SA/CA}$ 是以下任务的时间之和：
1. 处理入侵飞机轨迹
2. 评估潜在碰撞威胁
3. 生成避撞轨迹
4. 执行避撞操作

在 LAAM 中，这些任务大部分假定由自主系统执行（仅在紧急情况下需要人工干预），因此 **$t_{SA/CA}$ 是 CNS 性能的直接函数**。

## 在子课题3 中的应用

### CNS 性能→折减系数映射

| CNS 性能状态 | 导航不确定性 | 通信延迟 | 监视精度 | 容量折减系数建议 |
|:---|:---|:---|:---|:---|
| 优良（开放空域） | σ < 5m | < 5ms | 高精度 ADS-B | 1.0（基准） |
| 中等（郊区） | 5m ≤ σ < 25m | 5-10ms | 中等 | 0.6-0.8 |
| 受限（城市峡谷） | σ ≥ 25m | >10ms | 多径干扰严重 | 0.3-0.5 |
| 丧失（隧道/地下） | σ → ∞ | 断连 | 无法监视 | 0（禁飞） |

### 与现有监测预警体系的集成

- **绿**（正常）：CNS 性能全部达标 → 容量 = 静态基准 × 1.0
- **黄**（警戒）：某 CNS 维度降级 → 容量 = 静态基准 × CNS 折减系数
- **红**（预警）：CNS 性能低于安全阈值 → 容量 = 0 或紧急限制

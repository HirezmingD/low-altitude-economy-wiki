# 准移动闭塞安全间隔模型

## 概述

李艳华等（2025）将铁路准移动闭塞技术引入低空交通，提出以**前机所在闭塞分区始端为追踪目标点**的动态安全间隔模型，通过制动曲线计算实现航空器间的自动安全距离保持。

## 模型原理

### 直线飞行间隔

$$H_{nm} = \frac{v_n^2}{2a_n} + D_{iz}$$

| 参数 | 含义 | 单位 |
|------|------|------|
| v_n | 后行航空器n当前速度 | m/s |
| a_n | 常规制动减速度 | m/s² |
| D_iz | 纵向静态安全间隔 | m |

### 平面交叉口间隔

$$H_{nm} = \frac{v_n^2}{2a_n} + D_{ih}$$

- D_ih：横向安全间隔（考虑侧向碰撞风险）

### 运行逻辑

```
前机m占用分区k
    ↓
分区k → 后机n的「闭塞区」🔴 禁止进入
分区k-1 → 后机n的「缓冲区」🟡 以分区k始端为目标，计算制动曲线
分区k-2及以前 → 后机n的「自由区」🟢 保持原速
```

## 制动曲线生成

以闭塞区始端为目标点，结合目标距离、当前速度、制动性能生成航空器制动曲线，确定制动起始点。进入缓冲区（黄灯）后开始按曲线减速。

## 分区设计约束

- 分区长度 L_i ≥ 安全间隔 D_iz
- 每分区仅允许一架航空器占用
- 不同高度层分区长度不同（取决于该层航空器性能）

## 与容量评估的关系

单航道小时容量由间隔模型决定：

$$C = \frac{3600 \cdot v}{H + L_{aircraft}}$$

关键变量：v（速度↑→容量↑）、a（制动性能↑→H↓→容量↑）、D（安全余量↑→容量↓）

## 技术特点

| 维度 | 特点 |
|------|------|
| 安全性 | 准移动闭塞比移动闭塞多一层分区冗余 |
| 自动化 | 红绿灯信号无需人工管制，适配高密度 |
| 有人/无人融合 | 统一间隔规则，不区分航空器类型 |
| 技术依赖 | 需要低空智联网（5G-A通感一体）支撑实时感知 |

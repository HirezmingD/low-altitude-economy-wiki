# CNN-ConvLSTM复杂度预测模型

> ⭐ 核心方向 — 子课题3算法参考

## 技术概述

CNN-ConvLSTM是一种面向城市低空分层空域复杂度预测的深度学习模型，由空间编码器（CNN）、时序建模器（ConvLSTM）、未来预测器和空间解码器四部分组成，实现60s历史→180s复杂度场的端到端多步预测。

## 模型架构

```
┌─────────────────────────────────────────────┐
│  输入: 12帧 × 50×50 × 8通道                 │
│            ↓                                │
│  ┌─ CNN空间编码器 ──────────────────────┐    │
│  │ Conv2d(8→32, 3×3, ReLU)              │    │
│  │ Conv2d(32→64, 3×3, ReLU)             │    │
│  │ MaxPool(2×2, stride=2)               │    │
│  │ 输出: 12帧 × 25×25 × 64通道           │    │
│  └──────────────────────────────────────┘    │
│            ↓                                │
│  ┌─ ConvLSTM时序建模器 ─────────────────┐    │
│  │ 单层ConvLSTM(input=64, hidden=64)     │    │
│  │ kernel=3×3, 循环处理12步              │    │
│  │ 输出: H_12 (64×25×25)，编码60s演化     │    │
│  └──────────────────────────────────────┘    │
│            ↓                                │
│  ┌─ 未来预测器 ────────────────────────┐    │
│  │ Conv2d(64→36×64, 3×3)               │    │
│  │ reshape → 36帧 × 64×25×25            │    │
│  └──────────────────────────────────────┘    │
│            ↓                                │
│  ┌─ CNN空间解码器 ──────────────────────┐    │
│  │ Upsample(scale=2, bilinear)          │    │
│  │ Conv2d(64→32, 3×3, ReLU)            │    │
│  │ Conv2d(32→3, 1×1, linear)           │    │
│  └──────────────────────────────────────┘    │
│            ↓                                │
│  输出: 36帧 × 50×50 × 3通道                 │
│  (C_spv, C_hpv, C_cross)                    │
└─────────────────────────────────────────────┘
```

## 训练配置

| 参数 | 值 |
|------|-----|
| 优化器 | AdamW (lr=1e-3, weight_decay=1e-4) |
| 调度器 | Cosine Annealing LR |
| 损失函数 | Smooth L1（三通道等权和） |
| 批大小 | 8 |
| 最大epoch | 50（patience=10早停） |
| 训练时长 | ~7-8分钟（RTX 4060 8GB） |
| 数据集 | BlueSky仿真：75训练+20验证场景 |

## 预测策略

- **直接预测**（非残差）：模型直接输出未来36帧的复杂度值
- 消融实验证明残差连接失效（R²为负），因为高动态场景下复杂度突变频繁
- 推理阶段对输出截断至[0,1]与物理定义一致

## 性能指标

| 指标 | 全格 | 非零格 |
|------|------|--------|
| MAE | 0.0045 | 0.0196 |
| R² | 0.870 | 0.838 |
| 推理延迟 | 26.1ms（中位数） | P95: 51.2ms |

## 消融实验结论

| 序号 | 变体 | R² | 关键发现 |
|------|------|-----|---------|
| A1 | 完整SHC | 0.809 | 基线 |
| A2 | 无CNN编码器 | 0.647 | CNN空间编码贡献第三 |
| A3 | 无ConvLSTM | 0.570 | **ConvLSTM贡献最大**（-30%） |
| A4 | 5通道（去HPV） | 0.707 | HPV特征对非零格影响大 |
| A5 | 单通道输出 | 0.622 | 分层输出优于总复杂度 |

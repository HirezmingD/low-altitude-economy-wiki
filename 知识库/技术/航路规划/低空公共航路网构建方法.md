# 低空公共航路网构建方法

## 概述

廖小罕团队提出的城市低空公共航路网（天路图）构建方法体系，基于遥感AI解译+空域网格化+蚁群路径优化+三维仿真验证的完整技术链。

## 技术流程

### 第一步：低空空域网格化与数字化

**输入**：城市低空空域（真高1000m以下）
**方法**：
1. 统一网格剖分系统进行多级剖分
2. 剖分单元大小适应航路宽度要求（通常数米至数十米）
3. 每一体块赋予**唯一空间编码**（位置+层级）
4. 标注属性：空域性质、风险评级、障碍物信息等

**输出**：数字化低空体元栅格数据库

### 第二步：地理约束要素提取

**输入**：高分辨率遥感影像 + 城市三维模型
**方法**：
- 遥感智能解译技术 → 精准甄别约束要素：
  - 自然下界面：地形起伏
  - 人工附属物：建筑物、电力线、塔架
  - 政策边界：禁飞区、限飞区
  - 大气环境：边界层湍流区域
- 构建**地理约束要素特征库** + **影像识别与快速提取算法库**
- 有利条件识别：城市绿化带降低坠地风险，可作为航路辅助

**输出**：净空边界地理网格数据库

### 第三步：多级航路网路径规划

**输入**：净空边界数据库 + UAM交通需求
**方法**：
1. 改进蚁群算法（徐晨晨等）——全局路径寻优
2. 多级航路设计：不同级别航路对应不同限速/限高/准入条件
3. 地理约束要素迭代优化——避开约束区，利用有利区
4. 多航道时空资源配置——同一区域同一时段多机多用户运行

**航路布局备选方案**：
| 方案 | 特点 |
|------|------|
| AirMatrix网格布局 | 规则网格式，高自动化要求 |
| 建筑物楼顶布局 | 结合起降点，适合作业型 |
| 道路沿线布局 | 自然规避建筑物，有对地风险 |

### 第四步：仿真验证与迭代

**输入**：规划航路方案
**方法**：
1. 三维飞行仿真——验证航路可行性
2. 实际飞行验证——真实场景测试
3. 风险评估——空中碰撞+地面坠毁双维度
4. 迭代优化——根据验证结果调整航路

**输出**：最终航路网方案（天路图）

## 关键支撑系统

### 三维地理信息系统
- 基于遥感、时空地理大数据、人工智能
- 体元栅格三维航路及环境高效表达
- 动态仿真+虚拟现实验证

### 运行监管系统
- 中科天网云系统（民航局唯一公有云运行许可）
- 全国无人机遥感数据目录信息服务平台
- 云边端一体化网络体系
- 实时三维可视化+空地协同起降点网+高精度气象预报

## 容量评估视角

航路网构建直接影响容量：

- **航路宽度** = 体元栅格剖分单元 → 决定单航道容量
- **航路分级** → 不同级别不同容量参数
- **交叉口设计** → 瓶颈节点容量
- **多航道时空资源配置** → 总体网络容量

## 方法特征

1. **自顶向下**：从系统层面规划，非航空器自主航路
2. **约束驱动**：地理约束要素是航路划设的首要依据
3. **多用户共享**：航路为公共基础设施，非专用
4. **分级体系**：类似道路的国道/省道/县道分级

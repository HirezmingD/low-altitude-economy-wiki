# 空—地协同划设技术
## 技术概述
空—地协同划设技术是一套基于GIS和实景三维的复合技术体系，用于将空中飞行需求与地面空间约束进行协同分析与边界划设，输出可落地的低空空域管理方案。核心思路是通过技术融合+制度联动，实现空中边界与地面约束的双向反馈与实时校核。
## 技术架构
```
空中维度（飞行侧）           地面维度（用地侧）
─────────────────           ─────────────────
垂向高度分层                  刚性约束识别
(0-300/300-600/600-1000m)    (军事/敏感区/障碍物)
+
水平范围划设                  地面要素普查
(固定空域+临时空域)           (国土调查/地形地貌)
↘                      ↙
空—地协同划设引擎
(GIS + 三维网格 + 数字孪生)
↓
输出：分区/分层/分时管理方案
```
## 核心技术组件
### 1. 三维网格体素化
- 摒弃传统"点对点"航路模式
- 对空域进行三维体素切分
- 精确计算建筑物净空包络与安全隔离带
- 生成数字化电子围栏，实现空中边界精准落图
### 2. 地面边界映射
核心逻辑：将地面要素投影/映射为空中约束体
- **刚性管理要素** → 禁飞体（政治、军事、特殊防护区）
- **风险敏感要素** → 限制体（学校、危化品库、核电站）
- **高层建筑障碍** → 高度约束面
- 方法：垂直投影 + 缓冲扩展 + GIS拓扑关联
### 3. GIS空间叠加分析
- 建立用地功能与空域属性的拓扑关联
- 集成空间叠加分析+边界矢量化解译
- 依托全空间智能GIS平台实现可视化界定与动态调整
### 4. 实景三维 + 数字孪生
- 基于实景三维中国数据底座
- 融合格网剖分及高精度地形数据
- 构建低空数字孪生底座
- 支撑实时动态调整
## 适用条件
- 需要有高精度地理信息数据和实景三维数据
- 需要有完整的地面用地分类和建筑物三维模型
- 适用于规划级宏观评估，运营级需结合实时数据流
## 局限性
- 当前技术偏静态规划层面，缺乏实时动态反馈
- 建筑物变更（新建/拆除）后的空域更新机制未详细讨论
- 多运营人同时段空域竞争的分时协调机制待深化

# 风场感知改进A*路径规划算法

## 概述

张召悦等（2026）针对传统A*算法在三维城市风场环境中的缺陷（固定步长、二维建模、无风场权重），提出的三层改进方案。

## 传统A*缺陷

| 缺陷 | 后果 |
|------|------|
| 固定步长 | 狭窄空域规划失败，开阔区效率低 |
| 欧式距离启发 | 不反映实际飞行时间 |
| 无风场权重 | 可能进入高风险区 |
| 无平滑处理 | 轨迹拐点多，姿态调整能耗高 |

## 三层改进

### 1. 动态步长

$$S(i) = \min(k \cdot S_0 + \mu, \ S_{min})$$

步长与(1)当前节点到终点距离、(2)最近建筑障碍物距离联动：
- 狭窄区域：缩小步长 → 提升精度
- 开阔风场：放大步长 → 加速搜索

### 2. 直线可达性检测

拓展节点时回溯父节点：
- 两点间无建筑 + 无高风风险 → 直接直线连接
- 删减冗余拐点 → 拐点数 **-58.2%**

### 3. 风场感知时间代价函数

替代传统欧式距离单一权重：

$$g(n) = \sum_{i=1}^{n} \frac{dist(c_{i-1}, c_i)}{v_{k, i-1}}$$

$$h(n) = \sum_{}^{k} \frac{dist(c_{i-1}, c_i)}{v_{g, exp}}$$

- vk：当前栅格实际地速（空速±风速分量）
- 顺风加速、逆风减速完全量化

### 后处理：B样条平滑

路径输出后B样条曲线平滑拐点，过渡顺滑。

## 性能

| 指标 | 传统A* | 本文算法 |
|------|--------|----------|
| 飞行时间 | 基准 | **-23.6%** |
| 拐点数 | 基准 | **-58.2%** |
| 风险区穿越 | 可能 | **零** |
| 最优栅格粒度 | — | **2m** |

## 实验条件

- 区域：深圳南山区高密度城区（1km×0.9km）
- 无人机：大疆M350（空速12m/s，最大抗风12m/s）
- 飞行高度：80~150m
- 基准风速：8m/s（三级风上限）

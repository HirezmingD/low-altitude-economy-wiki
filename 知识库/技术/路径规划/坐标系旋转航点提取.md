# 坐标系旋转与边界航点提取方法

## 概述

徐博等（2015）提出的不规则区域全覆盖航线生成的坐标变换+航点提取方法。核心技巧是**将作业方向对齐为坐标轴方向**，化不规则区域的二维剖分为一维边界求交问题。

## 步骤一：环境坐标系构建

1. GPS获取凸多边形顶点的经纬度 (Lon, Lat)
2. 以最小经纬度为原点O：O = (Lon_min, Lat_min)
3. 建立米制直角坐标系OXY：X正东，Y正北
4. 将所有顶点转换为米制坐标Dj(xj, yj)

## 步骤二：坐标系旋转

**目的**：使新坐标系的X'轴平行于作业航向n（与Y轴夹角α）

**旋转角**：
- 当 0<α≤π/2：逆时针旋转(π-α)
- 当 π/2<α≤π：顺时针旋转(α-π/2)

**坐标转换方程**：
```
x' = (x - x_O')·cos(旋转角) + (y - y_O')·sin(旋转角)
y' = -(x - x_O')·sin(旋转角) + (y - y_O')·cos(旋转角)
```

## 步骤三：子区域剖分

1. 计算缩放后区域Y'范围：[y'_min, y'_max]
2. 子区域数量：由 (y'_max - y'_min)/d 决定（d为幅宽）
3. 分隔线：第k条为 y' = y'_max - (k-1)d, k=1,2,…,n
4. 第k子区域位于两条分隔线之间

## 步骤四：航点提取

对每条子区域：
1. 找出区域边界线上满足 y'_max-k·d ≤ y' ≤ y'_max-(k-1)d 的所有点
2. 提取这些点的x'坐标最小值x'_kmin和最大值x'_kmax
3. 第k条航线的两个航点：
   - (x'_kmin, y'_max-(k-1/2)d)
   - (x'_kmax, y'_max-(k-1/2)d)

## 步骤五：航向角寻优

遍历α从0到180°（步长5°），对每个α重复步骤二至四，计算多余覆盖率ε：
```
ε = (覆盖面积S' - 区域面积S) / S
```
选择ε最小的α为最优航向角。

## 算法复杂度

- 航向角采样数：~36（5°步长）
- 每次采样的子区域数：~区域高度/d
- 每次边界求交：O(m)，m为顶点数

总复杂度 ≈ O(36 × m × H/d)，其中H为区域高度。对于农业田块规模（百m²级），计算可在秒级完成。

## 对空域规划的启发

1. **坐标对齐简化法**：将复杂方向约束通过旋转转化为轴对齐→可借鉴用于空域航路方向标准化
2. **遍历寻优**：α步长遍历→可类比空域航路方向对容量影响的参数扫描
3. **边界交点法**：障碍物边界与栅格线的交点→可类比空域中禁飞区与航路的交叉检测

⚠️ 应用领域不同（农业喷洒 vs 城市空域），但坐标变换+栅格剖分的数学框架有一定通用性。

# 浙江省民用航空条例

## 基本信息

| 项目 | 内容 |
|:---|:---|
| 发布机构 | 浙江省第十四届人民代表大会常务委员会 |
| 通过日期 | 2026年5月28日 |
| 施行日期 | 2026年10月1日 |
| 公告号 | 第48号 |
| 法律层级 | 地方性法规 |
| 地位 | 课题所在省份的民用航空地方法规 |

## 章节结构（7章43条）

1. 总则
2. 机场规划建设
3. 机场运营管理
4. 机场安全环境保护
5. **低空飞行促进** ⭐（§27-§34）
6. **航空产业发展** ⭐（§35-§42）
7. 附则

## 低空飞行促进专章（§27-§34）

这是与课题最相关的章节：

- **§27**：县级以上政府统筹低空飞行航路航线规划布局，加强起降场、测试场及通信导航监视气象设施建设和维护
- **§28**：依托全省统一的低空飞行数字化监管服务平台，完善适飞空域公布、飞行计划管理、飞行动态监测等功能
- **§29**：推动完善无人驾驶航空器责任保险制度
- **§30**：促进地面物流网络和低空物流网络融合发展
- **§31**：低空应急救援体系建设
- **§32-§33**：推动低空在警务、测绘、环保、旅游、体育、农林等场景应用
- **§34**：做好无人驾驶航空器安全管理

## 航空产业发展专章（§35-§42）

- 支持航空制造、航空服务产业集群
- 临空经济区建设
- 航空人才引进与培养
- 社会资本投入与金融服务

## 对课题的意义

- 课题所在地的低空经济**地方法律框架**
- 明确省交通运输主管部门的行业管理职责
- 低空飞行促进专章为浙江示范区建设提供法律依据
- 南浔、余杭等示范区的政策背景

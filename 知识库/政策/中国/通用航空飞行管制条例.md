# 通用航空飞行管制条例

## 基本信息

| 项目 | 内容 |
|:---|:---|
| 发布机构 | 国务院、中央军事委员会 |
| 施行日期 | 2003年 |
| 法律层级 | 行政法规 |
| 依据 | 《民用航空法》《飞行基本规则》 |
| 地位 | 通用航空飞行活动的专项管理法规 |

## 核心制度

### 1. 临时飞行空域（§7-§11）
- 申请时限：**拟使用前7个工作日**提出（§9）
- 批准时限：拟使用前**3个工作日**前作出决定（§9）
- 使用期限：通常**不超过12个月**（§10）
- 批准权限：机场区域内→机场飞行管制部门；超出机场→分区/管制区/空军逐级审批（§8）

### 2. 飞行计划管理（§12-§18）
- 标准计划申请：**拟飞行前1天15时前**提出，**前1天21时前**批复（§16）
- 紧急任务：**最迟拟飞行前1小时**提出，起飞前15分钟批复（§16）
- 临时空域内短期计划：可一次性申请15天以内，不再逐日申请（§17）

### 3. 飞行保障（§20-§30）
- 飞行的组织指挥由从事通用航空活动的单位/个人负责（§24、§28）
- 机长对能否起飞、着陆和飞行有最终决定权（§29）

## 时效性说明

- 2003年发布，仍为现行有效行政法规
- 随着2024年《无人驾驶航空器飞行管理暂行条例》施行及2026年新《民航法》施行，其中部分无人机相关条款可被专项法规覆盖
- 条例中的通用航空定义（§3）与新《民航法》§157的表述基本一致

# 通用航空经营许可管理规定

## 基本信息

| 项目 | 内容 |
|:---|:---|
| 发布机构 | 中国民用航空局 |
| 发文日期 | 2016年4月7日 |
| 法律层级 | 部门规章 |

## 核心制度

### 经营项目分类（§6）

| 类别 | 典型项目 |
|:---|:---|
| **甲类** | 通用航包机飞行、石油服务、直升机引航、医疗救护、商用驾驶员执照培训 |
| **乙类** | 空中游览、航空摄影、海洋监测、城市消防、电力作业、航空器代管等 |
| **丙类** | 私用驾驶员执照培训、航空护林、航空喷洒/撒、空中拍照、气象探测等 |
| **丁类** | 使用载人自由气球/飞艇空中游览、航空表演飞行、个人娱乐飞行等 |

### 经营许可条件（§8）
- 企业法人，法定代表人中国籍
- 购买或租赁**不少于2架**民用航空器
- 有训练合格的航空人员
- 有基地机场（起降场地）及基础设施
- 投保地面第三人责任险等

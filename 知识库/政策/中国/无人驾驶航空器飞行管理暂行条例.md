# 无人驾驶航空器飞行管理暂行条例

## 核心制度

### 1. 无人机分类（§62）

| 类别 | 空机重量 | 最大起飞重量 | 速度限制 | 其他特征 |
|:---|:---:|:---:|:---:|:---|
| **微型** | <0.25kg | — | ≤40km/h | 真高≤50m，微功率无线电 |
| **轻型** | ≤4kg | ≤7kg | ≤100km/h | 需空域保持&可靠被监视能力 |
| **小型** | ≤15kg | ≤25kg | — | 同上 |
| **中型** | — | ≤150kg | — | 不含微/轻/小型 |
| **大型** | — | >150kg | — | — |

### 2. 管制空域制度（§19-§20）

**强制划设管制空域的范围：**
- 真高120米以上空域
- 空中禁区、空中限制区及周边
- 军用航空超低空飞行空域
- 机场及周边一定范围
- 国境线我方一侧一定范围
- 军事禁区、军工设施、核设施等敏感区域上空
- 重要公共基础设施、大型仓储区域上空
- 射电天文台、雷达站等电磁环境敏感区域上空
- 重要革命纪念地、不可移动文物上空

**管制空域外**为微型、轻型、小型无人机的适飞空域。

### 3. 融合飞行制度（§22）

| 融合飞行类型 | 条件 | 是否需要批准 |
|:---|:---|:---:|
| 警/海/应急部门内部 | 同一空域/机场区域 | ✓ 需批准 |
| 大型无人机 | 取得适航许可 | ✓ |
| 中型无人机 | ≤真高300m | ✓ |
| 小型无人机 | ≤真高300m | ✓ |
| 轻型无人机 | 适飞空域上方≤300m | ✓ |
| 微/轻型在适飞空域 | — | ✗ 无需批准 |
| 常规农用无人机 | — | ✗ 无需批准 |

### 4. 操控员管理（§16-§17）

| 无人机类别 | 要求 |
|:---|:---|
| 微型/轻型 | 无需执照，需掌握操作方法，了解风险 |
| 小型/中型/大型 | 需取得操控员执照（完全民事行为能力、培训考核、无犯罪记录等） |
| 常规农用无人机 | 无需执照，需取得操作证书 |

### 5. 运营管理（§11-§12）

- 使用**除微型以外的**无人机从事飞行活动的单位须取得**运营合格证**
- 常规农用无人机（≤150kg）作业无需运营合格证
- 经营性飞行及小/中/大型非经营性飞行须投保**责任保险**

### 6. 飞行申请（§26-§31）

| 飞行类型 | 申请时限 | 批准时限 |
|:---|:---|:---|
| 一般飞行 | 前1日12时前 | 前1日21时前 |
| 紧急任务 | 起飞前30分钟 | 起飞前10分钟 |
| **适飞空域内微/轻/小型** | **无需申请** | — |
| **常规农用** | **无需申请** | — |

### 7. 一体化监管平台（§23-§24）
- 国家无人驾驶航空器一体化综合监管服务平台
- 除微型外，无人机须报送识别信息
- 微/轻/小型须广播式自动发送识别信息

### 8. 反制设备管制（§43）
- 仅军队、警察和高风险反恐重点目标管理单位可配备
- 需在公安机关或军事机关指导监督下使用
- 任何单位或个人不得非法拥有、使用

## 与上位法的关系

- **§58**：本条例没有规定的，适用《[民用航空法](知识库/政策/中国/民用航空法2026.md)2026.md)》《[飞行基本规则](知识库/政策/中国/飞行基本规则.md).md)》《[通用航空飞行管制条例](知识库/政策/中国/通用航空飞行管制条例.md).md)》
- **《民航法》§258**："国务院、中央军事委员会对无人驾驶航空器的管理另有规定的，从其规定"
  - → 在无人机领域，本条例**优先于《民航法》适用**

## 对课题的意义

- **低空物流/载人/应急场景**的直接法律依据
- 管制空域划设规则直接影响低空航路规划
- 融合飞行制度是低空多场景共存运行的法律基础
- 一体化监管平台是数字孪生底座的政策接口

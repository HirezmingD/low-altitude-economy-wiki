## 核心制度

### 1. 空中交通管理架构（§4-§8）
- 空中交通管理 = **空中交通服务** + 空中交通流量管理 + 空域管理
- 空中交通服务 = **空中交通管制服务** + **飞行情报服务** + **告警服务**

### 2. 三级管制体系（§6、§14）

```
区域管制（高空/中低空管制区）
        ↓
进近管制（终端/进近管制区）
        ↓
机场塔台管制（机场管制地带）
```

### 3. 通用航空的特殊规定（§10）
- 在临时飞行空域内进行通用航空飞行 → 由从事通用航空活动的单位/个人负责组织，并对安全负责
- 在起降点飞行 → 由从事通用航空活动的单位/个人负责

## 对课题的意义

- 空中交通服务三大功能（管制/情报/告警）是低空综合管理平台的业务模型参照
- 通用航空在空管规则中的特殊地位为低空飞行服务体系建设提供了法律空间

# T/GITIF 028-2025[《低空航路运行安全能力评估规范》](知识库/政策/中国/低空航路运行安全能力评估规范.md)

## 核心内容

### 第1章 范围
适用于无人机等各类低空飞行器的航路安全场景评估。供低空飞行服务站、飞行器运营企业、空中交通管理部门使用。

### 第2章 规范性引用文件
引用MH/T 4055、[CCAR-92](知识库/政策/中国/无人驾驶航空器飞行管理暂行条例.md)、CCAR-86-R1、CCAR-115TM-R2、MH/T 4054等18项标准文件。

### 第3章 术语和定义
定义16项核心术语：低空飞行、航路安全评估、通信/导航/监视、禁飞区、限制区、重点保护设施、迫降点、目标信号等。

### 第4章 评估指标体系（核心）
详见[低空航路安全评估指标体系](/知识库/概念/容量评估/低空航路安全评估指标体系.md)

涵盖8类基础指标（空域环境/地理环境/通信/导航/监视/电磁/基础气象/反制）+ 1类动态气象指标，共76项二级指标。

### 第5章 综合评价（核心）
详见[低空航路安全综合评估方法](/知识库/技术/容量建模/低空航路安全综合评估方法.md)

采用"基础分值 + 动态气象修正"模型，四级安全分级（A/B/C/D）。

## 与课题的关联

该标准直接支撑**子课题3（容量评估）**：
- 空域环境和地理环境指标 → 容量评估的输入参数
- 综合评估方法 → 容量建模的方法论参考
- 安全分级 → 容量等级划分参考
- 评价应用中的"流量管控"直接指向容量测算

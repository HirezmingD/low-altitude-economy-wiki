# 低空经济知识库

一个面向低空经济（Low-Altitude Economy）研究的结构化知识库，以 Obsidian 为知识管理平台，系统整理低空空域治理、容量评估、产业转化等领域的学术文献、政策文件、技术概念与全球实践案例。

## 知识库结构

```
├── 知识库/
│   ├── 概念/          # 核心概念解析（空域治理、容量评估、低空经济）
│   ├── 摘要/          # 论文与报告摘要（空域治理、容量评估、产业转化、应用案例、政策标准）
│   ├── 技术/          # 技术方法（容量建模、机器学习、数字孪生、路径/航路规划）
│   ├── 政策/          # 政策法规整理（中国、国际）
│   ├── 实体/          # 关键实体（国家地区、平台系统、机构组织、示范区域）
│   ├── 文献综述/      # 系统性文献综述
│   └── 综合分析/      # 跨领域综合分析
├── 原始素材/          # 原始资料存档
│   ├── 论文/          # 学术论文全文
│   ├── 政策文件/      # 法律法规与规范性文件
│   ├── 文章/          # 行业报告与新闻报道
│   ├── 报告/          # 研究报告
│   └── 全球比较/      # 国际案例对比
├── Clippings/         # 即时剪藏
└── 模板/              # 知识库页面模板
```

## 覆盖领域

### 空域治理
低空空域管理体制、用途管制、空域分类、法律体系、数字飞行规则、机器可读法规、三级管控体系、U-Space 生态体系、AATM 先进空中交通管理系统等核心概念。

### 容量评估
空域复杂度建模、动态容量平衡、移动闭塞空域管控、低空公共航路、风场感知栅格、空域资源动态调配、阈值法容量评估、UAM 容量增长路线等关键方法与模型。

### 产业转化
eVTOL 航空器技术、低空经济产业图谱、垂直起降场与交通枢纽融合、低空起降设施用地规划、低空经济六大体系等产业维度。

### 全球比较
覆盖中国、美国、欧盟、日本、新加坡、阿联酋、英国、印度等国家和地区的政策框架与技术路线，包括各主要 UTM/U-Space/AAM 平台系统的架构对比。

### 技术方法
涵盖容量建模（CNS 性能模型、气体定律冲突预测、AFPS 自动飞行规划）、机器学习（CNN-ConvLSTM 复杂度预测、八通道空域特征工程）、数字孪生（北斗+5G 一体化基站）、路径规划（风场感知 A* 算法）等前沿技术。

## 使用方式

本知识库基于 Obsidian 构建，建议使用 [Obsidian](https://obsidian.md/) 打开以获得完整的双向链接、图谱视图和搜索体验。核心入口页面为目录文件与文献综述。

## 许可

本知识库内容仅用于学术研究与知识共享目的。

## 知识库概览

本知识库是一个面向低空经济研究的结构化知识管理系统，基于 [Obsidian](https://obsidian.md/) 构建。它系统整理了低空空域治理、容量评估、全球比较、产业转化等领域的学术文献、政策文件、技术概念与全球实践案例。

## 覆盖领域

### 空域治理

低空空域管理体制、用途管制、空域分类制度、法律体系（四层金字塔）、数字飞行规则、三级管控体系、U-Space 生态体系、AATM 先进空中交通管理系统、政企协同治理模式等核心概念。

涵盖 [《民用航空法》(2026修订)、无人机管理条例、CCAR-92、浙江省民用航空条例等](知识库/政策/中国/) 全套中国法规文件，以及 [全球治理模式五方分类](知识库/综合分析/全球低空空域分类制度五方比较.md) 的国际制度对比。

### 容量评估 ★ 核心方向

从 [空域资源理论](知识库/概念/容量评估/空域资源四维时空体.md)（廖小罕 2021）到 [16 折减因子体系](知识库/实体/示范区域/案例对比/子课题3关联对比.md)，完整覆盖理论层→方法层→应用层：

- **方法论谱系**：阈值法（Bulusu）· SHC 复杂度预测（CNN-ConvLSTM）· 多尺度协同优化（包杰）· 安全间隔法（移动闭塞）· 进场容量模型（等待时间）
- **环境因子**：风场栅格化 · 气候-性能-容量耦合（GCC）· 碳排放约束（巴黎 eVTOL）· CNS 性能传导链
- **评估-预警-调控闭环**：对标深圳 SILAS、成都 iwhereSky 红绿灯、日本 AATM 五类服务

### 全球比较

覆盖 8+ 国家/地区，五种治理模式分类（市场主导·规则引领·政企协同·制度特区·城市密集），18 个全球示范案例实证数据对标。日本三部曲（路线图→ConOps→铁路跨界实践）提供全球最清晰的"密度-时间"映射关系。

### 产业转化

eVTOL 航空器技术、低空经济产业图谱、垂直起降场与交通枢纽融合、"车站=垂直起降场"范式（日本铁路跨界）、低空起降设施用地 S5、社会接受度量化模型。

## 覆盖领域

### 空域治理

低空空域管理体制、用途管制、空域分类制度、法律体系、数字飞行规则、机器可读法规、三级管控体系、U-Space 生态体系、AATM 先进空中交通管理系统、政企协同治理模式等核心概念。覆盖中国完整的低空法律体系（四层金字塔结构），以及全球五种治理模式的制度对比。

### 容量评估 ★

从空域资源属性理论（自然/社会/经济三维属性）到 16 折减因子体系，完整覆盖"理论容量 → 有效容量 → 安全容量 → 容量动态"的评价链条：

- **方法论谱系**：阈值法（冲突率相变）· SHC 复杂度预测（CNN-ConvLSTM）· 多尺度协同优化 · 安全间隔法（移动闭塞）· 进场容量模型
- **环境因子**：风场栅格化 · 气候-性能-容量耦合 · 碳排放约束 · CNS 性能传导链
- **评估-预警-调控闭环**：对标多国实践系统中的完整闭环

### 全球比较

覆盖 8+ 国家/地区，五种治理模式分类（市场主导·规则引领·政企协同·制度特区·城市密集），18 个全球示范案例的实证数据对标，多国运行概念（ConOps）技术架构的系统比较。

### 产业转化

eVTOL 航空器技术、低空经济产业图谱、垂直起降场与交通枢纽融合范式、低空起降设施用地规划、社会接受度量化模型、产业考核 KPI 框架等产业维度。

## 技术方法

涵盖容量建模（CNS 性能模型、冲突预测、空域结构设计）、机器学习（CNN-ConvLSTM 复杂度预测、八通道空域特征工程）、数字孪生（通导一体化基站、时空数据引擎）、路径规划（风场感知 A*、混合整数规划）等前沿技术。

- 目录 — 全部页面索引
- 工作规则 — 操作规则手册

## 开源与协作

本知识库将逐步更新与完善。欢迎低空经济相关领域的研究者共同维护和贡献：

- **贡献内容**：论文摘要、案例分析、概念梳理、政策法规整理、国际比较研究
